# AGI Super Team visual direction

Audience: developers and creators who want their existing coding-agent environment to coordinate a concrete task.

The central promise is legible work: one brief becomes a plan, specialist artifacts and an inspectable review. Illustrations are conceptual; they do not certify an executed task or universal harness capability.

## Direction

- Ink-black, cool-white and ice-cyan; small chartreuse accents.
- Precision optics and coordinated information paths, with tangible page, code and report outputs.
- Existing local Instrument Sans for interface text and JetBrains Mono for commands.
- Strong hierarchy, generous negative space, reduced-motion support and accessible HTML labels.
- Avoid warm desk miniatures, robot mascots, decorative neural clouds and fake performance numbers.

The ui-ux-pro-max searches matched Developer Tool / IDE, Dark Mode (OLED) and Developer Mono. Their FAQ-first landing recommendation does not match this product-introduction task; the brief-to-deliverable story is an explicit design adaptation. Existing fonts avoid additional network dependencies.

## Image generation

The user initially requested `gpt-image-2`, then explicitly chose ChatGPT built-in image generation. The new hero and logo use the built-in `image_gen` tool. That tool does not expose a model identifier; no API-model assertion is made. Production prompts are stored beside this document. The rejected warm atelier illustration is excluded.

Logo geometry and workflow text should remain legible at small sizes. The standalone workflow SVGs have localized text equivalents in the READMEs. Original legacy assets are retained for rollback.
