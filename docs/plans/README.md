# 计划与提案

本目录存放**尚未实施**的计划、提案与设计草案。

与 [ADR](../adr/) 的区别：ADR 记录**已经做出**的架构决策且接受后不可变；本目录记录**正在考虑**的方向，可以修改、否决或被 ADR 取代。

一个计划被采纳并实施后：

- 若它构成了架构决策 → 转为一条 ADR
- 若它只是实施步骤 → 删除本目录的草稿，结论进入对应的 guide
