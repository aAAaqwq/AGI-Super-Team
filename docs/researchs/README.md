# 调研记录

本目录存放**调研文档**：对某个问题做过系统调查后留下的结论、证据分级与待验证项。

调研文档与 [guides](../guides/) 的区别：guides 是面向使用者的稳定说明，调研记录**可能包含未验证项和更正记录**，会随新证据修订。

写作约定：

- 每条结论标注证据等级：`[实测]` / `[官方]` / `[社区]` / `[未验证]`
- **未验证的内容必须显式标注**，不得作为实现依据
- 结论被推翻时保留**更正记录**，而不是静默改写
