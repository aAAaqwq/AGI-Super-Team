# 优化

本目录记录**质量审计与减重提案**。与既有目录的分工：

| 目录 | 回答什么 |
|---|---|
| `adr/` | 已接受的架构决策（不可变） |
| `plans/` | 未实施的计划与提案 |
| `architecture/` | 仓库结构与权威源 |
| **`optimization/`** | **审计发现的问题、冗余清单、减重动作** |

**规则**：本目录的每条结论必须带**可复现的命令或数字**，不写主观印象。
审计报告是一次性的快照，用日期命名；长期有效的结论才升级为 ADR。
