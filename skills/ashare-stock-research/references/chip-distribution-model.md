# 筹码分布自建模型（东财 cyq 接口失效后的替代方案）

## 背景：为什么必须自建
- 东财筹码分布接口 `push2his.eastmoney.com/api/qt/stock/cyq/get` 与 `push2.eastmoney.com/.../cyq/get`
  于 **2026-09 实测均 404**。
- 同域的 `push2.eastmoney.com/api/qt/stock/get`（拿股本/市值/PE）高频访问会 `Remote end closed connection`。
- → **筹码分布改为本地纯 Python 自建**，不依赖任何"筹码接口"。

## 一、数据准备

### 1) 日K（250 根，够覆盖一轮完整换手）
```
https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh603228,day,,,250,qfq
```
⚠️ **坑**：250 根也能返回，但 `data.<code>` 是 **dict**（键：`qfqday`/`qt`/`mx_price`/`prec`/`version`），
必须 `node.get('qfqday')` 取值。直接当 list 索引会 `TypeError: string indices must be integers`。

### 2) 流通股本（关键，别用总股本）
由腾讯行情反推 + 交叉验证：
```
[44] 流通市值(亿) ÷ [3] 现价 = 流通股本（股）
```
**验证方法**：`当日成交量(手)×100 ÷ 流通股本` 算出的换手率，必须与行情 `[38] 换手率` 吻合。
> 实证：景旺电子 1025.71亿 ÷ 104.45 = **9.82 亿股**；9/18 量 296,100 手 → 29,610,000 ÷ 9.82e8 = **3.02%** ✅ 与 `[38]=3.02` 完全一致。

## 二、算法（价格网格 + 换手率衰减）

```python
STEP = 0.20; LO, HI = 40.0, 125.0
n = int((HI - LO) / STEP) + 1
grid = [0.0] * n                        # 每个价位的持股量（股）

for r in rows:                          # rows: [date, open, close, high, low, vol]
    o, c, hi, lo, vol = map(float, (r[1], r[2], r[3], r[4], r[5]))
    shares = vol * 100                  # 手 → 股
    t = min(shares / CIRC, 1.0)         # 当日换手率
    if t <= 0: continue
    for i in range(n):                  # ① 历史筹码按换手率衰减
        grid[i] *= (1 - t)
    avg = (hi + lo + 2*c) / 4.0         # ② 当日均价（VWAP 近似）
    i0, i1 = int((lo-LO)/STEP), int((hi-LO)/STEP)
    ws = [(i, max(1 - abs(LO+i*STEP-avg)/max(hi-lo,0.01)*0.6, 0.15))
          for i in range(max(0,i0), min(n-1,i1)+1)]
    wsum = sum(w for _, w in ws)
    for i, w in ws:                     # ③ 当日新筹码按三角分布（峰=均价）分配
        grid[i] += shares * (w / wsum)
```

**要点**：① 衰减项 `(1-换手率)` 是模型的灵魂——换手越充分，老筹码被替换得越彻底；
② 均价用 `(high+low+2*close)/4` 近似 VWAP，比简单中值更贴近真实成交重心；
③ 三角分布让筹码向均价集中，比均匀分布更符合实际。

## 三、派生指标与解读

| 指标 | 算法 | 解读 |
|---|---|---|
| **获利盘比例** | Σ(价位<现价) / Σ全部 | >80% 抛压累积；<30% 底部区 |
| **市场平均成本** | Σ(价位×量) / Σ量 | 现价远高于均价 → 主力浮盈厚，主动砸盘意愿低 |
| **90% 筹码区间** | 累计 5% / 95% 分位价位 | 区间越窄 = 筹码越集中 |
| **集中度** | (p95−p5)/(p95+p5) | <20% 高度集中（易拉升）；>30% 分散 |
| **成本分层** | 按价格带统计占比 | 找**主力成本区**（最厚那带）与**高位套牢带** |

## 四、实证：景旺电子 603228（2026-09-18 收盘 104.45）

- 获利盘 **70.89%** / 套牢 29.11%
- 市场平均成本 **93.54 元**（现价高于均价 **+11.7%**）
- 90% 区间 69.60 ~ 110.80，集中度 22.8%

**成本分层**：
```
   40-80 元:  21.2%  ██████████
   80-95 元:  29.9%  ██████████████   ← 主力成本区（最厚）
   95-103元:  16.8%  ████████
  103-108元:  17.2%  ████████
  108-115元:  15.0%  ███████        ← 高位套牢带
```
**用法**：94 元是主力铁底（>50% 筹码在 95 元下方）→ 不破则主力浮盈仍在、无主动砸盘逻辑；
**103-115 元堆积 32.2%** → 这才是"为什么涨不动"的答案（每次冲高都有人解套）。

## 五、与「庄家资金强弱」串联 —— 回答"突破还是出货"的五维框架

筹码只解决"成本在哪"，必须叠三层才能下结论：

| 维度 | 数据 | 判据 |
|---|---|---|
| **① 筹码** | 本模型 | 套牢带位置 + 主力成本区；上方套牢占比 >30% 则突破需大量弹药 |
| **② 进出货** | 新浪 `MoneyFlow.ssl_qsfx_zjlrqs`（num=8~10，标准 JSON 非 JSONP） | **量能形态 × 价格行为 × 资金方向 × 获利盘 四件套**，不能只看换手率大小 —— 三态判定见下一节 |
| **③ 庄家资金强弱** | 同上，把近 10 日净流入排序成衰减曲线 | 从峰值衰减 **>90%** = "人还在，但不打了"（主升转观察期） |
| **④ 板块共振** | 腾讯行情一次拉 5-6 只同行 | **板块大涨它滞涨 = 最危险信号**（新增资金不认） |
| **⑤ 大盘** | 上证 + 深证综指（成交额）、创业板指 | 排除系统性风险，确认个股是独立弱还是被拖累 |

> ⚠️ **输出纪律**：只堆指标不给结论是无效输出。必须落到
> **「突破 / 洗盘 / 出货」三选一 + 概率 + 关键触发位（上方压力 / 下方防线）**，并给出可执行价位。

## 五-bis、洗盘 / 派发 / 失血 三态判定表（2026-10-27 修正，原「缩量=洗盘」过简）

**踩过的坑**：旧的判据是「缩量横盘=洗盘；放量长阴=派发」二元对立。
**实测发现第三种状态**：缩量**阴跌**既不是洗盘也不是放量派发，而是**派发尾声的失血**。
误判成洗盘 → 结论变成"洗盘结束会拉"，方向完全错。

| 判据 | 🟢 洗盘 | 🔴 派发（放量长阴） | 🔴 失血（缩量阴跌，最易误判） |
|---|---|---|---|
| **量能形态** | 缩量**横盘**，重心不破 | 放量长阴（换手 8%+） | **缩量阴跌**，量能逐日萎缩 |
| **价格行为** | 砸完 1-2 天内**快速收回** | 越走越低，收在低位 | **连跌数日，每天高开低走**，无一收回 |
| **资金流** | 净流入或小幅流出 | 大额净流出 | **连续净流出**，但流出额逐日递减 |
| **获利盘** | 仍有 40%+ | 快速下降 | **只剩个位数 %**（98% 套牢） |
| **均线** | 守住 MA20/MA60 | 跌破 MA20 | **跌破全部均线含 MA60/MA120** |
| **本质** | 主力还在，故意砸走浮筹 | 主力正在卖，还有货 | **主力已基本卖完，不需要再供量；下跌靠"没人接"自然滑落** |

**判读口诀**：
- **洗盘**是"量缩 + 重心不动 + 快速收回"；
- **派发**是"量放 + 重心下移 + 收在低位"；
- **失血**是"量缩 + 重心持续下移 + 一路阴跌" —— **量缩不能当利好读**。

### 派发确认的量化判据（比任何指标都硬）

> **「净流出累计 > 前次拉高时的净流入」= 派发确认，不必再找别的理由。**

示例股A 000001 实测：
- 10-20 单日净流入 **+8.00 亿**（超大单 +6.86 亿），把股价顶到 **27.18**，
  **未破 9/23 的 27.74 → 二次冲顶失败 = 双顶形态**
- 10-21 ~ 10-27 五日净流出 **−9.30 亿**（超大单 −6.38 亿）
- → 不但把那 8 亿反手卖掉，还多卖了 1.3 亿。**结构一走完，故事就结束了。**

配合看的两个佐证：
- **龙虎榜连续「N 家机构卖出」**（超声 10-19 / 10-21 / 10-26 三次 4 家机构卖出，
  10-26 机构席位合计净卖 −1.34 亿）
- **股东户数增加**（超声 9-30 达 99,749 户，较上期 **+4.02%**）→ 筹码从机构散到散户

### ⚠️ 「筹码真空区」的正确解读（别当成技术支撑）

超声模型显示 **14–17 元区间筹码仅 0.04%**。这是「**当前持仓成本在这一带几乎没有分布**」，
**不等于"这一带是支撑"**。它的真实含义是双面的：
- 好的一面：该区间**没有获利盘抛压**；
- 坏的一面：**也没有成本承接** —— 一旦上方防线（如 17.72）收盘跌破，
  缺乏"持股者不愿割"的成本托底，**容易一步下坠到下一个密集区**（超声 → 15.0–15.4 的 8 月大平台）。

**写法纪律**：报告里必须写清楚"下方无成本分布区"，而不是简化成"筹码真空=支撑"。
真正的支撑位要另取**前平台/前低/心理整数位**，不能从筹码模型里推。

### 上方套牢带的实战用法

超声实测：**23–28 元堆积 47.5% 筹码**（23–25 带单一最厚 27.35%）。
- 用户的成本 24.18 恰好压在最厚峰上 → **"回本"需要的不是反弹，是再来一轮炒作**
- 任何反弹到 23 元附近都会撞巨量解套盘 → **压力位要用筹码带定，不是用均线定**
- 判据沿用：**上方套牢占比 >30% → 突破需大量弹药**（超声 47.5%，远超阈值 = 别谈突破）
