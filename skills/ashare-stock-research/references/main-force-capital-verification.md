# 主力资金判定：五维交叉验证（接口 + 席位词典 + 实测对照）

用户会反复问这类问题：「如何精确判断主力资金走向」「换手率意味着什么」。
回答基调：**先破除"存在精确数据"的幻觉，再给出证据链方法**（用户是 INTJ / 第一性原理型，讲清"为什么不能"比给一堆指标更受用）。

---

## 0. 核心认知（先讲这段）

所有软件的「主力资金净流入」都是**推算值**，不是事实：

```
东财口径：超大单 ≥100万 / 大单 20-100万 / 中单 4-20万 / 小单 <4万
主力净额 = (大单+超大单)的主动买 − 主动卖      # 主动买按成交价贴近买一/卖一判定
```

三个致命缺陷：
1. **金额 ≠ 身份**——一笔1000万可能是机构建仓，也可能是一个大户一次下单
2. **主力会拆单**——1亿拆成1000笔10万，算法显示成"散户在买"
3. **主力会对倒**——自买自卖制造"大单流入"

→ 结论：它是**弱信号（★★★☆☆）**，只能当线索；结论必须由**不可造假的官方数据**给出。

### 证据金字塔

| 层级 | 数据 | 来源 | 可信度 | 能造假 |
|---|---|---|---|---|
| Ⅰ 硬 | **龙虎榜席位** | 交易所 | ★★★★★ | 不能 |
| Ⅰ 硬 | **股东户数** | 上市公司 | ★★★★☆ | 不能（滞后） |
| Ⅰ 硬 | 大宗交易 | 交易所 | ★★★★☆ | 不能 |
| Ⅰ 硬 | 十大流通股东 | 季报 | ★★★★☆ | 不能（滞后1-3月） |
| Ⅰ 硬 | 融资余额 | 交易所 | ★★★★☆ | 不能（T+1） |
| Ⅱ 推算 | 主力资金净流入 | 东财/同花顺 | ★★★☆☆ | **能** |
| Ⅲ 行为 | 盘口挂单/分时形态 | 行情 | ★★☆☆☆ | **极易** |

**方法一句话：用 Ⅰ 层校验 Ⅱ 层。**

### 席位性质词典（背下来）

| 席位名特征 | 身份 | 含义 |
|---|---|---|
| **"机构专用"** | 公募/保险/社保 | 真机构，中长线 |
| **"沪股通专用"/"深股通专用"** | 外资（北向） | ⚠️ **净额不能直接当"外资建仓"，必须先看买卖双向是否对等** —— 见下方 |
| **高盛/摩根/瑞银(中国)证券** | 外资券商自营 | 真外资 |
| 华鑫证券上海分公司 | 量化/游资 | 快进快出 |
| 国泰君安南京太平南路 | 知名游资 | 打板资金 |
| 中信证券上海溧阳路 | 知名游资 | 打板资金 |
| 银河证券绍兴 | 知名游资（赵老哥系） | 妖股推手 |
| **东方财富拉萨团结路/东环路** | **散户/量化聚集地** | ⚠️出现=散户在接盘 |
| 普通地方营业部 | 分散资金 | 参考价值低 |

### ⚠️ 「北向双向对等」= 量化对冲盘，不是建仓（2026-10-27 修正）

**只看净额会误判。必须同时看买入额和卖出额。**

示例股A 000001 / 2026-10-26 龙虎榜：
```
深股通专用：买 4.40 亿 / 卖 3.72 亿 / 净 +0.68 亿
```
净额看着是"外资在买"，但**买了 4.40 亿同时卖了 3.72 亿，双向几乎对等** ——
这是**量化/对冲盘在换手**，不是长线建仓。判据：

| 形态 | 性质 | 含义 |
|---|---|---|
| 买 ≫ 卖（卖 < 买的 20%） | 真建仓 | 有方向性，可跟 |
| 买 ≈ 卖（双向都在数亿量级，净额占比 <20%） | **量化/对冲/调仓** | **方向中性，别当利好读** |
| 卖 ≫ 买 | 真减仓 | 有方向性，偏空 |

**口诀：净额告诉你"往哪边偏"，买卖总额告诉你"这个偏是不是噪音"。**
净额占比 = |净额| ÷ (买+卖) —— **< 20% 一律视为噪音，不得作为结论依据。**

### 同日席位结构怎么读（机构卖 + 北向噪音 + 游资接 = 派发）

仍是超声 10-26（当日 −9.40%）：

| 席位 | 净额 | 判读 |
|---|---|---|
| 机构专用 ×4（3 卖 1 买） | **−1.34 亿** | 🔴 **真机构在派发**（连续三榜都是"4 家机构卖出"） |
| 深股通专用 | +0.68 亿（占比 8%） | ⚪ 噪音 |
| 国泰海通上海长宁区天山路 | +0.91 亿 | 🟡 游资接盘 |
| 中金上海分公司 | +0.51 亿 | 🟡 游资/量化接盘 |

**结论写法**：**机构在派发，接盘的是游资和量化噪音。** 这种结构里，"北向净买入"是**最不能当利好**的一条。

## 3. 股东户数 ★唯一能事后验证"筹码到了谁手里"

```python
GET .../get?reportName=RPT_HOLDERNUM_DET&columns=ALL&pageNumber=1&pageSize=6
    &filter=(SECURITY_CODE="601086")&sortColumns=END_DATE&sortTypes=-1&source=WEB&client=WEB
```
字段：`END_DATE` `HOLDER_NUM`(户数) `HOLDER_NUM_RATIO`(环比%) `AVG_HOLD_NUM`(户均持股)

```
户数减少 + 户均持股上升 = 筹码集中 = 主力吸筹
户数增加 + 户均持股下降 = 筹码分散 = 散户接盘 / 主力派发
```
⚠️ 更新时间不定（旬/季），是**验证工具不是预测工具**。

## 6. 换手率 × 主力资金 × 价格（六象限）

| 换手 | 主力资金 | 价格 | 本质 | 结论 |
|---|---|---|---|---|
| 高 | 净流入 | 涨 | 主力吸筹、散户交筹 | ✅ 可跟 |
| 高 | **净流出** | 涨 | **拉高派发、散户接盘** | 🚨 逃命 |
| 高 | 净流出 | 跌 | 出货+恐慌 | 🚨 逃命 |
| 高 | 净流入 | 跌 | 逆势承接/抄底 | 🟡 观察 |
| 低 | 净流入 | 涨 | 惜售 | ✅ 强（缺增量） |
| 低 | 净流出 | 跌 | 阴跌无接盘 | 🚨 无底洞 |

换手率分母用**流通股本 = 流通市值 ÷ 现价**（只有全流通股才等于总股本）。

## 7. 假资金流的 5 个特征

1. 成交额巨大但股价不动 → 对倒制造活跃
2. 主力净流入但股价下跌 → 数据失真/大单被动接盘
3. **14:50 后突然放量拉升** → 做高收盘价，次日诱多
4. **小单持续净流入 + 大单净流出** → 拆单派发（最隐蔽）
5. 龙虎榜买卖席位高度重合 → 对倒

## 8. 实测对照案例（2026-09-07，同一天、同一市场、相反答案）

这是本方法论最好的教学案例，可直接复用到报告里。

### 景旺电子 603228 —— 真机构建仓

龙虎榜买入前五（净买 **+10.36亿**）：

| 席位 | 买入 |
|---|---|
| 沪股通专用 | 8.76亿 |
| 机构专用 | 4.98亿 |
| 机构专用 | 3.82亿 |
| 机构专用 | 3.70亿 |
| 高盛(中国)证券上海浦东世纪大道 | 3.54亿 |

→ 3 个机构专用 + 沪股通 + 高盛。软件资金流也同向（9/4 +26.2亿 → 9/7 +16.0亿 → 9/8 +6.4亿 → 9/9 +3.8亿，连续4日净流入但**力度递减**）。

### 国芳集团 601086 —— 游资接力 + 主力派发

龙虎榜买入前五（净买仅 **+0.35亿**）：

| 席位 | 买入 |
|---|---|
| 国泰海通证券总部 | 0.42亿 |
| 国泰海通南京太平南路 | 0.41亿 |
| 沪股通专用 | 0.37亿 |
| 国信证券浙江互联网分公司 | 0.36亿 |
| 中金上海分公司 | 0.31亿 |

→ 零机构专用席位，全是游资，单席 0.3-0.4亿。

**关键对比：软件显示"主力净流入 5.14亿"，而龙虎榜官方数据前五席位合计只净买 0.35亿 —— 差 15 倍。** 这就是"推算值"与"官方硬数据"的差距，讲给用户看极有说服力。

股东户数验证（8/20→8/31，正是连续涨停期）：
```
08-20  39,499  (-10.78%)  ← 主力吸筹
08-31  41,559  (+5.22%)   ← 散户涌入接盘（+2060户）
```

资金流验证：
```
09-03 涨停  +2.96亿
09-04 +3.85%  -0.87亿 (超大单 -1.49亿)
09-07 涨停  +5.14亿
09-08 +7.61%  -0.41亿 (超大单 -1.14亿)  ← 涨停当天超大单净流出，典型涨停出货
09-09 -0.47%  -0.62亿
```
配合换手率（9个交易日累计 80.6%）与 9/9 首阴 → **四维同向指向派发**。

### 结论模板

> 判断主力资金的"精确性"，不来自某个更高级的指标，而来自**用不可造假的数据去校验可造假的指标**。
> 龙虎榜席位 + 股东户数，是 A 股唯一两个能让主力"留下指纹"的地方；其他所有软件资金流都只是线索。
