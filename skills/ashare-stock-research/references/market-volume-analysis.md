# 大盘/板块量能分析框架（成交量为切入点看趋势）

用户2026-09-10 提问："如何深入理解整个大盘成交量看大盘趋势，如竞价后缩量或者放量相关的，拿科技来看"。
本文件是该问题的完整答法：框架 + 阈值 + 实盘案例。数据全部来自 `references/data-sources.md` 里的腾讯接口。

## 0. 第一性原理：成交量 = 分歧的量
价格是**共识**，成交量是**分歧强度**。量能脱离"位置+方向"没有意义。量增=分歧加大（多空都在换手），量缩=分歧收敛（无人愿在现价成交或筹码锁定）。

| 位置 | 量能 | 含义 | 实操 |
|---|---|---|---|
| 高位 | 放量涨 | 接力换手/出货 | 危险，看换手率 |
| 高位 | 缩量涨 | 筹码锁定 | 健康但无新资金 |
| 低位 | 放量跌 | 恐慌出清/吸筹 | 可能见底 |
| 低位 | 缩量跌 | 无人接盘 | 阴跌最难受 |
| 上涨中 | 缩量涨 | **量价背离** | 随时回调 |

## 1. 三层阅读法（顺序不能反）
```
Layer 1  集合竞价(9:15-9:25)   → 隔夜情绪温度计（意愿）
Layer 2  开盘30分钟(9:30-10:00) → 主力真实态度（★最关键）
Layer 3  全天量 ÷ 均量         → 趋势是否成立（确认）
```
**核心命题：竞价可以骗人，开盘30分钟骗不了人。** 竞价只花钱报单，开盘30分钟要真金白银成交。

## 2. 四个对比坐标（缺一个都读不准）
| 坐标 | 算法 | 回答什么 |
|---|---|---|
| ① 时间轴 | 今日量 ÷ 5日/20日/60日均量 | 绝对量能多少 |
| ② 结构轴 | 板块成交额 ÷ 两市总成交额 | 资金在不在这个方向 |
| ③ 节奏轴 | 今日同时段 ÷ 昨日同时段 | 边际变强还是变弱 |
| ④ 量价轴 | 涨跌幅 × 量能变化 | 放量是进攻还是撤退 |

只看①就会永远想不通"为什么放量了还跌"。

## 3. 竞价强度判定阈值（A股经验值）
```
竞价额 ÷ 前一日全天成交额：
  < 0.5%       缩量（观望）
  0.5% ~ 1.0%  正常区间（主流）
  1.0% ~ 1.5%  放量（情绪亢奋）
  > 2.0%       异常放量（有事件，必查消息）

竞价额环比昨日竞价：±20% 内正常；> +30% = 隔夜有增量信息（异常信号）
```

## 4. 开盘30分钟黄金判定 + 三种组合
```
前30分钟成交额 ÷ 昨日全天成交额：
  > 40%   超高换手 = 分歧极大，多半冲高回落
  30~40%  正常活跃
  < 25%   清淡（消息真空/观望）
```
| 竞价 | 开盘30min | 判读 |
|---|---|---|
| 放量 | 放量 | ✅ 真放量，趋势可信 |
| 放量 | **缩量** | ❌ **假放量/诱多**（核心杀招） |
| 缩量 | 放量 | ⚠️ 承接换手，可能洗盘，看价格是否守 |
| 缩量 | 缩量 | 地量，等变盘信号 |

## 5. 日内节奏形态
```
前高后低（早盘量占比>40%）→ 抛压重、分歧大，反弹即减
前低后高（尾盘量放大）      → 资金尾盘进场(过夜意愿)或尾盘杀跌
均匀分布                   → 健康趋势
单点爆量（某分钟异常）      → 事件/机构调仓（指数调仓、大宗）
尾盘(14:30-15:00)占比：正常 12~18%；>25% 属异常
```

## 6. 盘中实操 SOP（贴屏幕用）
| 时间 | 动作 | 判定 |
|---|---|---|
| 09:15-09:25 | 看竞价额、高开/低开、期货 | 竞价额同比 >+30% 开始警惕 |
| 09:25 | 记录各指数竞价额+开盘涨跌 | 高开 >+1% 且科技 → 高度警惕 |
| 09:30-09:35 | 首根5分钟量 vs 昨日同时段 | 缩量=高开不可持续 |
| **09:30-10:00** | **核心窗口** | 前30min ≥ 昨日全天35% 才叫有量 |
| 10:00-10:30 | 方向选择期 | 放量突破=真，缩量回落=假 |
| 11:00-11:30 | 半日量检验 | 半日/昨日全天 >55% = 放量 |
| 14:00-14:30 | 尾盘前主力动向 | 拉抬 or 出货 |
| 14:30-15:00 | 尾盘量占比 | >25% 异常，看方向 |

## 7. 科技板块专用补充
- 三条指数同看，避免单一失真：**中证TMT（大盘科技）+ 科创芯片（硬科技）+ 创业板指（成长）**
- **科技占两市成交额比重**是"资金在不在科技"的最快指标，比看涨跌准得多
- 科技量能是爆发型：突破日常量 = 均量 **1.5~2 倍**；退潮缩到均量 **60~70%** 才算地量
- **地量 ≠ 见底**，必须配合价格止跌才有效
- 科技缩量而大盘放量 → 资金"跷跷板"切向其他方向（案例里切向煤炭/顺周期）

## 10. 盘口 / 订单流分析（2026-10-09 补充）

用户问"盘中如何看订单部分析涨跌"时的答法：五档 + 委比 + 内外盘 + 大单 + 逐笔。
东财入口：个股页「盘口」区（五档/委比/内外盘）、「主力」标签（资金流/大单统计）、分时图点成交量柱看该分钟成交明细。

| 指标 | 口径 | 判读 |
|---|---|---|
| 委比 | (买五档量−卖五档量)÷两者和×100% | >+30% 买强 / <−30% 卖强；**但挂单可撤，最易骗人** |
| **内外盘** | 外盘=以卖一价成交(主动买)；内盘=以买一价成交(主动卖) | 外>内偏强；**外>内却不涨 = 大单托着出货**（最阴场景） |
| 大单档位 | 东财：超大单>100万、大单20-100万、中小单<20万 | 主力净流入=超大单+大单；低位流入=吸筹，**高位流出=派发** |
| 逐笔成交 | 分时图→点量柱→该分钟明细 | 看**大单成交的价位**：低位吃货=吸筹，高位出货=派发 |
| 每笔均量 | 成交额÷成交笔数 | 均量大 = 大资金在场 |

**四种盘口陷阱**：① 假挂单诱多（看撤单率）② 压单测试（大单被吃掉=真买盘，自己撤=虚张声势）③ 对倒放量（量放大但价不动）④ 尾盘拉抬（14:55 拉高做收盘价，不代表真实强度）。

**口诀：挂单是「意愿」，成交是「事实」** —— 识破靠三条：撤单率、成交连续度、每笔均量。

### 实盘实证：示例股G 000003 近5日量能拆解（数据截止 2026-10-08）
| 日期 | 竞价额 | 前30min | 下午 | 全天 | 竞价/前日 | 前30min/全天 |
|---|---|---|---|---|---|---|
| 09/24 | 0.11亿 | 2.05亿 | 1.55亿 | 4.68亿 | — | 43.8% |
| 09/28 | 0.04亿 | 1.23亿 | 1.00亿 | 3.07亿 | 0.81% | 40.2% |
| 09/29 | 0.02亿 | 1.03亿 | 1.17亿 | 2.93亿 | 0.53% | 35.0% |
| 09/30 | 0.03亿 | 1.28亿 | 0.91亿 | 3.25亿 | 1.10% | 39.4% |
| 10/08 | 0.02亿 | 0.98亿 | 0.73亿 | 2.43亿 | 0.72% | **40.4%** |

读数：前30min 占比连续≈40% → **高点在早盘(9:30-10:00)**；全天量 4.68→2.43亿、下午量 1.55→0.73亿 → **量价齐跌、无人接盘的阴跌**（区别于恐慌放量出清）。10/8 实况：开 3.35(高开+2.4%)→收 3.23(−1.22%)，**完全验证"冲高回落"**。
→ 派生结论：**"早盘冲高、全天阴跌"型个股，做 T 的卖点窗口只有 9:30-10:00**。

### 做 T 可行性判据（2026-10-09 补充）
问"能不能每日做 T"时，先过四关再谈点位：
1. **振幅**：近 10 日平均振幅 ≥3% 才有空间（瑞康 6.08%，够）
2. **趋势**：下跌趋势做 T = "捡钢镚"，胜率 <50%；**趋势方向比振幅重要**
3. **底仓**：A股 T+1，**没有底仓就不存在做 T**（为做 T 建仓 = 用隔夜风险换日内 2-3%）
4. **成本换算**（要算给用户看）：半仓做一次成功 T ≈ 降成本 1.5% 左右（例：成本 3.66、1000 股，3.29 卖 500 / 3.17 买回 = 赚 60 元 → 成本 3.60）。
   要降 5% 需 **5 次连续成功**，下跌趋势里概率很低。

**四条铁律**：① 卖了绝不追高 ② 买回必须低于卖价 ③ 做 T 仓位 ≤ 底仓 1/2 ④ **连续 2 次失败就停手**。

### 集合竞价挂单时机（用户问"是否该开盘后再挂"）
- 8:30–9:14 挂单 = 9:15 才报送，**与 9:14 挂无异**；9:15–9:20 可挂可撤（**最灵活的窗口**）；**9:20–9:25 不能撤单**。
- **限价单不会吃暗亏**（价格优先：卖单挂 3.33，若开盘 3.40 则成交在 3.40；买单挂 3.18，若开盘 3.10 则成交在 3.10）。
- 真实风险是「**卖了不跌 → T 飞**」和「9:20 后无法改单」，**不是价格吃亏**。
- 卖单**分两档**（如 3.29 + 3.33）比单档挂更容易成交。
