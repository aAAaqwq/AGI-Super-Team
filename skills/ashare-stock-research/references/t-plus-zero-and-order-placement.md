# 做 T（日内回转）与挂单时机 — A股实操框架

触发：用户问「能不能做 T」「今日怎么做」「该不该现在挂单」「X 卖 / Y 买回」「挂单是不是要等开盘后」，
或给出**底仓成本价**要求降成本方案。

⚠️ 铁律：**用户给出的成本价必须先换算成浮亏 + 止损线（成本×0.95）并明确说出「已破/未破」**。
用户自定纪律是硬约束，不要用「还有支撑」之类话术软化。若已破线，**必须先点破这一点**，
再谈做 T —— 否则等于默许用户绕过自己的纪律。

---

## 一、集合竞价规则（回答「什么时候挂单」的唯一依据）

| 时间 | 可挂单 | 可撤单 |
|---|---|---|
| 开盘前任意时刻（如 8:30） | 券商**暂存**，**9:15 才统一报送** | — |
| **9:15–9:20** | ✅ | ✅ **可撤（最灵活，唯一能根据竞价调整的窗口）** |
| **9:20–9:25** | ✅ | ❌ **不可撤** |
| 9:25 | — | 撮合出开盘价 |
| 9:25–9:30 | 多数券商不接受 | ❌ |
| 9:30 后（连续竞价） | ✅ | ✅ |

**结论**：盘前 8:30 挂 = 9:14 挂，**完全等价**（都是 9:15 报送）。
所以「现在挂会不会出问题」的**正确答法是**：这个时段本身不会，真正的风险在 9:20 之后撤不掉。

## 二、限价单不会吃暗亏（消除用户最常见误解）

集合竞价是**价格优先**，限价单只会成交在「不差于你报价」的位置：

| 你的单 | 竞价情况 | 实际成交 | 结果 |
|---|---|---|---|
| 卖出 3.33 | 开盘 **3.40**（高开） | **成交在 3.40** | ✅ 卖得更高 |
| 卖出 3.33 | 开盘 3.28（低于挂价） | 不成交，进连续竞价 | 挂着等，无害 |
| 买入 3.18 | 开盘 **3.10**（低开） | **成交在 3.10** | ✅ 买得更便宜 |
| 买入 3.18 | 开盘 3.28（高于挂价） | 不成交 | 无害 |

**最差 = 按自己报价成交，不会更差。**

## 三、三个真实风险（这才是该提醒用户的）

1. **9:20–9:25 撤不了单** → 9:20 前挂完就不能改；观察窗口只有 9:15–9:20。
2. **做 T 的固有风险：卖了不跌 → T 飞**（丢筹码，被迫追高买回）。与挂单时机无关。
3. **今天可能到不了目标卖价** → 若外围偏弱/个股弱势，「先冲高」这一步可能不给。**判据：目标卖价需要的涨幅 vs 板块环境。**

## 四、做 T 的三个前提（缺一不可）

1. **必须有底仓** —— A股 T+1，当天买的当天不能卖。**空仓的人为了做 T 建仓 = 用隔夜风险换 2-3% 日内波动，性价比极差 → 明确劝阻。**
2. **有够用的振幅** —— 做 T 至少需要 2–3% 空间（扣双边手续费约 0.15%）。看近 10 日平均振幅。
3. **趋势不能单边向下** —— 下跌趋势做 T 胜率 < 50%，属「下跌趋势里捡钢镚」。

## 五、做 T 降成本数学（必须先算给用户看，别让他以为能轻松回本）

以 1000 股、成本 C、半仓做 T 为例：

```
3.29 卖 500 股  → +1,645 元
3.17 买回 500 股 → −1,585 元
净赚 60 元 → 剩余成本 = (C×1000 − 60) / 1000 = C − 0.06
```

**一次成功的半仓 T ≈ 降成本 0.06 元（约 1.6%）。要降 5% 需约 5 次连续做对。**
把这张表直接给用户，让他明白做 T 是**缓慢降成本**，不是解套方案：

| 目标成本 | 需成功做 T 次数 |
|---|---|
| 降 1.6% | 1 次 |
| 降 5% | **5 次** |
| 降 10% | 9 次 |

## 五·补、⭐⭐ 先算「值不值得做」：VWAP 中枢 + 净收益门槛（2026-11-17 实测）

### 5b.1 昨日 VWAP 是做 T 的中枢（必须先算出来）

T 的买卖点不该拍脑袋，用**昨日均价（VWAP）**当中枢：现价在 VWAP 上方偏强 → 优先「反 T」；
在下方偏弱 → 优先「正 T 或不做」。

腾讯行情直接能算，**但有单位坑（本会话踩过，算出 1746.16 这种离谱值）**：

```python
# f[6] = 成交量(手)，f[37] = 成交额(万元)
# 正确：VWAP = 成交额(元) / 成交量(股) = (f[37]*10000) / (f[6]*100)
vwap = (float(f[37]) * 10000) / (float(f[6]) * 100)
# 超声实测：f[6]=83.9万手、f[37]=14.65亿 → 17.44 ✅
# 漏掉最后的 /100 会得到 1746.16 ❌
```

**用法**：昨日收盘 vs 昨日 VWAP 的差值 = 「尾盘强弱」。
收盘低于 VWAP（超声 −1.15%、博纳 −1.38%）= 尾盘走弱 → 次日优先做反 T。

### 5b.2 净收益门槛：算完发现不值得，就明确说「不做」

```python
fee_rate = 0.0003*2 + 0.0005      # 佣金万三双向 + 卖出印花税万五 ≈ 0.11%
net = shares * price * pct/100 - shares * price * fee_rate
```

（判断「要不要做」用含滑点的 0.15%；算实际净收益用 0.11%。）

| 标的 | 可做股数 | 赚 3% 的净收益 | 结论 |
|---|---|---|---|
| 200 股 × 17.26 | 200 | **+100 元** | ✅ 值得 |
| 300 股 × 6.32 | 300 | +55 元 | 🟡 勉强 |
| 100 股 × 3.88 | 100 | **+11 元** | ❌ 不做 |
| 400 股 ETF（10 日均振幅 2.21%） | 200 | **+10 元** | ❌ 不做 |

**➜ 硬门槛：按「能吃到振幅的 1/3」估，净收益 < 30 元就不做** —— 那不是做 T，是给券商交手续费。
小仓位（<200 股）、小振幅标的（10 日均振幅 < 3%）直接说「不做」，别硬凑方案。

### 5b.3 正 T / 反 T 怎么选（按外部变量，不是按感觉）

| 情形 | 选 | 理由 |
|---|---|---|
| 昨日收盘 < 昨日 VWAP（尾盘弱） | **反 T**（先卖后买） | 先拿回现金，跌了再买回；不跌只少赚，不会多亏 |
| 外围/板块有利空（例：美股 AMD −5.58%、英伟达 −4.12% 压 PCB） | **只做反 T，禁正 T** | 正 T 容易买在半山腰 |
| 低开 >3% 且 30 分钟不破低点 | **正 T** | 超跌反弹时低吸最划算 |
| 高开 >2% | **纯减仓，不买回** | 高开是走人机会，不是做 T 机会 |

**纪律：破 MA10 一律不买回** —— 那是接下跌中的刀，该部分仓位按减仓处理，不按做 T 处理。
（11/17 博纳 MA10=6.27、超声 MA10=17.735 就是当天的「不买回线」。）

### 5b.4 竞价结束后给方案的标准条件表

用户会要求「竞价结束后告诉我分别怎么 T」。**9:26 拿到竞价开盘价后按档直接出方案**，不给模糊区间：

| 竞价情况 | 方向 | 动作模板 |
|---|---|---|
| 低开 >3% | 正 T | 低点买 N 股 → 反弹到 VWAP/MA5 卖 N 股 |
| 平开（±2%） | 反 T | 反抽 昨日VWAP~MA10 卖 N 股 → 回落 昨日低点上方买回 |
| 高开 >2% | 减仓 | 卖 N 股，**不买回** |
| 破 MA10 / 破昨日低 | 减仓 | 卖 N 股，不买回 |

每只必须写齐：`卖点（精确到分）/ 买点 / 股数 ≤ 可用股数 2/3 / 预期净收益（已扣费）/ 放弃条件 / 破位不买回的价位`，
并提醒「9:26 只是竞价数据，9:35 再确认一次」。
可复用脚本：`scripts/auction_t.py`（本 skill 自带；读 `positions.json`，输出竞价开盘价/竞价量/量比/当日VWAP/MA5-10-20/近10日振幅/净收益门槛判定）。
可直接挂 cron：`schedule=09:26, script=auction_t.py` 一次性触发，输出交给 agent 出方案。

## 六、分档挂单方案 + 四条铁律

**为什么要分档**：个股日内高点出现的时点不确定，分档保证「至少成交一半」，避免「差一分钱没成交、全天白等」。

| 侧 | 档位 | 说明 |
|---|---|---|
| 卖 | 目标价 −1.5% 与目标价 | 如 3.29 / 3.33，各半 |
| 买 | 目标价 与 目标价 −3% | 如 3.18 / 3.13 |

**四条铁律**（违反任一即停手）：
1. **卖了绝不追高** —— 宁可丢筹码。
2. **买回必须比卖价低** —— 同价买回 = 白交手续费。
3. **做 T 仓位 ≤ 底仓 1/2** —— 避免「T 飞了」全仓踏空。
4. **连续 2 次做错就停** —— 说明环境不适配，继续做就是送钱。

## 七、卖点窗口怎么定：先找个股的「日内形态规律」

**动作**：拉近 3–5 日分时，算**每日「前 30 分钟成交额 ÷ 当日全天成交额」**。

- 该比值**连续多日 ≥ 40%** ⇒ 该股是「**早盘冲高、全天阴跌**」结构
  ⇒ **做 T 的卖点窗口只有 9:30–10:00**，错过基本没第二次机会。

示例股G 2026-09 ~ 10 月实测：前30min占比连续 4 天 ≈ 40%，
对应形态「开 3.35（全天最高 3.38）→ 收 3.23」，高点确实只在早盘。

## 八、交付格式

① 先算处境（成本 / 浮亏 / 止损线是否已破 / 回本需涨多少）
→ ② 做 T 降成本数学
→ ③ 今日卖点/买点具体价位 + 分档
→ ④ 四条铁律
→ ⑤ 更优先的建议（反抽减仓 vs 死扛）+ 最后防线
→ ⑥ 三情景（开盘高/平/低）分别怎么应对
→ ⑦ 盯盘时间表 → ⑧ 风险提示

**重要**：做 T 是「技术手段」，**不是「解题答案」**。若用户已深度被套 + 趋势向下，
**应把「反抽减仓」排在「做 T」之前** —— 明确写出优先级，不要让做 T 掩盖该止损的事实。

## 九、实证：示例股G 2026-10-09

- 用户底仓成本 **3.66**，10/8 收 **3.23** → 浮亏 **−11.75%**，止损线 3.477 **早在 9/23 就破**（第 11 个交易日）。
- 成本 3.66 对应 9/22 天量顶（当日 3.56–3.95）区间 —— 即「最高区域接货」。
- 回本需 **+13.3%** → 明确告知不是做 T 能解决的量级。
- 建议顺序：**① 反抽 3.29–3.33 先减 1/3~1/2 仓位 → ② 剩余做 T（3.29/3.33 卖，3.18/3.13 买） → ③ 破 MA60（3.086）无条件清仓**。
