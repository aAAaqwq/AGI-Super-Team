# 盘中判断"主力是否还在"的信号框架

用户反复问的短线问题（妖股/题材持仓）：盘中/盘后判断主力还在不在。
A股主力 = 超大单/大单资金；散户 = 中单/小单。核心口诀：**看大不看小**。

## 一、最硬信号：分时均价线（黄线）= 主力当日成本线
- 股价**始终在均价线上方**、回踩不破 → 主力在场/护盘
- 股价**贴着均价线缩量横盘** → 洗盘，主力未走
- 股价**跌破均价线 30 分钟不回** → 主力弃守/出货（最常用出场触发）
- 放量跌破均价线 + 反弹无力 → 减仓/清仓信号

## 二、盘口语言（L2 或大单盯盘）
- 买一/买二大单**反复挂撤**（挂上又撤）→ 假托诱多，出货嫌疑
- 卖盘大单被**一口口吃掉**、买盘不撤 → 真买
- **大单卖出但股价不跌** → 有承接换手，未必出货
- 关键位（昨收/整数关/均价线）反复垫大买单 → 护盘
- 大单成交但**股价不涨**（放量滞涨）→ 对倒做量，出货准备
- 同手数大单（999/500 等）买卖对出 → 对倒特征

## 三、资金流数据（东财 push2his，每 5 分钟更新）
- 超大单持续**净流入** → 真实买入
- 超大单净流出 + 小单净流入 → **主力派发、散户接盘**（最危险形态）
- 主力净流入但股价滞涨 → 分歧，可能拉高出货
- 结论只看超大单+大单方向，忽略中单小单

## 四、换手率 × 量能
- 高位**放量滞涨** → 走（多空巨大分歧，出货嫌疑）
- 高位**缩量回调** → 主力未跑，可拿
- 高位**放量下杀** → 主力夺路而逃，快跑
- **缩量跌停** = 主力没跑干净（可能自救）；**放量跌停** = 主力夺路而逃（如沃特 9/3）
- 换手 >30% 且价不涨 = 巨量分歧，见顶概率大

## 五、龙虎榜（盘后/异动辅助）
- 买方席位全是知名游资（拉萨/益田路等）→ 游资接力，题材还在
- 机构专用席位净卖出 → 主力撤
- 买榜游资与昨日卖榜游资重合 → 一日游

## 六、三个"假主力"出货信号（看到就警惕）
1. 放量但价格不动（对倒出货）
2. 超大单流出 + 小单流入（散户接盘）
3. 跌破均价线 30 分钟不回（弃守）

## 七、公司公告级利空（最强信号，2026-09-08 万向德农实测）
妖股大涨后公司**自己发公告降温**——"股票交易异常波动""股价严重偏离基本面和合理估值区间""产品价格处于低位、业绩承压" → 视同最强卖出信号，次日大概率低开；盘后看到此类公告，建议明早开盘优先处理该持仓，反弹即走、不补仓。
