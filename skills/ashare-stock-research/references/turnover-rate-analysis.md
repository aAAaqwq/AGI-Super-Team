# 换手率分析框架（本质 → 计算 → 判定 → 实证）

用户是短线交易者，常问"换手本质是什么/意味着什么"、以及个股高换手能不能跟。
回答必须**先给本质定义，再给可执行阈值表，最后配一个他自己的票的实证**——纯理论会被认为没有价值。

---

## 一、本质定义（第一性原理）

```
换手率 = 成交量 ÷ 流通股本 × 100%
       = 流通筹码在一段时间内"易主"的比例
```

**它不是"有多少钱进来"，也不是"多少人关注"，而是筹码转手的强度。**

定义里两件事关键：
1. **分母是流通盘** → 它是归一化比例，可跨股票、跨时期比较（成交量做不到）
2. **每笔成交同时含一个买方和一个卖方** → 换手率天然是**分歧的度量**，不是资金的度量

### 三层含义（由表及里）
| 层 | 含义 | 实战意义 |
|---|---|---|
| ① 流动性 | 股票的变现速度 | 高换手=随时能跑；低换手=想跑卖不掉（高位的"纸上富贵"） |
| ② 分歧强度 | 归一化后的多空分歧烈度 | 承接"成交量=分歧的量"，换手率=分歧的**相对强度** |
| ③ 筹码结构 | 筹码换到了谁手里 | ★最重要：**决定后续涨跌的是"转给了谁"** |

> 口诀：**换手率告诉你"有多热闹"，主力资金流告诉你"谁在主导"。只看一个，必踩坑。**

---

## 二、计算口径（务必和行情口径对齐）

- **直接取**：腾讯实时行情 `[38]` = 换手%
- **自算**（需要历史换手序列时）：
  ```python
  流通股本(亿股) = 流通市值(亿) ÷ 现价       # 或 总市值[45]÷现价（全流通时等价）
  换手率(%) = 成交量(手) × 100 ÷ (流通股本 × 1e8) × 100
  ```
  实测校验：国芳集团 99.10亿市值 ÷ 14.88 = 6.66亿股；9/9 成交 90.8万手 → 90.8e4×100/6.66e8 = **13.63%** ✓ 与行情完全一致
- 更精确应用**自由流通股本**（剔除大股东锁定）。家族控股股（如国芳）若大股东持 60%+，13.63% 的"流通换手"相对真正可交易的 40% 就是 **34%** → 筹码已彻底打散。

## 三、绝对标尺（必须结合流通盘）

| 换手率 | 状态 | 典型场景 |
|---|---|---|
| <1% | 极度冷清 | 僵尸股、无人问津 |
| 1–3% | 正常 | 沪深300成分股日常 |
| 3–5% | 活跃 | 有资金关注 |
| 5–10% | 高度活跃 | 题材股启动期 |
| 10–20% | 极度博弈 | 妖股、次新股 |
| >20% | 筹码失控 | 击鼓传花，接盘风险爆炸 |

**盘子大小决定基准（同一个 5% 含义完全不同）：**
- 大盘股（1000亿+）：3–5% 已是"活跃"，因为 1% 换手 = 10亿资金
- 小盘股（<100亿）：10%+ 是常态
- 次新股开板：30–50% 常见

**关键对照（2026-09-09 实测）：**

| 标的 | 换手率 | 成交额 | 市值 |
|---|---|---|---|
| 景旺电子 | 4.15% | **45.07亿** | 1097亿 |
| 国芳集团 | 13.63% | 13.16亿 | 99亿 |

→ 景旺换手只有国芳的 1/3，成交额却是国芳的 **3.4 倍**。
→ **换手率 = 筹码活跃度；成交额 = 资金真金白银。两者必须一起看。**

## 四、⚠️ 核心认知：换手率本身没有方向

**这是多数人亏钱的地方。同样是 10% 换手，故事可以完全相反。**

| 换手 | 主力资金 | 价格 | 本质 | 结论 |
|---|---|---|---|---|
| 高 | **净流入** | 涨 | 主力吸筹，散户交出筹码 | ✅ 可跟 |
| 高 | **净流出** | 涨 | **主力拉高派发，散户接盘** | 🚨 逃命 |
| 高 | 净流出 | 跌 | 主力出货 + 恐慌 | 🚨 逃命 |
| 高 | 净流入 | 跌 | 主力逆势承接/抄底 | 🟡 观察 |
| 低 | 净流入 | 涨 | 筹码锁定、惜售 | ✅ 强（但缺增量） |
| 低 | 净流出 | 跌 | 阴跌，无人接盘 | 🚨 无底洞 |

**判定必须三维合看：换手率 × 主力资金 × 价格。**

## 五、实战三用法

### 1️⃣ 区分"洗盘"和"出货"（最常用）
```
高位调整 + 缩量（换手率下降）→ 洗盘：主力没卖，只是没人接
高位调整 + 放量（换手率上升）→ 出货：主力正在卖
```
**量能的方向比价格的方向更早说话。**

### 2️⃣ 识别顶部的"换手衰减"
```
阶段1  涨停 + 换手 <3%        → 一字板，筹码锁死（最强）
阶段2  涨停 + 换手 8–15%      → 开板放量，分歧出现
阶段3  天量换手 20%+ 不涨停    → 筹码大换手，主力派发
阶段4  换手逐日下降 + 价格滞涨 → 顶部确认 ★
```
**阶段4 反直觉之处**：换手率下降**不代表抛压减轻**，而是**连接盘的人都没有了**。

### 3️⃣ 抓"地量地价"
换手率长期极低（大盘股<1%、小盘股<2%）= 筹码沉淀、无人关注。
一旦**换手率突然跳升 3–5 倍**，往往是新行情起点（筹码锁死，少量资金即可撬动）。

## 六、三个必须避开的陷阱

| 陷阱 | 说明 |
|---|---|
| ① 换手率 ≠ 资金量 | 同一笔钱反复对倒（左手卖右手买）也能做出高换手 → 必须用**主力净额**过滤 |
| ② 流通盘变化会失真 | 解禁、增发、回购注销后，换手率不可前后直接比 |
| ③ 环境基准漂移 | 牛市整体换手是熊市 2–3 倍 → **跟自己的近20日平均换手比，不要跟别的股票比绝对值** |

## 七、实证：国芳集团 601086（2026-08-28 ~ 09-09）

**九个交易日累计换手 80.6%** → 整个流通盘几乎换了一遍主人。

| 日期 | 收盘 | 换手率 | 主力净额 | 形态 |
|---|---|---|---|---|
| 08-28 | 8.34 | 2.70% | +1.11亿 | 启动 |
| 08-31 | 9.17 | 3.81% | +1.92亿 | 涨停 |
| 09-01 | 10.09 | 4.54% | +1.04亿 | 涨停 |
| 09-02 | 11.10 | **0.87%** | +0.34亿 | 一字板（锁死）|
| 09-03 | 12.21 | 8.77% | **+2.96亿** | 涨停 |
| 09-04 | 12.65 | **19.60%** | **−0.87亿** ⚠️ | 天量换手 |
| 09-07 | 13.92 | 8.88% | **+5.14亿** | 涨停 |
| 09-08 | 14.95 | **17.84%** | **−0.41亿**（超大单 −1.14亿）| 涨停 |
| 09-09 | 14.88 | **13.63%** | **−0.62亿** | **首阴** |

**三个致命读数：**
1. **9/4 换手 19.6% 创天量，主力却净流出 0.87亿** → 换手暴增 ≠ 主力进场，可能是主力把筹码倒给散户
2. **9/8 涨停当天超大单净流出 1.14亿** → 拉涨停是为了出货
3. **9/8→9/9 换手 17.84%→13.63% 递减、价格滞涨** → 接力资金枯竭

> **"高换手"背后有两种相反的故事：A 主力建仓（后面还有大行情）/ B 主力派发（后面连续跌停）。光看换手率永远分不清，叠加主力资金流立刻清晰。**

---

## 八、一句话总结

> 换手率 = 筹码在一段时间内转手的比例，本质是 **"分歧的强度" + "筹码的流动性"**。
> 它**本身没有方向**，方向由"谁在买、谁在卖"决定：
> - 高换手 + 主力流入 + 上涨 = **健康换手**（散户→主力）
> - 高换手 + 主力流出 + 上涨 = **危险换手**（主力→散户）★
> - 低换手 + 上涨 = 惜售（强，但缺增量）
> - 低换手 + 下跌 = 阴跌无底
