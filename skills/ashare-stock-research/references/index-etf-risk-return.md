# 宽基 ETF / 指数：风险收益时间比评估法

**用途**：用户问「现在能不能买宽基 ETF / 有没有推荐 / 510300 的风险收益时间比如何 / 这个位置值不值得买」时走这里。
**核心**：**"跌到新低" ≠ "便宜"，"便宜" ≠ "该买"**。必须用**历史条件赔率**（同样的回撤深度/趋势状态下，历史上买入后 1 年胜率多少）来定价，而不是凭"跌了很多"下结论。

---

## 一、四步流程（缺一步结论就会错）

| 步 | 做什么 | 输出 |
|---|---|---|
| **① 定位** | 距峰值回撤多少？在多少个交易日的区间分位？ | **回撤档位**（决定赔率，见 §3） |
| **② 估值** | PE / PB | 安全边际 |
| **③ 趋势** | 是否站上周 MA20 / MA30 / MA52 | **右侧确认信号** |
| **④ 条件回测** | 历史上"同回撤档位 + 同趋势状态"买入的 1/3/6/12 个月胜率 | **可直接引用的概率** |

⚠️ **只做 ①②就下"可以分批买"的结论是错的**（本会话踩过：看到 250 日新低就说位置到了，回测后发现该档位历史 1 年胜率仅 31%）。

---

## 二、数据源（拉长历史是关键）

### ✅ 腾讯周线 —— 拉 11 年+，最稳（首选）
```python
GET https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh510300,week,,,600,qfq
# data.sh510300.qfqweek = [[date, open, close, high, low, volume], ...]
# 600 根周线 ≈ 11.7 年（实测 2015-01-30 ~ 2026-10-16）
```
- 日线 `day` 最多约 **640 根**（≈2.5 年），**不够做回撤分层回测**
- **周线是唯一能免费拿到 10 年+历史的稳定通道**

### ⚠️ 东财全历史 —— 数据最全但极易限流
```python
GET https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.510300
    &fields1=f1,f2,f3,f4,f5,f6&fields2=f51,f52,f53,f54,f55,f56,f57,f58
    &klt=101&fqt=1&beg=0&end=20500101&lmt=5000
# 实测 3495 根（2012-05-28 ~ 2026-10-16，14 年）
```
- **成功拉一次后就可能整批 RemoteDisconnected，重试 3-5 次 + sleep 1.5s×n 仍失败**
- **降级 fields2（f51,f53）会拿到错误的价格字段**（实测返回 1.930，真实 4.236）→ 别用降级 URL 凑
- **策略**：先试一次东财全历史，失败立刻转腾讯周线，不要在东财上耗

### secid 规则
`1.` + 沪市（`1.510300`、`1.000300`）、`0.` + 深市（`0.159915`）

## 三、风险收益指标计算（纯 Python，无需 pandas）

```python
import math, statistics as st

def risk_return(prices, periods_per_year=50):   # 周线用 50，日线用 250
    rets=[prices[i]/prices[i-1]-1 for i in range(1,len(prices))]
    m=sum(rets)/len(rets); sd=st.stdev(rets)
    ann=m*periods_per_year; vol=sd*math.sqrt(periods_per_year)
    # 最大回撤 + 起止
    peak=prices[0]; mdd=0; det=None; pk=0
    for i,p in enumerate(prices):
        if p>peak: peak=p; pk=i
        if p/peak-1 < mdd: mdd=p/peak-1; det=(pk,i)
    # 下行波动 → 索提诺
    downs=[min(x,0) for x in rets]
    dsd=math.sqrt(sum(x*x for x in downs)/len(downs))*math.sqrt(periods_per_year)
    return dict(ann=ann, vol=vol, sharpe=(ann-0.02)/vol,
                sortino=(ann-0.02)/dsd, mdd=mdd, calmar=abs(ann/mdd) if mdd else 0, span=det)
```

### 指标口径（引用时要说清）
| 指标 | 含义 | 好/差参考 |
|---|---|---|
| 年化收益 | 长期回报 | 宽基 6-8% 属正常 |
| 年化波动 | 价格噪声 | **>20% 偏高** |
| **夏普**（无风险 2%） | 单位风险超额收益 | **<0.3 差**；负数=不如存款 |
| **卡玛**（年化/最大回撤） | 单位回撤换来的收益 | **<0.5 差** |
| 最大回撤 | 最坏情况 | 宽基 −30%~−50% 都可能 |
| 回本时间 | 回撤后多久回前高 | 中位 1.2 年是常态 |

## 四、⭐ 回撤深度分层回测（本方法的核心产出）

```python
def dd_from_peak(i, wc):
    return wc[i]/max(wc[:i+1])-1

def backtest(bands, wc, horizons=(13,26,52)):   # 周为单位
    for lo,hi in bands:
        sig=[]
        for i in range(60,len(wc)):
            if lo<=dd_from_peak(i,wc)<hi:
                if not sig or i-sig[-1]>8: sig.append(i)   # 间隔>8周去重
        for h in horizons:
            rs=[wc[i+h]/wc[i]-1 for i in sig if i+h<len(wc)]
            win=sum(1 for x in rs if x>0)/len(rs)
            print(f"{abs(hi)*100:.0f}%~{abs(lo)*100:.0f}% {h}周: 胜率{win*100:.0f}% 中位{st.median(rs)*100:+.1f}%")
```

### 实测结果：510300（周线 2015-2026，11.7 年）

| 回撤档位 | 13周胜率 | 26周胜率 | **52周胜率 / 中位收益** |
|---|---|---|---|
| 10%~15% | 50% | 33% | **14% / −18.1%** 🔴 |
| **15%~25%** | 56% | **28%** | **31% / −8.9%** 🔴 |
| 25%~35% | 59% | 48% | 52% / +2.2% 🟡 |
| **35%~50%** | 67% | **89%** | **94% / +19.5%** 🟢 |

**➜ 结论：沪深300 的「浅回撤」是最差的买点。** 跌 10-25% 就买，1 年胜率只有 14-31%；只有跌 35%+ 才进入高胜率区。

**这条与直觉完全相反，是最容易被"跌了这么多该反弹了"骗到的地方。**

## 五、趋势确认信号回测（右侧优于左侧）

```python
def ma(i, w, wc): return sum(wc[max(0,i-w+1):i+1])/len(wc[max(0,i-w+1):i+1])
```

实测（510300 周线，跌破 15% 回撤为前置条件）：

| 买入信号 | 样本 | 13周 | 26周 | **52周胜率/中位** |
|---|---|---|---|---|
| 跌破 15% 就买（无脑左侧） | 53 | 58% | 58% | 62% / +13.1% |
| **+ 站上周 MA20** | 35 | 60% | 63% | **65% / +16.6%** |
| **+ 站上周 MA30** | 33 | 58% | 64% | **71% / +18.3%** ⭐ |
| 周 MA20 金叉 + 回撤>10% | 21 | 57% | 62% | 70% / +18.3% |
| 站上周 MA52（年线） | 44 | 60% | 66% | 62% / +13.9% |
| 周 MA52 金叉 | 13 | 50% | 50% | **50% / +0.7%** ❌ 无效信号 |

**➜ 有效：站上周 MA20/MA30（+7~9pp 胜率）。无效：MA52 金叉（千万别用）。**

## 六、持有期 vs 胜率（回答"时间比"必用）

510300 全历史滚动窗口实测：

| 持有期 | 胜率 | 中位收益 | 最好 | 最差 |
|---|---|---|---|---|
| 1 个月 | 52.5% | +0.4% | +30.1% | −28.5% |
| 3 个月 | 54.0% | +0.8% | +63.4% | −42.1% |
| 半年 | 54.5% | +1.8% | +37.6% | −36.1% |
| **1 年** | **57.7%** | +7.5% | +54.6% | **−47.0%** |
| **2 年** | **65.3%** | +9.0% | +107.6% | −34.9% |
| **3 年** | **70.0%** | +19.7% | +85.3% | −41.4% |

**➜ 1 年内是抛硬币（57.7%，最差能亏 47%）；2 年才明显偏多。做宽基不能按短线思路。**

**回本时间**：从 −15%~−25% 回撤恢复到前高，中位 **62.5 周（1.2 年）**，最快 22 周，最慢 5.3 年。

## 七、⚠️ 「新低」与「便宜」是两个尺度 —— 必须分别报

实测 510300（2026-10-16，现价 4.236）：

| 尺度 | 位置 | 结论 |
|---|---|---|
| **近 250 日** | 分位 **0.5%**（一年新低） | "很便宜" |
| **近 11.7 年** | 分位 **63.7%** | **"不便宜，还在中位之上"** |

**➜ 回答时必须两个尺度都给**，否则用户会以为"一年新低 = 历史大底"。

同理，各指数画面对比要列：`250日高/低 + 位置% + 距高点跌幅 + PE`，一眼看出谁是真便宜。

## 八、输出结构（用户偏好）

1. **结论先行**：能不能买、买多少、什么条件加
2. **四步证据表**（定位/估值/趋势/条件回测）
3. **回撤分层表**（让用户看到"为什么现在这档不好"）
4. **趋势信号表**（说明"等什么信号再买"）
5. **持有期胜率表**（回答"时间比"）
6. **具体标的表**：代码 / PE / 成交额 / 定位（核心/防御/进攻）
7. **分批方案**：批次 × 触发条件 × 仓位
8. **风险提示**：历史规律不代表未来 + 样本量说明

## Pitfalls
- **别用日线 640 根做回撤分层**（只有 1 次信号，样本不足）→ 必须周线 600 根
- **东财 push2his 拉全历史成功一次后就限流**，重试常无效 → 立刻转腾讯周线，别耗
- **东财降级 fields2 会返回错字段**（f53 拿到 1.930 而非 4.236）→ 只用完整 fields2
- **周线用 50 期/年、日线用 250 期/年** 年化，混用会把年化收益算错近 5 倍
- **单看"250日新低"就下"可以买"是最大陷阱**（§四 已证：浅回撤档 1 年胜率仅 14-31%）
- **宽基不设价格止损**（分散投资），但必须设**逻辑止损 + 持有期预期**（≥2 年）
- **回测样本量要说出来**（13-53 个信号），不要把它包装成铁律
