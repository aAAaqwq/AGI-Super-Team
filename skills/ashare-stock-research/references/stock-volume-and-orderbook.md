# 个股放量/缩量判定 + 盘口订单分析

触发：用户问「怎么看放量还是缩量」「成交量怎么看」「盘中怎么看订单/盘口分析涨跌」「量比在哪看」。
（大盘/板块层面的量能框架见 `market-volume-analysis.md`；本文件是**个股层面**。）

---

## 一、第一性：放量/缩量是**相对概念**

「成交 100 万手是放量还是缩量」无法回答 —— **必须先定参照系**。三个层级：

| 参照系 | 怎么比 | 回答什么 |
|---|---|---|
| ① 自己过去 | 今日量 ÷ 5日/10日/20日均量 | 相对自己放还是缩 |
| ② 同类 | 今日换手率 vs 板块平均换手 | 在板块里活跃吗 |
| ③ 大盘 | 个股量能变化 vs 两市量能变化 | 个股行为还是系统性 |

> 只看①会误判：全市场都缩量时你的票缩得更少，其实是相对强。

## 二、量化阈值表（可直接照着查）

### 2.1 今日量 ÷ 5日均量
```
  < 0.7        缩量（无人愿交易）
  0.7 ~ 1.2    平量
  1.2 ~ 2.0    温和放量（有资金关注）
  2.0 ~ 3.0    大幅放量（强烈分歧）
  > 3.0        天量（极端，必查是否见顶/见底）
```
**交叉校验**：同时看 ÷10日、÷20日。
- ÷5日 低但 ÷20日 正常 → 只是短期缩量（前两天刚爆过量）
- ÷5日、÷20日 都低 → 真清淡

### 2.2 换手率（跨股可比，但要看市值分档）

```
换手率 = 成交量 ÷ 流通股本 × 100%
流通股本 = 流通市值 ÷ 现价      ← 别用总股本，只有全流通股两者才等价
```

| 市值 | 正常 | 活跃 | 过热 |
|---|---|---|---|
| 小盘（<50亿） | 3~5% | 5~10% | **>15%** |
| 中盘（50~200亿） | 1~3% | 3~5% | >8% |
| 大盘（>200亿） | <1% | 1~2% | >3% |

### 2.3 ⚠️ 盘中必须按时间折算（否则一定错）

```
盘中量比 = 当前累计成交量 ÷ (5日均量 × 已交易时间占比)

例：10:30（已交易 60/240 分钟 = 25%），已成交 30 万手，5日均量 99.3 万手
   折算全天 = 30 ÷ 0.25 = 120 万手 → 量比 = 120 ÷ 99.3 = 1.21 → 温和放量
```
**更省事**：盘中直接看行情软件的「量比」字段（已自动折算）。
量比 <0.8 缩量 / 0.8~1.2 平量 / >1.5 明显放量（此时要问：放量的**方向**是什么）。

## 三、放量 ≠ 好，缩量 ≠ 坏（必须结合位置 + 方向）

这是最易误判处。四象限：

| 位置 | 量能 | 方向 | 含义 |
|---|---|---|---|
| **高位** | **放量** | 涨 | 接力换手/**出货** ⚠️ |
| 高位 | 缩量 | 涨 | 筹码锁定（健康但无新钱） |
| **低位** | **放量** | 跌 | 恐慌出清/吸筹 🟢 可能见底 |
| **低位** | **缩量** | 跌 | **无人接盘 → 阴跌** 🔴 最难受 |
| 上涨中 | 缩量 | 涨 | 量价背离 ⚠️ 随时回调 |

**四条铁律**：放量涨=有资金抢筹（高位警惕出货）；放量跌=有人在跑（低位可能是最后一跌）；
缩量涨=无量虚涨；缩量跌=阴跌磨人。
**记住「天量之后必有天价」** —— 天量常即顶部。

## 三-bis、⚠️ 「缩量」的正负号依赖趋势位置（2026-10-27 修正，最易误判）

上表把「缩量跌」只放在**低位**一格，漏了最容易让人误判的一格：**高位回落途中的缩量阴跌**。
很多人看到「量缩了」就得出「卖压枯竭、洗盘结束、要拉了」——**方向完全错**。

| 场景 | 缩量的真实含义 | 该怎么读 |
|---|---|---|
| 上涨/横盘 + 缩量 + 收盘在上方 | 惜售、高控盘锁仓 | 🟢 正面（锁仓） |
| 涨停封死 + 缩量 | 筹码锁定 | 🟢🟢 最强 |
| 低位 + 缩量 + 阴跌 | 无人接盘的阴干 | 🔴 最难受，但下行空间有限 |
| **高位破位后 + 缩量 + 连跌数日 + 跌破全部均线 + 资金连续净流出** | **主力已卖完、不再供量的"失血"** | 🔴 **最危险：会被误读成洗盘** |

**三条硬区分（只看量能必然判错，必须配下面两条）**：

1. **资金流方向** —— 洗盘时主力是净流入或小幅流出；失血时**连续净流出**。
2. **获利盘比例**（自建筹码模型，见 `chip-distribution-model.md`）—— 洗盘时仍有 40%+ 获利盘；
   失血时**只剩个位数 %**（示例股A实测 1.94% = 98% 套牢）。
3. **能否快速收回** —— 洗盘砸完 1-2 天收回；失血**一路阴跌、无一收回**。

**口诀：缩量在上升趋势里是"没人卖"，在下跌趋势里是"没人买"。同一个数字，相反的结论。**

### 配套信号：「连续 N 日高开低走 + 开盘价逐日下移」

比单日 K 线更早暴露资金意图的一个廉价指标 —— **把最近 5 日的开盘价按顺序排出来**：

```
示例股A 000001（2026-10-21 ~ 10-27）
开盘价：24.96 → 23.80 → 21.22 → 20.01 → 18.89    ← 每天台阶式下移
收盘价：24.07 → 22.03 → 20.64 → 18.70 → 17.80    ← 全部收在开盘价下方
```
- **开盘价逐日下移** = 每天都有资金愿意在更低的价位接，但没有资金愿意往上抬 → **无承接**
- **每天开>收（高开低走）** = 早盘的买盘全部被砸掉 → **有人在利用早盘流动性出货**
- 再叠加**尾盘 30 分钟放量、而全天资金净流出**（超声连续 5 日尾盘 2.1–4.1 亿）= **主力借尾盘流动性离场，不是抢筹**

> 这三条同时出现，就不必再找别的解释了：**这是派发尾声的失血，不是洗盘。**

### 与四维共振打分的联动（重要）

`ashare-volume-resonance-analysis` 的时间轴阈值表里「缩量 <0.9 倍 = +1」**只成立于上升趋势或横盘**。
**下跌趋势里不得因"缩量"给正分**（应记 0 或 −1），否则会把"5 连阴 −30.5% 的失血"算成正面信号。
打分前先问一句：**这只票现在在上升趋势还是下跌趋势？**（MA5 vs MA20、近 5 日累计涨跌）

## 四、盘口订单分析（东财「盘口」/五档区域）

| 指标 | 定义 | 判读 |
|---|---|---|
| **委比** | (买五档总量−卖五档总量)÷(两者和)×100% | >+30% 买盘强 / <−30% 卖盘强。⚠️ **最易骗人**（挂单可撤） |
| **外盘** | 以**卖一价**成交（主动买） | 买方急，愿追 |
| **内盘** | 以**买一价**成交（主动卖） | 卖方急，愿砸 |
| **大单/超大单** | 单笔 >100万 / 20–100万 | 主力 / 大户；主力净流入 = 两档净额和 |
| **每笔均量** | 成交额 ÷ 成交笔数 | 均量大 = 大资金在场 |

**内外盘比委比可信**；**外盘>内盘但股价不涨 = 有人用大单托着出货（最阴的场景）**。
**逐笔**（分时图点成交量柱）：看大单成交的**价位** —— 低位吃货=吸筹，高位出货=派发，同价位反复对倒=制造成交。

### 四种盘口陷阱
| 陷阱 | 表现 | 识破 |
|---|---|---|
| 假挂单诱多 | 买一挂巨额买单 | **看撤单率**，频繁撤=假；真买盘会推价格上行 |
| 压单测试 | 卖一挂大单压着 | 被吃掉=真买方强；自己撤=虚张 |
| 对倒放量 | 同价位反复成交但股价不动 | 量放价滞 = 自买自卖 |
| 尾盘拉抬 | 14:55 突然拉高 | 为做**收盘价**，不代表真实强度 |

**口诀：挂单是「意愿」，成交是「事实」。** 看撤单率 + 成交连续度 + 每笔均量。

## 五、手机端「量比」在哪看（东财 APP 实测路径）

量比**默认不显示**，按此顺序找：
1. **个股分时页 → 价格下方数据行**（`今开 最高 最低 换手 量比 市盈`）→ **手指在该行左右滑动**
   （屏幕窄，默认只露前几个字段，量比被挤到后面 —— 这是「找不到」的头号原因）
2. **五档/盘口区域下方**（量比、委比、内外盘、换手、振幅）
3. **自选股列表 → 右上角编辑/长按标题栏 → 勾选「量比」**（一劳永逸，多股对比）
4. 行情 → 沪深个股 → 排序 → 选「量比」（找全市场异动）

**兜底替代**：换手率（位置更靠前，一定看得到）+ 直接比成交量柱高矮。

## 六、可复用算法（execute_code，腾讯接口）

```python
# 个股量能标尺：÷5日/÷10日/÷20日均量 + 换手率 + 判定
k = json.loads(fetch(f"https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,120,qfq"))
rows = k['data'][code].get('qfqday')          # ⚠️ 字段序 [date,open,close,high,low,volume]
vol = [float(r[5]) for r in rows]             # 手
FLOW_SHARES = 流通市值/现价                     # 流通股本（股），勿用总股本
r5  = vol[i] / (sum(vol[i-5:i])/5)            # 判定主指标
turn = vol[i]*100 / FLOW_SHARES * 100          # 手→股 再除流通股本

# 日内量能拆解（近5日）：倒序，用前先 [::-1]
d = json.loads(fetch("https://web.ifzq.gtimg.cn/appstock/app/day/query?code=sz000003"))
# 每行 "HHMM 价 累计量(手) 累计额(元)"，是累计值
# 竞价额 = 首行(0930)累计额；前30min = 1000累计 − 0930累计
# 前30min占比 = 前30min额 ÷ 全天额   → >40% = 冲高回落结构
# ⚠️ 当日分时会多出一行 `1530`，累计值与 1500 相同 —— 那是盘后清算行，不是交易分钟。
#    算"全天额"要取 1500（或倒数第二行），不要把 1530 当成第 243 分钟。
```

**判定基准要算给用户看**（例：5日均量 99.3 万手 →
缩量 <69.5万手 / 平量 69.5–119.2 / 温和放量 119.2–198.6 / 大幅放量 198.6–297.9 / 天量 >297.9）。

## 七、实证：示例股G 2026-09-15 ~ 10-08 量能标尺

| 日期 | 量(万手) | ÷5日均 | ÷10日均 | ÷20日均 | 换手% | 涨跌% | 判定 |
|---|---|---|---|---|---|---|---|
| 09/18 | 97.2 | 1.64 | 1.39 | 1.02 | 6.46 | +10.10 | 温和放量 |
| 09/21 | 194.3 | 2.93 | 2.78 | 2.12 | 12.91 | +10.09 | 大幅放量 |
| **09/22** | **465.0** | **4.97** | **5.62** | **4.83** | **30.90** | −0.28 | **天量（顶部）** |
| 09/24 | 139.1 | 0.66 | 1.02 | 1.17 | 9.25 | −1.78 | 缩量 |
| 09/28 | 94.1 | 0.41 | 0.65 | 0.78 | 6.25 | −2.11 | 缩量 |
| 09/30 | 98.8 | 0.48 | 0.66 | 0.81 | 6.57 | +0.93 | 缩量 |
| **10/08** | **74.3** | **0.56** | **0.49** | **0.62** | **4.94** | −1.22 | **缩量** |

**读法**：9/22 天量（换手 30.9%=一天换掉 1/3 流通盘）+ 长上影（冲 3.95 收 3.59）+ 次日跌 ⇒ 顶部；
其后量能萎缩 84%（465万→74万手）、价跌量减 ⇒ **无人接盘的阴跌**（不是恐慌崩，是慢慢阴干）。
同期日内结构：9/24~10/8 前30min占比 35~44%（≈40%），全天/下午额持续新低 ⇒ 高点固定在早盘。
