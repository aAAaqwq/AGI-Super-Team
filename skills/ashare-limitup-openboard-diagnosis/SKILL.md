# 涨停开板性质判定（分歧 vs 出货）

**用途**：回答「它开板了，是洗筹还是派发」「这个开板能不能接」。
**核心**：开板本身没有好坏。判据是 **开板之后那半小时** —— ①跌多深 ②破不破均价线 ③多久回封 ④开板段里谁在主动成交。

**姊妹 skill**：
- `ashare-limitup-streak-analysis` — 能不能续板（**值不值得做**）
- 本 skill — 开板了怎么办（**能不能买**）
- `ashare-intraday-signal-verification` — 盘口真假验证（**信号真不真**）

## 触发条件
- 「XX 开板了 / 炸板了，是分歧还是出货」
- 「它开板给机会了吗，能不能接」
- 打板后封板被打开，要不要撤/要不要补
- 复盘时判断某只票当天开板是洗还是派

---

## 一、四看判据表（按重要性排序）

| # | 看什么 | 分歧（洗筹，可参与） | 出货（派发，走） |
|---|---|---|---|
| 1 | **什么时间开板** | 09:30-10:00 早盘开（低位换手，抬成本） | 13:30 后，尤其 14:00-14:45（跟风盘最厚时砸） |
| 2 | **跌多深** | 回落 **<3%**，最低价不破当日分时均价线 | 回落 **>5%**，直接砸穿均价线 |
| 3 | **能站回去吗** | **15 分钟内**回封，封单 ≥ 第一次的 70% | 横 30 分钟回不去，反弹一次比一次低 |
| 4 | **开板段内谁在主动成交** | 外盘 > 内盘（主动买在吃） | 内盘 ≫ 外盘（主动砸，买一挂单是幌子） |

**铁律**：**挂单是意愿，成交是事实。** 买一挂几万手只说明"想接"，内盘才是"真有人卖给它"。

### 补充判据
- **砸的形态**：一笔/几笔巨量长阴砸穿后立刻被吃掉 → 洗；碎单绵延不断、反弹无量 → 派发
- **回封质量**：放量打上去的真承接；尾盘一两分钟缩量偷袭封回 → **诱多**，次日大概率低开
- **反复炸板怎么读**：炸 5 次仍收在涨停、且每次低点在**抬升** → 买盘强（分歧型）；炸开后一路走低、回封一次比一次弱 → 出货型
- **板块环境**：同板块其他票还在封/在涨 → 洗；同板块集体炸板 → 板块级派发，个股再强也扛不住

## 二、操作纪律（比判据更重要）

```
1. 开板那一刻分不清 → 不赌第一笔。开板不是买点，回封才是买点。
2. 回封 + 封单重建 ≥ 原来 70% → 才可小仓介入。
3. 破均价线且 30 分钟不回封 → 直接放弃，不补不摊。
4. 已经封死的票，不要在开板瞬间挂单抢 —— 你抢到的那一刻，往往是它在给你派发。
5. 高开 >+5% 一律不追（追在派发位是最大亏损来源）。
```

## 五、Pitfalls

- **⚠️ 封死板的全天内外盘是失真的**：正裕工业 10/26 全天 内盘 1661 手 / 外盘 286,081 手（99.4% 外盘）—— 这不是"抢筹"，是数据口径把封板成交量全算成外盘。**内外盘只能在「开板段内」或「未封板时」用**，一字板/封死板不要拿它下结论。
- **炸板次数多 ≠ 一定出货**：关键看每次开板的低点是抬升还是下移。襄阳轴承炸 5 次仍收涨停，说明承接在。
- **别把"回封了"当安全**：尾盘缩量偷袭回封是诱多，次日低开概率高。看回封时的量。
- **一字板不要预设"明天会给舒服买点"**：一字板 + 封单薄 = 要么买不到，要么开板即派发，中间态概率低。
- **均线止损对打板股太远**：MA5 可能在 -15% 外。打板用「当日均价线 + -5% 纪律」，MA5 只作结构参考。
- **腾讯分时最后一行是 15:00 收盘集合竞价**，算开板段时别把它当连续交易分钟。
