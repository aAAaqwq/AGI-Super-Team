# A股买点时机决策（不等回踩 vs 等回踩）

**用途**：回答「什么时候入场好」「现在能不能买」「做超短线 1-3 天选哪只」「明天哪只会涨停」。
**与选股 skill 的分工**：`youzi-stock-quality-screen` 回答「这票质量行不行」；**本 skill 回答「什么时候下手」**。

---

## 一、⭐⭐⭐ 核心判据：有没有「第二条腿」

**这是最贵的一课（2026-11 锋龙股份，两次错过 33%）。**

| 时间 | 事实 | 我给的买点 | 结果 |
|---|---|---|---|
| 11/10 盘前 | 锋龙 11/09 首板 43.86；通用设备板块 5 只涨停（梯队最好）；史最大 2 连板 | 「等回踩 MA5 40.90」 | **11/10 开盘 46.00（高开 +4.88%），日内最低也是 46.00 —— 全天没回到 40.90** |
| 11/11 | → 48.25 涨停 | 未再提示 | 又错过 |
| 11/12 | → **58.39（4 板）** | 才承认判断保守 | **43.86 → 58.39 = +33%，一次都没买到** |

**教训一句话**：
> **有第二条腿（板块梯队）的票不会给你回踩；没有第二条腿的票，回踩了也别接。**

### A / B 两类，两套标准

```
【A 类 · 不等回踩，次日开盘就买】
   ① 板块梯队 ≥5 只涨停          ← 决定性条件
   ② 历史最大连板 ≥2 板（有基因）
   ③ 首板 10:00 前封板 或 炸板回封
   ➜ 次日高开 3~5% 且不破前日最低 → 开盘直接买

【B 类 · 必须等回踩】
   ① 板块独苗 / 梯队 ≤2 只
   ② 无连板基因（史最大 1 板）
   ③ 尾盘偷袭封板
   ➜ 等回踩 MA5 或首板收盘价
```

### 买点阶梯（A 类）

```
首板收盘价 ──── 破这里 = 一日游，放弃
次日开盘    ──── 高开 3-5% 且不破前日最低 → 首选买点
次日日内低  ──── 开盘冲高回落后回踩不破前日低 → 二次买点
```

### 不追的三种情况（一律不买）

| 情况 | 原因 |
|---|---|
| **一字板开盘** | 买不进，别挂单自我安慰 |
| **高开 >7%** | 当天已透支，次日大概率低开 |
| **跌破前日最低** | 首板资金已撤，接力逻辑失效 |

## 二、⭐⭐ 三筛无果时：诚实说「今天没有合格标的」

**2026-11-12 实测**：当日 45 只涨停全部封住，按「可买性 + 位置 + 涨停基因」三条筛完：

| 类别 | 数量 | 问题 |
|---|---|---|
| 2-4 板连板股 | 14 只 | 距 MA30 **全部 ≥+12%**（4 板的东方环宇 +38.1%、锋龙 +35.1%、飞亚达 +28.2%） |
| 位置低（<+15%）首板 | 5 只 | **全部无涨停基因**（史最大 ≤1 板） |
| 兼顾两者 | **1 只**（兴欣新材） | 当天已封死，买不进 |

**➜ 正确输出：「今天没有符合你标准的标的」+ 三个替代方案。**

```
① 等明天：唯一合格那只（今天封死买不进）明天高开 3-5% 不破今日涨停价 → 开盘买
② 转非涨停强势股：位置比所有涨停股都好的（距 MA30 <−15% + 主力净流入 >3 亿 + 距当日高 <2%）
③ 空仓等：现金也是一种仓位
```

### ❌ 绝对不能做的三件事

1. **降标准硬凑** —— 把 +38% 的 4 板包装成「妖性足」，用户追进去就是接盘
2. **只报「资金最多」的** —— 资金多 ≠ 位置安全（通富微电主力 +9.23 亿，但史最大仅 1 板）
3. **假装有答案** —— 用户是拿真金白银按你的话下单的

## 三、超短线 1-3 天的时间框架

用户明确说过「做超短线我持仓一般 1-3 天」。执行纪律：

| 时间 | 动作 |
|---|---|
| **T 日 14:30-14:50** | 确认尾盘是否守住当日高附近（距高 >−1% = 强），此时才买 |
| **T+1** | 涨 5% → 减半；涨 10% → 全出；跌破买点止损 → 无条件走 |
| **T+2** | **无论盈亏清仓**（超短线不留第三天） |

**三条铁律**：
1. **不追涨停** —— 今天封死的明天买不进；能买进的多半是开板的弱票
2. **不补仓** —— 超短线没有「摊薄」概念，错了就走
3. **不超 3 天** —— 超短线变长线持有，就是套牢的开始

**仓位**：单只 ≤2 成；已有持仓时先算清现金余额再定（用户常满仓，超短加仓要和可用资金对齐）。

## 四、盘前选股的标准提问顺序

用户问「今日可买入的股 / 明天可能涨停的品种」时，按这个顺序跑，不要跳步：

```
① 板块资金流 TOP10（东财 m:90+t:2，含主力净额）
   → 找「主力净额 >5 亿 + 涨跌家数一边倒」的板块，这才是主线

② 主力净流入个股 TOP20（fid=f62）
   → 与 ① 的板块交叉，只留主线板块内的

③ 涨停池连板梯队（getTopicZTPool）
   → 2-4 板 + 封单 0.2-1 亿 + 换手 8-20%（可买 + 有空间）

④ 非涨停但强势（涨幅 4-9.5%）
   → 换手 ≥5% + 量比 >1，这些明天最容易接力

⑤ 三筛：可买性 → 位置（距 MA30）→ 涨停基因（史最大连板）
   → 全过 = 推荐；有 0 只 = 走第二节的诚实输出
```

**为什么第 ④ 步重要**：今天涨停的全部买不进（封单 1-27 亿），**「涨 8-9.5% 但还没封板」的才是真正能买的接力对象**。实测 13 只符合，其中加涨停基因 + 位置双重过滤后只剩 2 只。

## 五、Pitfalls

- **⭐ 不要用「等回踩 MA5」这套套所有票** —— 这是本 skill 存在的唯一理由。先判 A/B 类，再给买点。
- **「距今日高 −1%~−3%」是尾盘强度的分水岭**：>−1% 尾盘强（可买）；−3%~−6% 冲高失败（不买）；>−6% 跳水（放弃）。
- **分时形态比日线更早暴露真相**：早盘冲高后横盘不动（如鼎信通讯量比 6.10 但从 6.04 横到 5.80）= 放量滞涨 = 派发，次日最容易崩。
- **观察股的「回踩 MA5」买点要跟着股价重算**：涨停后距 MA5 会瞬间拉开 10%+，原先算出的「+1.0% 贴线」立刻失效 —— 位置判断必须在**涨停价确定后**重算，不能用昨收的口径。
- **用户会买你明确标记「禁追高」的票**（本次东方创业：我说距 MA30 +20.8% 超红线，他仍买在 7.98）。此时不要重复说教，直接给「反弹到成本就走 / 破位减半 / 死线全清」的分批方案 —— 他要的是解决方案，不是复盘。
- **持仓成本是券商「摊薄口径」时，回本价会显著高于加权均价**（超声 24.195 → 28.020），需涨幅从 +35% 变成 +57%。这种票要主动把策略从「等回本」改成「逢反弹减仓换强票」，否则用户在等一个不可能的价格。
