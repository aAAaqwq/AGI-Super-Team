## 一、筹码峰（牧牛晚报）

### 是什么

**筹码峰 = 全市场持仓成本分布图**，在 K 线图右侧：
- **红色柱** = 获利盘（成本在现价下方）
- **蓝色柱** = 套牢盘（成本在现价上方）
- **黄色虚线** = 平均成本线
- **柱子越长** = 该价位筹码越多

### 四大形态

| 形态 | 含义 | 操作 |
|---|---|---|
| **单峰密集** | 筹码高度集中，成本一致，临近变盘 | **低位单峰** = 主力吸筹完毕，向上突破概率大<br>**高位单峰** = 出货尾声，破位风险高 |
| **多峰密集** | 多价位换手，多空平衡 | 峰间来回震荡，高抛低吸做 T |
| **筹码发散** | 成本散布宽区间，单边趋势中 | 参考意义小，顺势而为不猜顶底；**筹码重新聚集 = 反转信号** |
| **真空区** | 两密集峰之间的无筹码空白 | **向上突破真空区涨势迅猛**（追涨黄金路段）；**向下进入真空区跌势迅猛** |

### 四步实战流程

```
① 看形态（单峰/多峰/发散/真空区）
    ↓
② 看颜色（获利盘 >90% 警惕抛压；套牢盘 >70% 反弹压力大；各占一半等方向）
    ↓
③ 找密集区（最高峰的顶部 = 压力位，底部 = 支撑位）
    ↓
④ 盯筹码移动
   · 上涨中下方筹码上移 = 拉高派发 → 危险
   · 横盘/下跌中上方筹码下移 = 打压吸筹 → 机会
```

### 数据获取

**免费接口拿不到历史筹码分布。** 可选：
- 东财「筹码分布」页面（需抓取，不稳定）
- 用「距 MA30 位置」近似（回测证明这个近似反而最有效，见第七节）
- 付费数据源（Tushare Pro 有 cyq_perf 接口）

## 二、三步选股法（铁树哥）

**从 5000 多只股票筛强势股的三步漏斗：**

| 步骤 | 条件 |
|---|---|
| **① 成交量筛选** | 涨幅 **3%-5%** + 成交量放大 **2 倍以上** + 换手率 **3%-5%** |
| **② 走势结构过滤** | 多头排列（MA5>MA10>MA20）+ 放量拉伸 + 缩量回调 |
| **③ 筹码分布筛选** | 筹码高度集中，**90% 成本区间宽度 < 20%** |

**心法**：「每天花 20 分钟按规矩筛选，操作和心态做减法，少即是多、慢即是快。」

**配套**：
- **波段操作**：顺势 + 纪律，5/10 日线做高抛低吸锚点，吃鱼只吃中段
- **三三制仓位**：老仓/新仓/备用仓，赚钱往上加、亏钱往下撤、开局不顺直接清

**⚠️ 回测结果：这个方法没有超额，且「多头排列」是负向指标。详见第七节。**

## 三、真龙识别（星月神话·龙头战法）

**核心理念：龙头不预判、只识别 —— 由市场选出来，你做第一时间识别。**

### 四大特征（必须同时满足）

| 特征 | 判据 |
|---|---|
| **① 带动性** | 一涨停，全板块跟风 |
| **② 领涨性** | 连板最多、涨幅最大 |
| **③ 渡劫能力** | 大盘跳水能横盘稳住，企稳后第一个起飞 |
| **④ 顶级流动性** | 换手走出来的焦点，**而非一字板庄股** |

### 识别路径

```
题材爆发 → 找最先涨停且封死的票
   ↓
对比前五名分时图（拉升最干脆、回落有承接、封单最大）
   ↓
在板块首次大分歧「渡劫日」确认
   （烂板次日率先弱转强 = 绝佳买点）
```

### 买卖口诀

- **买在分歧，卖在一致**
- 情绪退潮、高位股集体杀跌时 → **空仓保命**

### 卖出三信号

1. **失去带动性**（无小弟助攻）
2. **高位放巨量滞涨**（死亡换手）
3. **情绪高潮日龙头反而封不住板**（借暖出货，最危险）

**➜ 这部分和 `ashare-limitup-streak-analysis` 高度重合，用那个 skill 即可。**

## 四、一夜持股法（李涨停168）

### 执行清单

| 环节 | 规则 |
|---|---|
| **选股时间** | **只在 14:30 之后动手**，不提前、不预判、不赌尾盘 |
| **6 大硬性条件**（缺一不可） | ①涨幅 **3%-5%** ②20 天内有过涨停 ③量比 **>1.4** ④市值 **<200 亿** ⑤换手率 **5%-10%** ⑥**分时全天在均价线上方（水上）** |
| **买入纪律** | 只买 1 只或分散 2-3 只，**总仓位 ≤5 成**，买入后**不加仓不补仓** |
| **次日卖出铁律** | 高开/强势冲高就卖 · 平开/强势冲高就走 · 平开/弱势直接走 · **低开立刻止损** · **10:00 前全部清完** |
| **风控底线** | 单笔亏损 **≤2%** · 大盘大跌/情绪冰点/跌停多 → **直接空仓** · **只做隔夜绝不拿成中线** |
| **心法** | 不赌涨跌，只赚纪律和先手的钱；避开 ST、异动、解禁、业绩雷、监管立案、高位减持股 |

**⚠️ 回测结果：T+1 微弱正超额（+0.41% vs 基准 −0.12%），T+5 极差（−5.12%）。符合「隔夜」定位。**

## 七之三、⭐⭐⭐ 回测方法论（比策略值钱，必读）

### 三个必踩的坑

**① 时间跨度太短 → 环境红利被当成策略 alpha**
30 天区间（9/17-10/31）正好是「急跌后反弹」，超跌策略全部优异；6 个月全失效。
**➜ 至少 6 个月，最好 2 年，必须跨上涨/下跌/震荡。**

**② 极端日制造假象**
- 「高开+深跌」：241 个信号，68% 集中在 7/20、7/31 两天暴跌反弹日。剔除后 T+1 从 55.2% 掉到 **35.9%**。
**➜ 必须检查信号集中度：单日/前5日占比 >20% 就要剔除重算。**

**③ 只看均值掩盖月度不稳定**
「高开>2%」2 年整体 +0.52%，但拆开：2025-04 +1.75%，2026-09 −0.58%。
**➜ 必须分月验证，正超额月份 ≥60% 才算可用。**

### 标准回测流程（照做）

```
① 时间跨度 ≥6 个月（最好 2 年，跨多环境）
   ↓
② 检查信号集中度（前5日 >20% → 剔除极端日重算）
   ↓
③ 分年 + 分月验证超额（正超额 ≥60%）
   ↓
④ 三个周期都看（T+1 / T+3 / T+5），别只看一个
   ↓
⑤ 跟「同年/同月基准」比，不要跟全局均值比
   ↓
⑥ 承认局限：无滑点、无手续费、涨跌停买不进、流通市值假设不变
```

### ✅ 唯一相对稳定：高开 >+2%（仅 T+1）

| 指标 | 剔除极端日后 | 基准（剔极端） | 超额 |
|---|---|---|---|
| **T+1** | **50.3% / +0.38%** | 46.7% / −0.05% | **+3.6 个点 / +0.43%** |
| T+3 | 44.4% / −0.31% | 42.1% / −0.52% | 🟡 微正 |
| T+5 | 42.2% / −0.71% | 41.1% / −0.87% | 🟡 微正 |

**月度验证**：6 个月里 4 个月正超额（67%），但 **9/10 月连续负超额（−0.41% / −0.15%）**。

**用法**：**收盘筛「今日开盘 > 昨收 2%」→ 次日开盘买 → 次日收盘卖。绝不拿过 2 天。**

| 位置 | T+1 | **T+5** |

## 八、⭐ 改进后的选股流程（吸收了回测结论）

```
第 0 步  位置前置（回测最重要维度）
         距 MA30 >+15% 的高位票 → 降级处理（T+5 均值 −4.13%）
         距 MA30 <−15% 的低位票 → 加分

第 1 步  分两种意图

【A. 超跌反弹（T+1 隔夜，胜率最高 51.8%）】
   · 距 MA30 <−15%
   · 近 5 日跌 >10%
   · 最好缩量（量/5日均 <0.8）
   · 次日开盘买，T+1 收盘卖，绝不拿过 2 天

【B. 趋势跟踪（T+3~T+5，看低位股）】
   · 距 MA30 <−15%（低位）
   · 量≥2 倍（唯一正向技术条件）
   · 不用「多头排列」（数据上是负向）
   · 不用「涨3-5%」（低位是陷阱）

第 2 步  筹码峰校验
   · 单峰密集 + 低位 → 最强
   · 下跌中上方筹码下移 → 吸筹
   · 向上突破真空区 → 追涨黄金路段

第 3 步  风控（这条最不该省）
   · 仓位 ≤5 成，单笔亏损 ≤2%
   · 大盘跌停多/情绪冰点 → 空仓
   · 避开 ST、业绩雷、监管立案、高位减持
```

## 九、Pitfalls

- **「涨幅 3-5%」在低位是负向的**：回测胜率 18.6%，比随机买入还差一半。只在「高位强势股」场景才用
- **「多头排列」是陷阱**：胜率 41.3%，比基准低 3.9 个百分点，多头+缩量更是 37.2%
- **T+1 有效 ≠ T+3/T+5 有效**：超跌反弹 T+1 胜率 51.8%，T+5 只有 24.6%
- **筹码峰无免费历史数据**：只能用「距 MA30」或「90% 成本区间」近似
- **「分时水上」无法日线回测**：只能用「收盘 > (H+L)/2」近似，但这个近似反而是负向的
- **回测不含滑点/手续费/涨跌停买不进**：实际收益会再打折
- **样本局限**：798 只 / 30 天 / 单一情绪周期，结论方向可信但幅度可能偏
