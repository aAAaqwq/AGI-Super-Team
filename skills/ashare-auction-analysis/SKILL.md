# A股集合竞价分析（9:15-9:25 → 开盘决策）

**触发场景**：用户说"竞价怎么看""低开怎么办""开盘价多少""结合竞价怎么操作""今天XX怎么走"。

**核心逻辑**：**竞价是全天第一份"真金白银的表态"** —— 它反映隔夜消息、外围市场、资金意愿的合成结果。竞价的可信度高于盘中任何时点的盘口，因为它是"真成交"，不是挂单。

## 一、时间轴（A股，务必按此理解）

| 时段 | 规则 | 可操作性 |
|---|---|---|
| 8:30-9:14 | 券商暂存，9:15 统一报送 | 挂单等价 |
| **9:15-9:20** | **可挂可撤** | ⚠️ **虚假挂单高发期**（大单撤单诱多） |
| **9:20-9:25** | **不可撤单** | ✅ **真实意愿**（这5分钟最可信） |
| **9:25** | **开盘价确定** | 价格锁定 |
| 9:25-9:30 | 多数券商不接受委托 | 等待 |
| 9:30 | 连续竞价开始 | 真实成交 |

**⭐ 铁律**：**9:20 前的价格和量都可能是假的，9:20-9:25 的是真的，9:25 定盘价是最终结果。**
**⚠️ 常见坑**：9:21 看到的"低开 1.732"可能到 9:25 变成 1.755（今天实战就发生过，买盘把价格拉回 1.3%）。

## 二、数据获取（腾讯接口，无需鉴权）

```python
import urllib.request, json

def gbk(u):
    return urllib.request.urlopen(urllib.request.Request(
        u, headers={"User-Agent":"Mozilla/5.0"}), timeout=20).read().decode('gbk','ignore')

# 实时行情 + 五档（f[] 数组）
raw = gbk("http://qt.gtimg.cn/q=sh600693,sz002589,sz159930")
for line in raw.strip().split('\n'):
    f = line.split('"')[1].split('~')
    # f[1]名称 f[2]代码 f[3]现价 f[4]昨收 f[5]今开 f[6]成交量(手)
    # f[9..18] 买1-5 价格/量  f[19..28] 卖1-5 价格/量
    # f[30]时间 f[32]涨跌% f[33]高 f[34]低 f[37]成交额(万) f[38]换手% f[49]量比
    op, prev, px = float(f[5]), float(f[4]), float(f[3])
    gap = (op/prev-1)*100 if prev else 0
    print(f"{f[1]} 开{op} 跳空{gap:+.2f}% 现{px} ({f[32]}%) 竞价量{f[6]}手")
    for i in range(5):
        print(f"  卖{i+1} {f[19+i*2]}×{f[20+i*2]}手 / 买{i+1} {f[9+i*2]}×{f[10+i*2]}手")

# 分时（首条即 9:25/9:30 的开盘数据）
m = json.loads(urllib.request.urlopen(urllib.request.Request(
    "https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh600693",
    headers={"User-Agent":"Mozilla/5.0"}), timeout=20).read().decode())
mins = m['data']['sh600693']['data']['data']
# 格式: "0930 价格 累计量(手) 累计额(元)"
```

**⚠️ 关键**：`f[6]` 是竞价成交量（9:25 那一条），**用它除以昨日全天成交量，就是"竞价量占比"**。

## 三、竞价量能判读（核心）

### 3.1 竞价量 ÷ 昨日全天成交量

| 比值 | 判读 |
|---|---|
| **< 0.5%** | 缩量（无人关注，可能横盘） |
| **0.5% - 1%** | 正常 |
| **1% - 1.5%** | 放量（有资金动作） |
| **1.5% - 2%** | 明显放量（大资金介入） |
| **> 2%** | **异常放量**（可能有重大消息/情绪极端） |

### 3.2 竞价价 + 竞价量的四种组合（最重要）

| 组合 | 含义 | 操作 |
|---|---|---|
| **高开 + 放量** | 资金抢筹，情绪强 | 🟢 持有/可追（但防高开低走） |
| **高开 + 缩量** | 无量虚高，诱多 | 🔴 **警惕冲高回落** |
| **低开 + 放量** | 抛压重/或有资金承接 | ⚠️ **看开盘 30 分钟定方向** |
| **低开 + 缩量** | 无人问津，阴跌 | 🔴 弱势，别碰 |

### 3.3 三个实战铁律

1. **竞价放量 + 开盘 30 分钟缩量 = 假放量 / 诱多**（最经典的陷阱）
2. **竞价缩量 + 开盘放量上攻 = 真启动**（资金 9:30 才进场）
3. **竞价高开但盘口卖压厚（卖1-卖5 大单） = 有人在出货**（挂单是假的，卖单是真的）

## 四、五档盘口读法

### 4.1 看什么

| 观察 | 含义 |
|---|---|
| **卖盘薄（卖1 只有几手）+ 买盘厚** | 🟢 承接强，容易上攻 |
| **卖盘厚（卖1-3 大单压着）+ 买盘薄** | 🔴 **压单测试/出货** |
| **买卖都薄** | 🟡 观望，无方向（成交量会很小） |
| **买1 有大单（几千手）但不断撤** | 🔴 **假托单**（诱多） |
| **卖1 有大单但价格不跌** | 🟢 **压单吸筹**（洗盘） |

### 4.2 实战判据（今天就用了）

```
卖1  24.79×2 手      ← 卖盘极薄
买1  24.78×176 手
买2  24.77×1,390 手   ← 买盘厚
买3  24.75×923 手
→ 结论：承接强，虽然低开但不怕
```

## 五、跳空缺口的三档分类

| 跳空幅度 | 含义 | 操作 |
|---|---|---|
| **0 ~ ±2%** | 正常波动 | 按原计划 |
| **±2% ~ ±5%** | 明显情绪 | 观察 30 分钟再动 |
| **±5% 以上** | 极端（消息/跌停开板） | **立刻决策**：低开是逃命/抢反弹，高开是出货/追涨 |

**⭐ 跌停开板专项**：
- **连续一字跌停后第一次"没封死"** = 开板信号
- **开板不代表反转，只代表"能卖了"**
- **操作：反抽到 −3%~−5% 区间，立刻清仓**（不要幻想回本）

## 六、竞价 → 开盘 30 分钟 → 全天 的推演

```
9:25 竞价定盘
  ├─ 高开放量 ──→ 9:30-10:00 看能否站稳开盘价
  │                 ├─ 站稳 → 趋势日（持有）
  │                 └─ 跌破 → 假高开（走）
  ├─ 低开放量 ──→ 9:30-10:00 看能否收复昨收
  │                 ├─ 收复 → 反包（强）
  │                 └─ 继续跌 → 弱势（走）
  └─ 平开缩量 ──→ 全天大概率窄幅震荡（不操作）
```

**关键时点**：
- **9:30-9:35**：前 5 分钟定情绪（有没有承接）
- **9:35-10:00**：主力真实意图（是否放量上攻/砸盘）
- **10:00**：全天方向基本确定

## 七、实战案例（2026-10-19 竞价）

| 标的 | 竞价 | 判读 | 操作 |
|---|---|---|---|
| **东百集团** | 开 9.11（−7.70%），**未跌停**（跌停价 8.88） | **连续跌停后首次开板** = 给逃命机会 | 反抽 −3%~−5%（9.40-9.60）立刻清 |
| **上海电影** | 开 27.71（+0.22%），竞价量仅 1,810 手 | 唯一高开，盘口清淡 = 观望 | 持有，守 27.35 |
| **瑞康医药** | 开 3.01（−0.66%），买1-3 共 2,600+ 手 | 3.00 整数关口有支撑，但已破 MA60 | 反抽 3.10-3.13 清仓 |
| **超声电子** | 开 24.78（−1.90%），**卖1 仅 2 手**、买2 1,390 手 | **卖盘极薄 + 买盘厚 = 承接强** | 持有，守 24.55 |
| **能源ETF 159930** | 9:21 虚拟价 1.732 → **9:25 定盘 1.755** | ⚠️ **竞价虚拟价不可信**，被买盘拉回 1.3% | 以 9:25 定盘价为准 |

**教训**：**9:21 的 1.732 和 9:25 的 1.755 差了 1.3%** —— 千万别在 9:20 前就下结论。

## 八、禁忌清单

| ❌ 错误做法 | 为什么 |
|---|---|
| 9:15-9:20 看到大单就判断 | 可撤单，可能是假的 |
| 用竞价价当"今天一定会这样" | 9:25 才定盘，且开盘后可能立刻变 |
| 只看价格不看量 | 无量高开 = 诱多；放量低开可能是承接 |
| 忽略五档买卖厚度 | 卖盘薄+买盘厚的低开，往往比高开更安全 |
| 把"开板"当"反转" | 开板只代表能卖了，不代表会涨 |
| 竞价数据不结合大盘 | 大盘 −0.6% 时，个股抗跌才有意义 |

## Pitfalls

- **腾讯接口 `f[6]` 是竞价成交量（手），不是成交额**；成交额在 `f[37]`（单位：万元）。
- **分时接口首条是 0930**（9:25 的竞价数据合并进去了），不是 0925。
- **9:25-9:30 期间行情接口显示"高=低=开"**，这是正常现象（还没连续竞价）。
- **量比字段 `f[49]` 在 9:30 前是 0**，别用它判断。
- **ETF 的竞价量普遍很小**（0.001-0.1 亿），不能和个股用同一套阈值。
- **跌停价计算**：`昨收 × 0.9`（主板）；创业板/科创板 `× 0.8`；ST `× 0.95`。
