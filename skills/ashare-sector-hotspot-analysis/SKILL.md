# A股板块热点与连板妖股判断

**用途**：回答「今天/本周资金在哪个方向」「哪个板块会出连板」「某某板块能不能延续」「某只连板股能不能跟」。
**核心**：不看谁涨得多，看 **① 资金持续性 ② 板块广度 ③ 有无真实产业催化** —— 三项全优才是主线。

## 触发条件
- 用户问"今天/本周热点板块是什么"、"买哪个板块"
- 用户问"XX 板块能延续吗"、"传媒会延续还是科技反弹"
- 用户给出连板股（"XX 已经2连板"），问能不能跟
- 需要复盘当日资金主线、涨停分布

## 一、三维度判定框架（核心）

| 维度 | ✅ 延续信号 | ❌ 退潮信号 |
|---|---|---|
| **① 资金持续性** | 主力连续 **2-3 天**净流入且递增 | 单日流入后立刻转负 |
| **② 板块广度** | 龙头涨停 + **跟随股也涨**（含大市值） | 只有龙头涨，其他不跟 |
| **③ 产业催化** | 有**真实业绩/订单/涨价**支撑 | 只有"概念"和"小作文" |

**用法**：三项全优 = 主线（可做）；两项 = 轮动（快进快出）；一项或零项 = 情绪票（只打板客参与）。

## 二、数据接口（全部免费）

### 1. 行业/概念板块排行（东财 clist）
```python
GET https://push2.eastmoney.com/api/qt/clist/get
  ?pn=1&pz=60&po=1&np=1&fltt=2&invt=2
  &fid=f3                  # 按涨幅排序
  &fs=m:90+t:2             # t:2=行业板块, t:3=概念板块
  &fields=f12,f14,f3,f62,f104,f105,f128,f140
# f14=板块名 f3=涨跌幅 f62=主力净流入(元) f128=领涨股
# ⚠️ 盘前返回 f3=0/f6="-" → 只能盘后或盘中取
```
**必须同时取 t:2（行业）和 t:3（概念）** —— 概念板块的资金量往往更真实（如"光通信模块"比"元件"更细）。

### 2. 涨停池（含连板数）
```python
GET https://push2ex.eastmoney.com/getTopicZTPool
  ?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt
  &Pageindex=0&pagesize=300&sort=fbt:asc&date=YYYYMMDD
# data.pool[] 每条：n=名称 c=代码 hybk=行业 lbc=连板数
```
**用途**：统计连板高度分布 + 行业分布 → 判断有没有主线。

### 3. 个股行情（腾讯，批量）
```bash
curl -s "http://qt.gtimg.cn/q=sh000003,sz000001" | iconv -f gbk -t utf-8
```

## 三、判定阈值

### 3.1 连板高度分布 → 判断市场情绪
```
最高板 ≥5板 且高标≥2只  → 强主线，情绪高涨
最高板 3-4板             → 有主线但分歧
最高板 ≤3板 且无高标      → 轮动期/退潮期，别追高
```

### 3.2 板块资金量级 → 判断主线归属
```
单板块主力净流入 > 20亿   → 资金主攻（可做）
10-20亿                  → 次主线
< 5亿                    → 情绪票（只适合打板）
```

### 3.3 板块广度 → 判断真假行情
```
龙头涨停 + 同板块 3+ 只跟涨（含大市值） → 真板块行情
龙头涨停 + 同板块 0-1 只跟涨            → 独立妖股（板块不跟，风险极高）
```

## 四、连板妖股识别（高风险）

**妖股特征**：
- 换手率 > 15%（巨量分歧）
- 振幅 > 10%（天地板反复）
- 概念标签含：`最近多板` `昨日高振幅` `昨日高换手` `东方财富热股`
- **独立性**：同板块不跟（无板块效应）
- **基本面**：PE 极高或亏损（纯资金驱动）

**判断"能不能跟"的三条**：
1. **板块跟不跟**：板块不跟 → 只能靠游资接力，随时断
2. **资金连不连**：龙虎榜连续净卖 → 主力在出
3. **催化实不实**：无真实业绩/订单 → 只靠情绪

## 五、实战案例：2026-10-13 科技 vs 传媒

| 方向 | 资金（当日） | 板块广度 | 产业催化 | 结论 |
|---|---|---|---|---|
| **科技（PCB/光通信/CPO）** | ✅ 光通信 +35.32亿、PCB +20.88亿、CPO +17.49亿、元件 +13.67亿 | ✅ 示例股A涨停 + 深南/生益/中际旭创等大市值齐涨 | ✅ 金禄电子"高多层板面向AI算力"、信维通信"高端MLCC量产"、PS5因AI内存涨价 | **主线** |
| **军工** | ✅ 合计约 +40亿 | ✅ 江龙船艇涨停 + 中航沈飞 +4.34% | ✅ 地缘冲突（胡塞/霍尔木兹） | 第二主线 |
| **传媒（AI漫剧）** | ❌ 数字媒体仅 +3.47亿 | ❌ 风语筑涨停但示例股E冲高回落、儒意电影已跌 | ❌ "尚未形成规模化收入"+多家提示风险 | **情绪票** |
| **消费（百货）** | ⚠️ 示例股C +20.58亿（个股） | ❌ 一般零售仅 3 只涨停，示例股C 2 板独苗 | ❌ PE 218、业绩平淡 | **独立妖股** |

**当时涨停池（67只）**：最高仅 3 板（5只），元件 9 只涨停最多 → **无强主线，但元件/PCB 是资金最密集处**。

**结论**：科技三项全优 = 主线；传媒三项全弱 = 情绪票；消费/示例股C = 独立妖股。

## 六、输出结构（用户偏好）

1. **当日板块全景表**（行业 + 概念，含涨幅/主力净流入/领涨股）
2. **资金量级排序** → 指出主线
3. **涨停池连板分布**（高度 + 行业分布）
4. **三维度打分对比表**（延续 vs 退潮）
5. **龙头股清单**（每个方向 2-4 只，标 PE/市值/昨日表现）
6. **明确结论**：哪个是主线、哪个是情绪票、哪个是独立妖股
7. **风险提示**（非投资建议 + 不追涨停龙头 + 位置提醒）

## Pitfalls
- **东财板块接口盘前不可用**（f3=0）→ 只能盘后或盘中取；盘前用前一日收盘数据分析
- **行业板块(t:2)与概念板块(t:3)要给两个口径** —— 同一波资金在两边名字不同，只看一个会漏
- **"涨幅第一"不等于"资金第一"** —— 实测：数字媒体 +11.94% 但资金仅 3.47亿；PCB +6.08% 但资金 +20.88亿。**资金才是主线判据**
- **涨停家数多不代表强** —— 要看**连板高度**（高度≤3板说明无主线）
- **板块龙头涨停 ≠ 板块行情** —— 必须看**跟随股**（同板块 3+ 只跟涨才算真行情）
- **妖股独立走强时不要用"板块逻辑"解释** —— 板块不跟的连板是纯游资，与板块景气无关
- 腾讯行情是 GBK，需 decode('gbk')
