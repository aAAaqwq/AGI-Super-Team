## 案例 1：金健米业 600127 —— 「打折甩卖」四特征全中（最干净的教学样本）

**数据日**：2026-11-03 收盘 10.10（+3.27%），换手 29.50%，成交 19.11 亿，流通 64.82 亿

### 四特征对照

| # | 特征 | 实际情况 | 命中 |
|---|---|---|---|
| ① | 短期暴涨后见顶 | 5.03 → **17.05（+239%）** → 跌到 9.54 | ✅ |
| ② | 连续大幅下跌 | −10.01 / −9.97 / −8.43 / −9.01 / −9.99 / −9.99 / −6.45 / −6.99 / −6.02（**连 9 根大阴**） | ✅ |
| ③ | 下跌途中缩量 | 0.59 / 0.58 / 0.65 / 0.66 / 0.76 / 0.80x | ✅ |
| ④ | **股东户数暴增** | **94,848 → 168,589（+77.75%）**，户均仅 5.00 万 | ✅✅✅ |

### 对倒证据

```
11/03 新浪资金流：+1.406 亿（超大单 +0.614）
11/03 东财龙虎榜：−2.114 亿（买 1.63 / 卖 3.75）
                   ↑ 相差 3.5 亿 → 判定对倒
```

近 12 日资金：10/19 **−5.595 亿**、10/22 **−4.371 亿**、10/23 −2.312 亿，
末端 10/30 +0.326 / 11/02 +1.318 / 11/03 +1.406 回流 3 亿，**累计仍净流出 8.95 亿**。

### 其他

- 五标准只过 1 条（流通 64.82 亿）；PE −252.82（亏损）、PB 9.91
- 均线：只站上 MA5（9.88），MA10 10.83 / MA20 12.40 / MA30 13.12 全破，距 MA30 **−23.02%**
- 筹码结构最差：上方 13-17 是 16.8 万户散户的密集套牢区，下方 9.05-9.54 才刚开始形成支撑

**结论：不是启动，是打折甩卖后的技术性反弹。龙虎榜净卖 2.11 亿 = 主力在跑。**

## 案例 2：示例股A 000001 —— 对倒 + 户数暴增（第一次识别对倒）

**数据日**：2026-10-30 收 17.20（+4.05%），振幅 **17.30%**，换手 26.72%

### 走势

```
0930  15.71 低开 −4.96%
0953  15.34 最低 −7.3%
1030  17.77 主力拉升（10:00-10:30 成交 9.56 亿 = 全天 34.9%）
1304  18.18 涨停
1329  18.18 封了 25 分钟
1334  17.96 开板
1459  17.19 尾盘
收盘  17.20
```

### 对倒证据

```
10/30 新浪资金流：+5.944 亿（超大单 +4.907）
10/30 东财龙虎榜：−0.586 亿（上「日振幅 15%」榜）
                   ↑ 反向 → 对倒
```

### 筹码

| 报告期 | 户数 | 变化 |
|---|---|---|
| 2026-03-31 | 53,985 | −3.89% |
| **2026-06-30** | **95,898** | **+77.64%** 🚨 |
| 2026-09-30 | 99,749 | +4.02% |

**➜ 散户数量翻倍。配合「拉到 27.18 → 三连杀 → 户数 +77.64%」= 教科书派发。**

### 后续验证（11/03）

- 11/03 收 16.68（−3.47%），量比 0.83，**全部均线跌破**，距 MA30 **−25.35%**
- 11/03 资金 −0.468 亿（超大单 −0.428）→ 10/30 进的钱在撤
- 反抽只撑 2 天（10/30 放量 1.37x → 11/02 摸 17.74 → 11/03 跌回 16.68）

**结论：10/30 的 +5.94 亿是假的，真实是主力借涨停出货。**

## 案例 3：大连圣亚 600593 —— 流通盘合格但三重利空

**数据日**：2026-11-03 收 41.95（+3.99%），换手 7.83%，量比 1.19，流通 54.03 亿

| 项 | 数值 | 判定 |
|---|---|---|
| 流通市值 | **54.03 亿** | 🟢 30-100 亿区间正中 |
| **股东户数** | 2026-06-30 **+3.97%**、2026-09-30 **+15.39%**（两期连增） | 🔴 筹码分散 |
| 资金流（8 日） | **−0.92 亿**（10/26 单日 −0.546 亿） | 🔴 净流出 |
| 量能 | 全 10 日在 0.50-0.90x | 🟡 缩量反抽 |
| **PE / PB** | **104.21 / 18.70** | 🔴 极贵 |
| 均线 | 站上 MA5/MA10，破 MA20 44.04 / MA30 44.61 / MA60 42.54 | 🟠 距 MA30 −5.97% |

**结论：流通盘合适是唯一优点。+3.99% 是缩量 0.90x 的反抽，不是启动。**
**「缩量上涨」必须分两类：主力高控盘 OR 无人跟风。户数暴增 + 资金流出 = 后者。**

## 案例 4：国芳集团 601086 —— 拉一天就派发（最典型的「一日游」）

**数据日**：2026-11-03 收 14.00（+4.01%），换手 17.73%，振幅 11.2%（12.86→14.37）

### 表面上很好看

- 11/02 资金 **+6.517 亿**（超大单 +4.935）
- 买1 挂 **9,053 手**（14.00 极厚）
- 20 日涨停 3 次、历史最大 **5 连板**、距 MA30 只 +1.5%

### 但三个信号说明在派发

```
① 11/03 超大单 −0.132 亿 → 11/02 拉一天，今天大资金就撤了

② 股东户数：
   2026-10-20  49,119 户
   2026-10-30  87,722 户   +78.59% 🚨
   → 一个月翻近一倍，全部换到散户手里

③ 龙虎榜近期连续净卖：10/27 −0.187 / 10/28 +0.139 / 10/29 −0.116
```

其他：PE 92.83 / PB 5.78（最贵）、流通 93.24 亿（游资拉不动）、户均市值 9.29 万。
**六判据得分 1/6。**

**结论：11/02 拉一天，11/03 开始派发。不碰。**

## 沉淀的判据优先级

1. **资金流与龙虎榜反向 → 一票否决**（对倒，别再往下看）
2. **户均市值 <8 万 → 散户盘 → 不具备持续拉升条件**
3. **户数暴增 >30% → 派发完成**
4. **跌停日龙虎榜净买 → 主力接货，可加分（慈文传媒唯一支撑点）**
5. **换手 >35% → 无锁仓，只能做超短**
6. PE/PB 只在同板块内比较才有意义

**两个数据源必须交叉，这是本 skill 最核心的一条。**
