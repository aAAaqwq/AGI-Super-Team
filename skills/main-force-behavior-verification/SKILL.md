# 主力行为验证 + 妖股基因筛选

**用途**：
1. 用户问「X 票主力还在吗 / 是不是还在继续涨」
2. 用户要「有期待变成妖股或龙头的票」
3. 判断某根大阳线是「启动」还是「派发」
4. 用户问「这个行情能不能持续 / 要看板块」→ 走判据 7（板块梯队）

**这两件事共享同一套数据字段**（股东户数、户均市值、龙虎榜、资金流、换手、涨停池），所以合并在一个 skill 里。
**先做第 0 步（有没有涨停基因），再做七判据（主力还在不在 + 能不能持续）。**

---

## 〇、第 0 步：先看这票有没有「涨停基因」

**2026-11-03 用户明确否掉过一批票，原话：**

> **「你挑选的好垃圾都没涨停过的，再扫描一下这些板块的优质有期望变成妖股或者龙头的」**

**踩坑经过**：用户要「旅游消费板块主力启动征兆」，我给了千禾味业 / 大商股份 / 重百集团 ——
形态完美（横盘 → 地量 → 放量洗盘 → 反包），但**20 日涨停 0 次、历史最大连板 1 板**。

**诊断**：那三只是**慢牛**（每天涨 2-3%），游资看都不会看，**永远不可能变妖股或龙头**。
形态判据再漂亮也没用 —— 缺的是「主力从来没在这票上做过连板」这个前提。

### 慢牛 vs 妖股的量化分界（必背）

| 维度 | 慢牛（不要） | **妖股 / 龙头（要）** |
|---|---|---|
| **20 日涨停次数** | **0 次** | **≥2 次，最好 ≥3** |
| **历史最大连板** | **1 板** | **≥2 板，最好 ≥3** |
| 流通市值 | 50-100 亿 | **30-50 亿**（游资拉得动） |
| 股价 | 无要求 | **≤10 元** 最佳（低价易炒） |
| 题材 | 无故事 | **有题材**（传媒/游戏/白酒/重组） |
| 换手率 | ~3% | **≥8%**（有资金关注） |
| 股东户数 | — | **不暴增**（见六判据第 3 条） |

### 涨停基因算法（60 日 K 线口径）

```python
is_gem = code.startswith(("300","301","688","689"))
lp = 19.5 if is_gem else 9.5                    # 创业板/科创板 20cm，其余 10cm
zt_flags = [(c[j]/c[j-1]-1)*100 >= lp for j in range(1, len(c))]
zt20   = sum(zt_flags[-20:])                    # 20日涨停次数   → 必选 ≥2
max_lb = 最长连续 True 的长度                     # 历史最大连板   → 必选 ≥2
cur_lb = 从末尾往前数连续 True                    # 当前连板（是否正在启动）
```

### 筛选三步

```
① 圈板块 → 拉成分股（东财 fs=b:BKxxxx）
   ↓
② 只保留 zt20≥1 或 max_lb≥2 的（慢牛全部剔除）
   ↓
③ 三道否决：
   · 股东户数近期暴增 >30%      → 已派发，剔除
   · 距 MA30 > +25%            → 高位，追不得
   · 量比 <0.3（一字板封死）    → 买不进，只能看
```

### 实测：825 只 → 62 只有涨停基因

**同一批票，按妖股基因筛出来的和按形态筛出来的完全不重合。**
完整扫描字段与优选案例见 `references/yaogu-gene-scan.md`。

**关键陷阱**：涨停基因够但户数暴增 = 派发完成，不是启动。
- 大晟文化 600892：20 日涨停 2 次，但**户数 +169.3%** → 剔除
- 国芳集团 601086：20 日涨停 3 次、最大 5 连板，但**户数 +78.6%** → 剔除

## 一、「主力还在 vs 主力在跑」七判据

**用户说「X 票主力还在」时，不要凭感觉附和，按六条硬判据打分再回话。**

| # | 判据 | 主力还在 | 主力在跑 | 取法 |
|---|---|---|---|---|
| **1** | **资金流 × 龙虎榜方向** | **两者同向** | **一正一负 = 对倒** | 新浪 MoneyFlow vs 东财龙虎榜 |
| **2** | **跌停/大跌日的龙虎榜** | **净买入**（接货） | 净卖出（出货） | 取大跌那天的行 |
| **3** | **股东户数变化** | 减少 / 持平 | **暴增 >30%** | 东财 RPT_HOLDERNUM_DET |
| **4** | **户均市值（权重最高）** | **>15 万**（大户主导） | **<8 万**（散户盘） | 同表 AVG_MARKET_CAP |
| **5** | **换手率** | 8-20% | **>35%（高速换手，无锁仓）** | 行情 f[38] |
| **6** | **PE / PB** | 合理 | **PE>90 或亏损** | 行情 f[39] / f[46] |
| **7** | **板块梯队** | **≥3 只同板块涨停** | **独苗 / 1 只** | 当日涨停池 hybk 计数 |

**打分口径**：几条达标就几分，**≥4 分可说「主力还在」，≤2 分直接说「在派发」**。

### 判据 4 是最高权重的（最容易被忽略）

**户均市值直接暴露「这票是谁在拿」：**

| 户均市值 | 含义 | 结论 |
|---|---|---|
| **>15 万** | 大户/机构主导，户数几千到一万多 | **能控盘，有主力生存的土壤** |
| 8-15 万 | 混合 | 中性 |
| **<8 万** | **散户盘**（户数几万到十几万） | **主力一走就踩踏，不具备持续拉升条件** |

**实测对比（2026-11-03 同一天三只）**：

| 股票 | 户均市值 | 户数 | 得分 |
|---|---|---|---|
| 新经典 603096 | **22.15 万** | 1.12 万 | **5/6** ✅ |
| 慈文传媒 002343 | 4.70 万 | 8.14 万 | 3/6 🟡 |
| 国芳集团 601086 | 9.29 万 | 8.77 万 | 1/6 🔴 |

**➜ 三只都是「20 日涨停 3-7 次」的妖股，但户均市值把它们分成了完全不同的三类。**

### 判据 1 的三种结果（决定能不能信资金流）

| 资金流（新浪） | 龙虎榜（东财） | 结论 |
|---|---|---|
| **+5.47 亿** | **+1.34 亿（同向）** | ✅ 真进场（慈文传媒 11/03） |
| **+5.94 亿** | **−0.59 亿（反向）** | 🔴 对倒，真实净卖（示例股A 10/30） |
| **+1.41 亿** | **−2.11 亿（反向）** | 🔴 对倒，真实净卖 2 亿（金健米业 11/03） |

**➜ 反向时以龙虎榜为准，直接定性「对倒出货」。这个判据已两次救场。**

### 判据 2 的反直觉用法

**跌停日的龙虎榜是主力意图的最强证据：**

- 慈文传媒 10/27 跌停 −10.00%，龙虎榜**净买 +1.62 亿（买 2.66 / 卖 1.04）**
  → **主力在跌停时接货**，不是跑
- 三天后（10/30）再跌停，11/03 反抽 +5.60% 且资金 +5.47 亿、龙虎榜 +1.34 亿（同向）
  → 印证判据 2 的判断

**➜ 只看「跌了 10%」会误判，必须看跌停当天龙虎榜是谁在买。**

## 一之二、判据 7 展开：板块梯队决定「能不能持续」

**用户原话**：「不知道是不是持续行情，要看板块」—— 这是对的，个股资金再强，板块没梯队也走不远。

**判法**：拉当日涨停池，按 `hybk` 统计同行业涨停家数。

| 板块内涨停家数 | 判定 | 含义 |
|---|---|---|
| **≥5 只** | 🟢🟢 强梯队 | 有龙头有补涨，资金乐意做 |
| 3-4 只 | 🟢 有梯队 | 够容纳资金 |
| **2 只** | 🟡 弱梯队 | 勉强，容易断 |
| **1 只（独苗）** | 🔴 **没梯队** | 孤军深入，游资不敢做 |

**2026-11-04 实测三组对照**：

| 持仓 | 所在板块 | 11/04 该板块涨停数 | 判定 |
|---|---|---|---|
| 示例股A | **元件** | **7 只** ⭐ | 🟢 有梯队（深南电路 1.47 亿封单、沪电 0.96 亿、金安国纪 1.41 亿…） |
| 新经典 | 出版 | **2 只** | 🟡 弱梯队（龙版传媒 3 板但炸 4 次、中信出版 1 板） |
| 百花医药 | 化学制药 | **1 只** | 🔴 无梯队（只有金陵药业） |

**➜ 结论直接可落地：超声有板块支撑（补涨逻辑成立）；百花是独苗（涨停也是孤军，次日开板概率高）；新经典板块弱（不适合加仓）。**

**完整实测样本（118 只涨停行业分布、元件 7 只封板时间明细、百花盘口）见 `references/sector-ladder-and-seal-timing.md`。**

### 「买盘厚 ≠ 会涨停」—— 必须叠加板块

**百花医药 11/04 盘口**：
```
买1  9.89 × 10,182 手  ← 一万手托单
买盘合计 13,980 手 vs 卖盘 3,628 手（3.9:1）
```
**光看盘口像要涨停，但化学制药板块只有 1 只涨停 → 涨停概率只给 40-45%。**

**➜ 盘口是「当下的力量」，板块梯队是「能不能走远的土壤」。盘口强 + 板块空 = 一日游。**

## 一之三、⚠️ 尾盘封板的质量问题（2026-11-04 实测）

**同样是涨停，封板时间不同，次日表现完全相反。**

| 封板时间 | 质量 | 次日风险 |
|---|---|---|
| **9:25-10:00 竞价 / 早盘封** | 🟢 最强（全天看多） | 次日高开概率大 |
| 10:00-13:00 盘中封 | 🟡 正常 | 中性 |
| **13:47-15:00 尾盘封** | 🔴 **抢筹性质** | **次日容易冲高回落** |

**实测**：2026-11-04 元件板块 7 只涨停（深南电路、沪电、金安国纪、华正新材、兴森科技、广合科技、海星股份）**全部是 13:47-15:00 尾盘封板**。

**➜ 封单 1.47 亿也不算强。封板资金是尾盘抢筹，不是全天持股意愿。次日不要追高，冲高即减。**

**取法**：涨停池 `fbt` 字段（首封时间），`93105` = 09:31:05。

## 一之四、「拉一天就跑」形态（比一次性派发更阴）

**特征**：先砸盘制造低价 → 某天拉涨停（龙虎榜净买，制造「主力回来了」的假象）→ 之后连续净卖。

**百花医药 600721 完整链条（2026-11）**：

| 日期 | 涨跌 | 资金流 | 龙虎榜 | 判读 |
|---|---|---|---|---|
| 10/16 | — | — | **−1.831 亿**（买1.27/卖3.10） | 大幅净卖 |
| 10/22 | −9.00% | −1.279 亿 | — | 砸盘 |
| 10/27 | −4.14% | −0.305 亿 | — | 继续砸 |
| **10/30** | **+9.96%** | **+3.681 亿** | **+1.562 亿**（买2.61/卖1.05） | **拉涨停，制造假象** |
| 11/02 | +1.53% | +0.085 亿 | **−0.516 亿** | 开始卖 |
| 11/03 | −4.31% | −0.957 亿 | — | 大跌 |
| **11/04** | +3.66% | −0.003 亿（超大单 **−0.152**） | **−0.345 亿** | 继续卖 |

**叠加股东户数：** 2026-06-30 的 32,359 户 → 2026-09-30 的 **117,603 户（+263.43%）**
**➜ 这是本 skill 记录过的最大户数暴增（超过金健米业 +77.75%）。**

**识别口诀**：**「涨停那天龙虎榜净买，但涨停后 2-3 天龙虎榜连续净卖」= 拉一天就跑。第一天是广告，后面才是生意。**

## 一之五、⭐ 超大单占流通盘比率（比绝对金额更硬的「重仓」证据）

**绝对金额会被市值骗**：同样是「超大单净流入 5 亿」，在 50 亿流通盘里是重仓建仓，在 500 亿里是路过。

```python
超大单占流通盘 = 单日超大单净额 / 流通市值
封单占流通盘   = 涨停封单金额   / 流通市值
```

| 超大单占流通盘 | 判定 | 含义 |
|---|---|---|
| **> 3%** | 🟢🟢 **重仓建仓级** | 一天买走 3% 以上流通盘，这是「选定标的」不是「试仓」 |
| 1-3% | 🟢 明确进场 | 正常主力建仓 |
| 0.3-1% | 🟡 一般 | 可以看 |
| **< 0.3%** | 🔴 无量 | 别当主力信号，可能只是大单撮合 |

### 铁律：这个比率可以推翻「有没有涨停基因」的判断

**2026-11-17 华胜天成 600410 实测：**

| 日期 | 走势 | 量能 | 主力净额 | **超大单** |
|---|---|---|---|---|
| 11/12 | +4.00% | 2.06x | +1.139 亿 | +1.421 亿 |
| **11/13** | **+10.00% 涨停** | 3.20x | **+17.437 亿** | **+11.007 亿** |
| 11/16 | 高 15.32 → 收 13.90（−2.80%） | 3.51x | +3.304 亿 | +2.434 亿 |
| **11/17** | **反包涨停 15.29** | 换手 7.90% | — | **封单 8.49 亿** |

- 流通市值仅 **167.65 亿** → 11/13 超大单 **11.007 亿 = 占流通盘 6.6%**
- 11/17 封单 **8.49 亿 = 占流通盘 5.1%**（当日全场最大，第二名 4.98 亿）
- 形态：涨停 → 次日冲高 15.32 **回落到 13.90 洗盘** → 再反包涨停 = 标准「洗盘后反包」

**但它的历史最大连板只有 2 板。**

**➜ 结果：按「基因 25% + 位置 15% + 主力 25% + 板块 20% + 大盘 15%」加权打分，它只有 62 分，被 70 分门槛挡在外面；实际上它是当天最强的一只。**

**➜ 修正规则：单日超大单 > 流通盘 3% 时，「主力重仓锁仓」的权重应当盖过「历史连板基因」，不要因为「史最大只 2 板」就降级。**

### 反向用法：比率低但金额大 = 假信号

- 大市值票「超大单 +5 亿」占流通盘 0.2% → 只是机构调仓，不是炒作
- 小市值票「超大单 +0.5 亿」占流通盘 2.5% → 可能是真控盘

**➜ 判断主力「有没有在做事」，先算这个比率，再看绝对金额。**

### ⚠️ 但要区分「被迫卖出」型的反向压制

**2026-11-17 同日反例**：PCB / 光模块板块出现「**多只重仓 AI 硬件的基金发清盘预警**」。
这是**被迫卖出**（净值跌破清盘线，基金经理必须卖），不是意愿问题。

**➜ 这类抛压会长期压制反弹，即使个股位置低、有资金回流也不该抢。**
**➜ 识别信号：板块连续下跌 + 消息面出现「基金清盘 / 被动赎回 / 强平 / 预警」字样。**

## 二、配套：「打折甩卖」四特征（判定派发完成）

已在该类分析中复用多次，四特征：

1. 短期暴涨（+30~240%）后见顶
2. 见顶后**连续大幅下跌**（−6% ~ −10% 连杀多日）
3. 下跌途中**缩量**（散户在捡便宜，主力慢慢出）
4. **股东户数同步暴增** ← **决定性证据**

**金健米业 600127（2026-11-03）完整案例**：
暴涨 239%（5.03→17.05）见顶 → 连 9 根大阴跌 43%（16.75→9.54）→ 下跌缩量 0.58-0.80x
→ **户数一个季度 94,848 → 168,589（+77.75%）**，户均仅 5 万。
当日资金流 +1.41 亿 vs 龙虎榜 −2.11 亿 = 对倒。
**四条全中 → 判定「不是启动，是打折甩卖后的反弹」。**

## 四、Pitfalls

- **别把「形态标准」当成「有妖性」**：横盘+地量+放量洗盘+反包，慢牛也能走成这个形态。
  **先看涨停基因，先看涨停基因，先看涨停基因。**
- **户均市值比户数更有效**：户数 8 万但户均 22 万，仍可能是大户控盘；户数 1 万但户均 4 万，是散户抱团。
  **两个一起看，户均优先。**
- **资金流单独看会被骗**：两次实测（超声、金健）都是资金流大幅流入、龙虎榜大额净卖。
  **必须两个数据源交叉，反向即判对倒。**
- **跌停日龙虎榜不能漏看**：这是判据 2，也是慈文传媒「主力还在」结论的唯一支撑点。
- **换手 40%+ 不是「活跃」是「没锁仓」**：一天换掉四成筹码，持仓者天天在变，不存在稳定筹码。
- **PE 亏损 + PB >4 + 户数暴增 三条同时出现，基本可以判定为末期**（慈文传媒：PE−103 / PB4.27 / 户数+121.94%）。
- **涨停基因的 20cm 判定**：创业板/科创板（300/301/688/689 开头）用 19.5%，其余用 9.5%，
  否则会把 20cm 的涨停漏掉。
- **买盘厚 ≠ 会涨停**：百花医药 11/04 买1 挂 10,182 手、买卖比 3.9:1，但板块只有 1 只涨停，
  涨停概率仍只给 40-45%。**盘口是当下的力量，板块梯队才是能不能走远的土壤。**
- **涨停封单大 ≠ 板强，要看首封时间**：11/04 元件 7 只涨停全是 13:47-15:00 尾盘封，
  封单最大 1.47 亿也不算强。**尾盘封是抢筹，次日容易冲高回落。**
- **「涨停日龙虎榜净买」不代表主力回来了**：要看涨停后 2-3 天是否连续净卖
  （百花医药：10/30 净买 1.562 亿 → 11/02 净卖 0.516 亿 → 11/04 净卖 0.345 亿 = 拉一天就跑）。
- **用户持仓成本一律按截图/明示取，不要自己推**：本会话两次算错（示例股B按 12.70 实际 13.527、
  超声按 22.20 实际 24.195），差 4-5 个百分点会误导全部减亏建议。
