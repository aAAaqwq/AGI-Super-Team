### ⭐⭐ 3.2.3 「追高」的正确定义（推翻旧认知）

**「不要追高」这句话只说对了一半。回测数据表明：**

| 情形 | T+5 均值 | 胜率 | 判定 |
|---|---|---|---|
| 涨停 **且** 连续3日超大单流入 **且** 累计<5亿 | **+11.32%** | **71%** | ✅ **该追** |
| 涨停 **但** 只有单日流入 | +2.82% | 53% | ❌ 不该追 |
| 大涨 >6% 但无连续流入 | +2.06% | 52% | ❌ 不该追 |
| 连续流入但当日跌 | +1.50% | 55% | 🟡 可埋伏，但慢 |

**➜ 正确表述：**
- ❌ **追高 = 价格上涨但资金不连续**（博纳 11/16 买在 6.77，11/13 只流入 1 天）
- ✅ **追强势 = 价格突破 + 资金连续 3 日流入 + 累计<5亿**

**➜ 两者形态相似（都是涨停/大涨），但后续差 4 倍。**

### 3.2.6d ⭐⭐⭐ 赔率结构与操作要求（这是能不能赚钱的关键）

**消除重复后的赔率（72 只股票，每只 1 次）：**

```
盈利 48 次（67%），平均 +16.37%
亏损 24 次（33%），平均 -8.31%
盈亏比 1.97 : 1
中位收益 +4.80%
```

**➜ 这是「中高胜率 + 中高赔率」策略，但**必须满足三个执行条件**，否则期望会转负：**

| 条件 | 原因 | 不做会怎样 |
|---|---|---|
| **① 必须严格止损（-5% ~ -8%）** | 33% 的信号会亏，平均亏 8.31%；不砍会拖到 -15%+ | 期望从 +8% 变负 |
| **② 必须让利润奔跑（不设固定止盈）** | 12.8% 的信号涨超 30%，是收益主要来源 | 只能吃 +3% 到 +4.8%（中位数） |
| **③ 单票仓位 ≤2 成，同时拿 3-5 只** | 收益集中在少数票（前5只占57%），押单只会错过 | 命中率再高也可能颗粒无收 |
| **④ 同一只票只做第一次信号** | 新华传媒 6 次信号、九阳 3 次，后几次效果衰减 | 重复追同一只票收益递减 |

**➜ 一句话：这个信号是「收集长尾」，不是「稳定小赚」。单次中位 +4.8%，靠少数大赢家（+30%以上）把均值拉到 +8%。**

**➜ 实操：优先 80-500 亿区间，尤其 120-200 亿（胜率 83%，虽样本仅 18 个）。**

```
① 今日涨停（或涨幅 >9.5%）
        ↓
② 流通市值 ≥50 亿吗？  否 → 放弃（小盘 T+5 仅 +1.34%，胜率 41%）
        ↓ 是
③ 拉东财 fflow 近 5 日超大单
        ↓
④ 连续天数 ≥3 吗？  否 → 放弃（单日流入 T+5 仅 +2.82%）
        ↓ 是
⑤ 3 日累计在 0.5~5 亿吗？  否 → 降级（>5亿 T+5 仅 +0.32%）
        ↓ 是
⑥ 所属板块当日热度 TOP20% 吗？  否 → 降级（40-60% 只有 +3.79%）
        ↓ 是
⑦ ✅ 真金三连·热板 → T+5 期望 +9.58%（中小盘）/ +9.17%（大盘，胜率77%）
```

```python
# 1. 拉近 5 日资金流（东财接口）
rows = fflow(secid)  # 见 3.2 ① 的接口
sup = [r["sup"] for r in rows[-5:]]   # 超大单，单位亿

# 2. 判连续性
streak = 0
for v in reversed(sup):
    if v > 0: streak += 1
    else: break

# 3. 打分
cum3 = sum(sup[-3:])
if streak >= 3 and cum3 < 5:
    grade = "⭐⭐⭐ 最优（T+5 期望 +11.32%，胜率 71%）"
elif streak >= 3:
    grade = "⭐⭐ 可做（T+5 期望 +7.52%）"
elif streak == 2:
    grade = "⭐ 弱（T+5 +0.38%，不如基准）"
else:
    grade = "❌ 单日流入，不做（T+5 +0.02%）"
```

**➤ 一句话：宁可等第二天确认「连续」，也不要赌第一天「单日」。**

**② 冲高不进钱（最隐蔽的出货信号）**

**③ 涨停封单质量**

| 封单 | 判定 | 交易含义 |
|---|---|---|
| **0.2 - 1 亿** | 🟢 健康 | 能买能卖，有换手 |
| 1 - 3 亿 | 🟡 偏强 | 仍有换手空间 |
| **> 3 亿** | 🔴 一字板 | 买不进（日出东方 13.22 亿） |
| **< 0.1 亿** | 🟠 分歧大 | 随时开板 |

**必算占比**：`封单占流通盘 = 买一量(股) / 流通股本`
- \>3% 极强 / 1.5-3% 强 / 0.5-1.5% 一般 / <0.5% 弱

**④ 炸板次数**

| 炸板次数 | 判定 |
|---|---|
| 0-2 次 | 🟢 强（抛压已消化） |
| 3-4 次 | 🟡 分歧 |
| **≥5 次** | 🔴 高位派发（日出东方 7 次、文投控股 7 次） |

**⑤ 外盘占比（主动买卖方向）**

```python
# 腾讯行情 f[7]=内盘 f[8]=外盘

```
