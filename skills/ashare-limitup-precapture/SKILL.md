## 〇、先记住这条铁律（2026-11 血泪教训）

**强势股不会给你「回踩 MA5」的机会。**

2026-11-09 锋龙股份首板 43.86，我给的买点是「等回踩 MA5 40.90」。
结果：11/10 高开 +4.88% 开 46.00 → 11/11 +9.39% 开 52.78 → 11/12 4 板 58.39。
**从 43.86 到 58.39 涨 33%，全程没回踩过一次。**

**➜ 对「板块梯队最好 + 有连板基因」的票，买点是「首板次日高开 3-5% 且不破前日低」，不是等回踩。**

## 一、五维筛选（启动前必须全过）

### 维度 1：个股基因（能不能连板，天生注定）

**先查这个，不合格直接淘汰，不要看其他维度。**

```python
def streak_gene(code, days=250):
    """返回历史连板段长度列表，如 [6,2,1]"""
    k = json.loads(fetch(f"https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,{days},qfq"))
    rows = k['data'][code].get('qfqday') or k['data'][code].get('day')
    c = [float(r[2]) for r in rows]
    runs=[]; cur=0
    for i in range(1,len(c)):
        if (c[i]/c[i-1]-1)*100 >= 9.8: cur+=1
        else:
            if cur>0: runs.append(cur)
            cur=0
    if cur>0: runs.append(cur)
    return sorted(set(runs), reverse=True)
```

| 历史最大连板 | 判定 | 处理 |
|---|---|---|
| **≥5 板** | 🟢🟢 强基因（游资熟） | 优先 |
| **3-4 板** | 🟢 有基因 | 可做 |
| **2 板** | 🟡 弱基因 | 谨慎 |
| **1 板或 0** | 🔴 无连板基因 | **直接淘汰** |

**真实数据（2026-11-12 实测）**：

|---|---|---|
| 锋龙股份 | **3 板** | 4 连板 ✅ |
| 兴欣新材 | **3 板** | 首板封死 ✅ 候选 |
| 安阳钢铁 | 1 板 | 首板，不做连板博弈 ❌ |
| 超颖电子 | 1 板 | 首板，无基因 ❌ |
| 泰嘉股份 | 0 板 | 首板，无基因 ❌ |

**⚠️ 2026-11-12 实测结论：45 只涨停股中，位置低的 5 只首板（超颖电子/安阳钢铁/大西洋/中捷资源/泰嘉股份）历史最大连板全部 ≤1 —— 这就是为什么它们只能是一日游。**

### 维度 3：⭐ 主力意图（最硬的证据，本 skill 核心）

**主力做一只票，必然留下四个足迹。看着四个，就知道他在哪个阶段。**

#### 3.1 主力意图四阶段识别表

| 阶段 | 形态特征 | 量能 | **超大单** | 判定 |
|---|---|---|---|---|
| **① 建仓** | 放量试盘（涨 3-7%）→ 缩量洗盘（跌 1-3%） | 试盘 4-8x → 洗盘 0.5-1.5x | 连续小幅流入 | 🟢 准备做 |
| **② 拉升** | 首板 → 连板，每板换手 5-15% | 7-9x | **大幅流入（单日 >1 亿）** | 🟢 可参与 |
| **③ 派发** | **冲高但不进钱** / 涨停封不住 / 高换手 | 4-8x | **由流入转流出** | 🔴 立刻走 |
| **④ 崩塌** | 连续阴跌，反弹无力 | 逐日萎缩 | 持续流出 | 🔴🔴 不碰 |

### 维度 5：大盘环境（时机对不对）

| 指标 | 健康区间 | 危险信号 |
|---|---|---|
| 涨停家数 | **40-80 只** | <30（冰点，连板难）/ >100（过热，次日易炸） |
| 跌停家数 | 0-5 只 | **>10 只（危险）** |


## 二、与其他涨停股的卡位关系（决定你能不能上车）

**同一个板块，3 只以上涨停时，要分清谁是龙一、龙二、跟风。**

| 角色 | 判定标准 | 连板概率 |
|---|---|---|
| **龙一** | **首封时间最早**（9:25-9:35）+ 封单最大 + 连板最高 | 🟢🟢 最高 |
| **龙二** | 跟风但封板早、有独立逻辑 | 🟢 中等 |
| **跟风（第3只以后）** | 板块已涨停 2 只后才封 | 🔴 次日大概率掉队 |

**取法**：拉板块涨停池，按 `fbt`（首次封板时间）排序。

```python

GET https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989
  &dpt=wz.ztzt&Pageindex=0&pagesize=400&sort=fbt%3Aasc&date=YYYYMMDD
```

**2026-11-12 实例**：
```
通用设备板块涨停 4 只：
  锋龙股份 4 板（9:25 首封，封单 0.97 亿）
  日发精机 2 板（9:25 首封，封单 2.30 亿）
  泰嘉股份 1 板

```

**⚠️ 跟风股的陷阱**：板块龙头 3 板时，第 4 只跟风涨停的票，次日只有 20-30% 概率续板。

## 三、买入时机规则（三档，按确定性排序）

### 档 1：首板次日高开接力（最推荐）

**条件（必须同时满足）**：
```
① 昨日首板（涨停）
② 今日高开 3-5%（不是一字板，也不是平开）
③ 开盘不破昨日最低价
④ 板块昨日涨停 ≥3 只
⑤ 个股史最大连板 ≥2
```

**操作**：开盘 9:30-9:35 直接买，仓位 2 成，止损昨日最低价。

**真实案例（锋龙股份）**：
```
11/09 首板 43.86（最低 41.28）
11/10 高开 46.00（+4.88%），最低 46.00（不破 41.28）✅
       → 46.00 买入 → 11/12 58.39，获利 26.9%
```

### 档 2：洗盘后放量突破（次优）

**条件**：
```
① 首板后回调 1-3 天，量能逐日萎缩
② 超大单仍为净流入（大资金没跑）
③ 放量突破首板收盘价
```

**操作**：突破当日买，仓位 1-2 成，止损首板日最低价。

**真实案例（示例股H）**：
```
11/09 首板 4.20（主力 +1.553 亿，超大单 +1.099 亿）
11/10-11/12 回调 3 天，量能 2.44→1.79→1.05 递减
11/11 超大单仍 +0.162 亿（没跑）
➜ 等放量突破 4.20 买，止损 3.86
```

### 档 3：二板后打板（最激进，不推荐）

**只在板块 ≥5 只涨停 + 市场最高连板 ≥5 板时考虑。**

**操作**：竞价排队打板，仓位 1 成，次日不涨就走。

### ⚠️ 一票否决（硬规则，不看总分）

|---|---|---|
| **位置过高** | 距 MA30 **> +25%** | 高位接盘（襄阳轴承 3 板 +47.5%、日出东方 5 板 +51.1%、锋龙 4 板 +35.1%） |

## 七、Pitfalls（血泪教训）

- **🔴🔴🔴 数据源口径不同，符号可能相反（2026-11-17 实测）**：华胜天成 11/16
  - 新浪 `zjlrqs`：净 **+3.304 亿**，超大单 **+2.434 亿**（流入）
  - 东财 `fflow/daykline`：主力 **−6.139 亿**，超大单 **−4.482 亿**（流出）
  - **同一天、同一只票，两个主流数据源的超大单符号完全相反。**判断「连续流入」时**必须固定一个源**，否则结论会 180 度反转。
  - **推荐用东财 fflow**（`push2his.eastmoney.com/api/qt/stock/fflow/daykline/get`）：可拿 120 天历史、自带收盘价、口径更严格（超大单 = 单笔 ≥100 万且占流通盘 ≥0.2%）。
  - 新浪的优势只是「当日实时更快」，做**连续性判断时不要混用**。

- **🔴 不要用「等回踩 MA5」对待强势股** —— 锋龙 43.86→58.39 全程没回踩，错过 33%。强势股的买点是「高开接力」，不是等回调。
- **🔴 位置 > +25% 一律不追** —— 东方环宇 4 板距 MA30 +38.1%、锋龙 4 板 +35.1%，这个位置接力就是接盘。
- **🔴 看超大单，不看总净额** —— 云煤 11/11 净流出 0.175 亿但超大单 +0.162 亿（洗盘）；思美 11/11 净流出 0.662 亿超大单 −0.087 亿（派发）。同样的"流出"，含义相反。
- **🔴 冲高不进钱 = 出货** —— 东方创业 11/10 冲 8.50 只进 0.077 亿，是明确出货信号，第二天就崩。
- **🔴 炸板 ≥5 次不碰** —— 日出东方 5 板炸 7 次、文投控股 4 板炸 7 次，高位分歧极大。
- **🔴 无涨停基因的票不做连板博弈** —— 2026-11-12 实测：位置低的 5 只首板股史最大连板全部 ≤1 板，注定一日游。
- **🔴 换手 >25% 的涨停不追** —— 思美传媒换手 24.70%，说明筹码一天换掉 1/4，随时崩。
