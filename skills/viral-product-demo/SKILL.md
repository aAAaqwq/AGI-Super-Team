# 爆火产品演示宣传视频脚本生成器

## 核心原则

1. **不卖功能，卖一段完整的用户旅程**。观众不关心你有多少功能，关心你能不能把他每周都在做的一件事跑完。
2. **不吹全自动，吹"人机协同"**。主动暴露产品边界（"它停下来等我确认"）比"一键搞定"可信十倍。
3. **具体 = 真实**。所有数字、场景、人物、行业术语都要具体，禁止"很多""大量""优秀"这类抽象形容词。

## 工作流

### 第 1 步：明确产品定位（必须先问清）

在动笔前，向用户确认以下信息（缺什么问什么，不要一次性问太多）：

- 产品名称、面向客户（什么角色/行业/规模的人）
- 产品最强的 1-2 个能力（决定用哪段用户旅程做主菜）
- 竞品或对标片（如有）
- 视频时长预期（60秒短视频 / 3-5分钟中视频 / 8分钟长测）
- 投放平台（抖音 / 视频号 / 小红书 / B站 / YouTube）

如果用户没给全，先用默认假设出一版，并在脚本开头标注假设。

### 第 2 步：选用户旅程

从用户真实工作流中选一条**产品最强、且至少含 3 个环节**的完整链路做主线。不要把所有功能都塞进一条片子。

常见可选链路类型（按产品类型选）：

| 产品类型 | 可选主链路 |
|---|---|
| AI Agent / 办公助手 | 接到任务 → 自主找上下文 → 调工具执行 → 交付结果 |
| 设计/创意工具 | 输入需求 → 自动生成 → 人工微调 → 导出交付 |
| 数据/分析工具 | 接入数据 → 自动清洗 → 生成图表 → 输出洞察 |
| 电商/营销工具 | 建活动 → 选品定价 → 生成素材 → 投放监测 |
| 教育/培训产品 | 布置任务 → 学生完成 → AI批改 → 个性化反馈 |
| 客服/CRM 工具 | 接入咨询 → 自动分类 → 生成回复 → 同步工单 |
| 金融/财务工具 | 导入账单 → 自动分类 → 生成报表 → 风险提示 |
| 协作/项目管理 | 创建项目 → 自动分配 → 进度追踪 → 生成周报 |

**选链路的标准**：这条链路必须是目标用户每周都在做、且做起来很痛的事。

### 第 3 步：搭结构

按 `references/viral-structure.md` 中的时间轴骨架填充。每个环节严格走"抛任务 → 下指令 → AI执行 → 遇卡点 → 交付物 → 轻评价"六拍。

### 第 4 步：写脚本

按 `references/script-template.md` 的分镜表输出，每个镜头包含：
- 时间码
- 画面（录屏 / 真人出镜 / 特写）
- 旁白/口播原文
- 屏幕上出现的关键文字
- 该镜头植入的卖点（如果有）

### 第 5 步：自检

交付前逐项核对：
- [ ] 前 15 秒是否有"痛点 + 反转 + 承诺"三件套
- [ ] 全片是否有至少 1 处"产品遇到卡点停下来等人"的细节
- [ ] 所有数字是否具体（N个、N份、N次），有没有抽象形容词
- [ ] 卖点是否全部"顺便"带出，没有一句硬广
- [ ] 结尾是否是"行业判断 + 产品收口"，而不是"快来下载"
- [ ] 标题和标签是否给出 3 套备选

## 输出物规范

默认交付一份 Markdown 分镜脚本，包含：
1. 一句话选题
2. 目标平台与时长
3. 分镜表（时间码 / 画面 / 旁白 / 屏幕文字 / 植入卖点）
4. 3 套备选标题
5. 标签组合建议
6. 拍摄注意事项（录屏分辨率、语速、BGM 风格）
