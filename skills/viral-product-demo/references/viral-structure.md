# 爆款结构详解

## 时间轴骨架（8分钟长测版，可等比压缩到3-5分钟）

| 段落 | 时长占比 | 作用 |
|---|---|---|
| 开场钩子 | 前 15 秒 | 完播率生死线 |
| 场景引入 | 15-40 秒 | 把产品放进真实剧情 |
| 环节 1（主菜 A） | 40 秒 - 2 分钟 | 第一个 wow moment |
| 环节 2（主菜 B） | 2-3 分钟 | 展示协同/权限/上下文理解 |
| 环节 3（主菜 C） | 3-4 分钟 | 跨工具操作/自动化 |
| 环节 4（主菜 D） | 4-5 分钟 | 批量处理/高级功能 |
| 环节 5（主菜 E） | 5-6 分钟 | 深度执行/操作外部系统 |
| 环节 6（主菜 F） | 6-7 分钟 | 生成工具/团队复用 |
| 结尾升华 | 最后 20-30 秒 | 把产品放进行业叙事 |

短视频（60秒）压缩版：
- 前 5 秒：痛点 + 反转
- 中间 45 秒：只跑 1 个最强环节，走完整六拍
- 最后 10 秒：一句判断 + 轻号召

## 开场钩子三件套

```
[痛点] ______（目标用户）每天最耗时间的，不是______本身，而是______。
[反转] 以前我要______（切N个软件/手动做XX），现在我用______一句话搞定。
[承诺] 今天我用一个真实的______需求，从______到______全流程跑一遍。
```

### 钩子变体

- **数字型**："每天花3小时在重复操作上，其中2小时是无意义的。"
- **反差型**："我用AI完成了一项工作，全程只手动点了3次鼠标。"
- **吐槽型**："你们是不是也这样？一个工作要切5个软件，复制粘贴20次。"
- **身份型**："做了8年XX，第一次觉得这件事终于可以'躺'了。"

## 六拍节奏（每个环节都走一遍）

每个工作流环节严格按这六拍：

1. **抛任务**："现在我要做______，以前要______。"（先讲以前有多麻烦）
2. **下指令**：对着屏幕输入一句话指令（录屏一定要录到输入框）。
3. **产品执行**：快放/倍速展示，旁白讲"它自己在做______"。
4. **遇卡点**（强烈建议有）："它发现需要______，停下来等我操作/确认。"
5. **交付物**：展示结果——表格、报告、文档、图表、评分。
6. **轻评价**："这个结果我没想到/比我自己做的还细。"（一句就够，不要夸成演讲）

## 信任建立四招

### 1. 主动暴露边界
不要说"全自动一键搞定"，要说"它会在需要人决策时停下来等确认"。产品的边界被展示出来，观众反而相信其他部分是真的。

### 2. 具体数字替代形容词
- ❌ "很多数据" → ✅ "处理了127条记录"
- ❌ "不少文件" → ✅ "解析了23个文件"
- ❌ "有些问题" → ✅ "15道题，每道3个进阶追问"
- ❌ "效率很高" → ✅ "以前要3小时，现在20分钟"

### 3. 真实剧情细节
- 具体人名："老板在群里说""张总发邮件要"
- 具体场景："周五下班前""客户明天就要"
- 具体行业术语：用目标用户每天说的话，不要用营销话术
- 具体时间："上周""昨天下午"

### 4. 超出预期的"额外洞察"
在交付物之外，产品多输出了一个没想到的结论（行业洞察、数据趋势、异常发现）。这是全片最容易被截图传播的瞬间。

## 卖点植入时机表

| 卖点类型 | 最佳植入时机 | 植入方式 |
|---|---|---|
| 核心壁垒（系统打通/数据权限/独家模型） | 第一次登录/授权时 | 顺口一句"这样它就能读取______了" |
| 免费额度/试用 | 第一次进入产品时 | "新用户送30天，今天用的就是这个额度" |
| 高级功能（云跑/批量/跨设备/API） | 在"量一大就费时"的痛点后 | "像这种批量的，我改用云跑，不占本机资源" |
| 团队协作/分享 | 最后一个环节 | "生成链接发给同事，大家复用同一套标准" |
| 数据安全/权限 | 提到"在我的权限范围内"时 | 自然带过，不要专门讲 |
| 生态集成（飞书/钉钉/Slack/Office） | 产品和生态联动时 | "它直接打通了飞书，不用手动导出导入" |

**铁律：全片不出现"真好用""太牛了""强烈推荐""YYDS"这类硬广词。**

## 结尾升华公式

```
[行业判断] 以后______（这类工作）的竞争，不是谁功能多，而是谁真的能______。
[产品收口] 这次实测下来，______（产品名）最让我意外的是______。
[轻号召] 如果你也在被______折磨，可以去试试。下期见。
```

### 行业判断的写法
- 不要说"我们产品很好"，要说"这个行业正在发生什么变化"。
- 把产品放进趋势里："AI进入工作现场""从个人提效到团队提效""从功能比拼到流程理解""从工具到Agent"。
- 观众觉得"这是趋势"，才会觉得"用这个产品是站在趋势上"。

## 标题公式

1. **痛点型**：`不用切换N个软件，一套工具完成______！`
2. **实测型**：`用真实______流程实测______：AI真的进工作现场了`
3. **猎奇型**：`人类对______的开发不足百分之一，它还能干这个`
4. **数字型**：`每天省2小时，我用______把______全跑通了`
5. **反常识型**：`原来______根本不需要______，一个工具就够了`

## 标签组合

- 精准人群：`#你的目标用户标签`（如 `#HR` `#设计师` `#运营` `#产品经理`）
- 产品名：`#你的产品名`
- 生态背书：`#飞书` `#企业微信` `#钉钉` `#Slack`（如有集成）
- 泛流量：`#AI办公` `#Agent` `#人工智能` `#效率工具` `#干货`
- 情绪/猎奇：`#还能干这个` `#居然可以这样`
