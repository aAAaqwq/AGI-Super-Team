# 分镜脚本模板

## 输出格式

每次输出脚本时，按以下结构组织：

```
# 一句话选题
（一句话说清这条片子讲什么）

# 目标平台 / 时长
抖音竖屏 9:16 / 8 分钟（或按实际）

# 分镜表

| 时间码 | 画面 | 旁白/口播 | 屏幕文字 | 植入卖点 |
|---|---|---|---|---|
| 00:00-00:05 | ... | ... | ... | ... |
| 00:05-00:15 | ... | ... | ... | ... |
| ... | ... | ... | ... | ... |

# 备选标题（3套）
1. ...
2. ...
3. ...

# 标签组合
#目标用户 #产品名 #...

# 拍摄注意事项
- 录屏分辨率：...
- 语速：...
- BGM：...
```

## 短视频（60秒）压缩版结构

| 时间 | 内容 |
|---|---|
| 0-5秒 | 痛点 + 反转钩子 |
| 5-20秒 | 场景引入 + 输入指令 |
| 20-40秒 | 产品自动执行（快放）+ 卡点停下 + 交付物展示 |
| 40-50秒 | 轻评价 + 一个额外洞察 |
| 50-60秒 | 一句行业判断 + 轻号召 |

## 拍摄注意事项

- **录屏分辨率**：1080p 起步，竖屏 9:16（抖音/视频号/小红书）或横屏 16:9（B站/YouTube）。
- **输入框一定要录到**：让观众看到你真的输入了一句话指令，这是"实测感"的核心证据。
- **语速**：旁白偏快（每分钟 220-250 字），但在"交付物展示"时放慢半拍。
- **BGM**：轻电子/Lo-fi，音量压到人声的 20% 以下，不要用旋律太强的。
- **字幕**：硬字幕全片都加，关键词（产品名、核心动作）用强调色。
- **倍速**：产品自动执行过程用 1.5-2x 快放，但遇到"卡点"和"交付物"时恢复原速。
