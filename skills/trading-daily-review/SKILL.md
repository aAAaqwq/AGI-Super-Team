# A股每日交易复盘

按用户的每日实盘操作生成结构化复盘记录：记录操作 → 核验产业逻辑 → 生成复盘文档（MD + HTML）→ 飞书私聊发送。用户每天收盘后/盘后会分享操作，这是高频复现工作流。

## 触发条件
- 用户分享当日买卖操作（"今日复盘：10.25 买入某股…"）
- 用户要求"写好今日的复盘记录"、"记录一下我的操作"
- 用户持仓标的涉及 A 股个股，需要产业逻辑核验

## 流程（5 步）
1. **记录操作**：从用户消息提取 标的 / 方向 / 成交价 / 买入逻辑，结构化为表格
2. **逻辑核验**：对每只标的调用 `jiuyangongshe-stock-industry-logic` 技能（`python3 scripts/fetch_stock_logic.py "股票名" --delay 2`），取异动解析 + 相关文章，对照用户买入逻辑给出 ✅吻合 / ⚠️不一致 结论；**深挖相关文章里的政策/事件催化**（可能是比题材更硬的逻辑，如公积金装修提取点名金螳螂）
3. **生成 MD 文档**：保存到 `docs/trading-daily/YYYY-MM-DD-复盘.md`（结构见 templates/daily-review-template.md）
4. **转 HTML**（移动端阅读）：用 Python markdown 库 + 内置样式模板（见 templates/daily-review-template.md 底部的 style 块）
5. **发送**：`hermes send -t "feishu:oc_<your-chat-id>" "MEDIA:<md路径>"` 与 HTML 各发一次（用户飞书私聊 DM）
6. **同步盯盘配置**（别漏）：当天新买入的票 → 加进持仓盯盘脚本 `WATCH`（代码/名称/**成本价**/规则）；已清仓的票 → 从 `WATCH` 移除。做法见 skill `position-alert-watchdog`。
   主动提一句「已把 XX 加入/移出盯盘」比等用户来问更好——用户买完票的下一步通常就是要求盯盘。

## 用户交易纪律（必须写入文档）
- 每日策略：继续持有，静待涨停
- **止损线：开盘跌幅 > -5% 无条件离场**（用户原话："开盘不>-5%将继续持有"）
- 文档必须包含「次日关注要点」（题材热度延续性、资金/连板情绪承接、政策催化节点）和「明日计划」

## 陷阱
- **韭研公社搜索页 content 是截断摘要**（异动解析的题材标签+编号要点齐全，足以核验逻辑）；详情页正文需登录，公开抓不到全文——不要承诺/编造完整正文
- **一篇异动解析可含多只股票标签**：判断是否真讲该股以 content 为准，不以标题（搜"英维克"命中的第一条可能是"金富科技异动解析"）
- **逻辑分层标注**：资金/技术面逻辑（尾盘拉升、连板）与站内基本面逻辑（题材/订单/政策）往往是两条线——分别标注，明确哪个是硬催化（如政策落地日期），哪个是情绪（如无约束力备忘录+澄清公告）
- **数据如实标注**：登录墙内容（销量/营收/分页）标 UNKNOWN，不编造
- **数据实时变化**：站内 totalCount 会随交易日增长（如白银有色异动解析 39→40 条），复盘引用时以当日抓取值为准
