# 公众号文章分析

一键式工作流：**获取 → 结构化理解 → 外部核查 → 批判性阅读地图**。

## 触发条件

- 用户提供 `mp.weixin.qq.com/s/...` 链接并要求分析/解读/拆解/评价
- 用户粘贴公众号文章正文并要求深度分析
- 用户要求判断公众号文章可信度、论证质量或宣传手法

## 前置约束

1. 公众号域名 `mp.weixin.qq.com` 通常被 robots.txt 禁止自动抓取：**先尝试 web_fetch，若返回 robots 拒绝错误，立即改用真实浏览器（open_url_in_browser + 滚动读取），禁止绕过 robots 或换爬虫通道**。
2. 分析内核必须按 `doubao-critical-reading-companion` 执行：先读其 SKILL.md 及 4 个 reference（protocols / argument-reconstruction / evaluation-guidelines / fact-checking），再按其模板输出。
3. 外部事实核查只针对会改变核心判断的事实，核查状态只能用：支持／部分支持／不支持／证据不足／待外部核查／未执行外部核查。未检索时禁止用"支持、属实、已验证"。

## 工作流

### Step 1 获取全文

1. `web_fetch` 抓取链接（分页读完全文，`end_offset >= total_length`）。
2. 被拒（robots/验证/空内容）→ 真实浏览器打开，滚动逐屏读取，记录：
   - 标题、作者/账号、编辑、发布时间线索
   - 全部小节标题与核心段落定位（8-20 字可搜索短语）
   - 文末参考资料链接、图片来源（截图 OCR 关键引语）
3. 全文获取失败 → 告知用户受限原因，绝不编造正文。

### Step 2 结构化理解

按 critical-reading 流程：议题、核心结论、文本目的、目标受众、文本协议（信息/论证/说服，混合按主导机制）。

### Step 3 外部核查（必须执行）

- 对高影响事实（数字、引语、事件时间线、因果主张）执行实际检索，优先官方/一手来源。
- 对照文章发布时间与事件发生时间。
- 记录每个来源：标题、机构、日期、可访问链接、访问日期。

### Step 4 输出阅读地图

- 默认**完整模式**（使用指南 / 一句话判断 / 议题与结论 / 核心论点卡 / 说服力 / 保留判断 / 外部事实核查表 / 文章没告诉你的 / 论证增强 / 下一步核查 / Mermaid 论证链）。
- 文本短或用户要求快判 → **快速快判模式**。
- 交付：对话正文输出；内容长时另存 Markdown 文件交付。

## 输出模板

完整/快速模板与 Mermaid 要求一律沿用 `doubao-critical-reading-companion` 的 SKILL.md 模板（完整模式必含 Mermaid 论证链；Word 不插 Mermaid）。

## 失败处理

- 文章失效/404 → 说明并询问是否有备份或转载链接。
- 关键事实查不到可靠来源 → 标"待外部核查"，不猜测。
- 浏览器也无法访问 → 报告受限原因。
