## 模板 1：完整版一键生成（先出 10 秒试片）

```
现在你是这部片子的导演兼制作，由你来帮我做一部知识科普短片。

这部短片的主题是：{在这里写你的主题，比如：为什么越努力越焦虑？}

【规格】
- 1080P，30帧，尺寸是16:9横屏
- 用 Remotion 工程来做这部片子
- 可以使用任何想使用的技术
- 不需要为影片配音，使用中文字幕把片子讲清楚
- 动效要足够华丽但不杂乱

【视觉风格】
- 整体调性：{选填，比如：深空黑底 + 金色线条，科技感极简风格}
- avoid: 不要卡通风格，不要高饱和荧光色，不要廉价PPT感
- 画面之间不要硬切，要有丝滑的过渡
- 优先用同一个元素贯穿前后两个画面来转场
  例如一个圆从大到小变成下一个画面里的太阳，
  一条线延伸出来变成下一个画面的道路。
- 转场要短而干净，淡入淡出、闪白黑场只作为辅助

【音乐与卡点】
- BGM 风格：{比如：轻快的电子纯音乐，类似纪念碑谷OST}
- 先分析这首音乐的 BPM 和所有重拍位置，标出每个重拍的秒数
- 每次画面切换都必须落在重拍上
- 高潮段落要让画面、文案、音效三者同时爆发

【音效】
- 每个关键动作都要配一个音效（碰撞/出现/增长/消失）
- 音色用清脆的钢琴音、风铃音或电子音，类似纪念碑谷的音效质感
- 越关键的动作，音高越高

先只做开头 10 秒给我看效果，风格满意后再继续做完整条。
```

## 模板 2：风格三选一（定画风用）

```
基于主题：{你的主题}
给我出 3 个完全不同的视觉风格方案，每个方案包含：
1. 风格名称
2. 主色调和质感描述
3. 核心视觉元素（比如：粒子、线条、几何体、水墨笔触）
4. 适合讲述什么氛围的故事
5. 一个具体的开头画面描述

avoid:
- 不要常见的扁平PPT风格
- 不要廉价的渐变霓虹风
- 不要儿童卡通插画风
```

## 模板 3：分镜编排（脚本结构化）

```
主题：{主题}
核心知识点：{用一句话说清}
观众共鸣点：{观众会在自己生活中哪里遇到这个问题？}

请把这个知识点拆成 8-12 个镜头的分镜脚本，每镜 2-5 秒，总计 60-90 秒。

表格格式：
| 镜头 | 时间 | 画面描述 | 字幕文案 | 转场方式 | 重拍点 |
|------|------|----------|----------|----------|--------|

要求：
1. 第一帧必须有一个视觉锚点（一个突出的颜色/物体/动作）
2. 第一句话要直接戳中观众正在经历的事，不要背景铺垫
3. 每句字幕不超过 15 个字
4. 结尾抛一个与观众自身相关的、有争议性的问题
5. 每 15 秒要有一个小转折或情绪起伏
```

## 模板 4：迭代修改（局部调整用）

```
整体风格我满意了。

现在调整第 {X} 段（{时间段}）：
- 现在的问题是：{具体描述哪里不满意}
- 我想要改成：{具体修改方向}

只改这一段，其他部分保持不变，修改完输出新的 10 秒片段给我看。
```
