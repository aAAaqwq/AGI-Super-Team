# Vibe 知识大赏 · 视频创作 Skill

> 抖音 #vibe知识大赏 活动专属创作能力：用 AI 写代码生成氛围感知识科普视频，一段提示词做出 10w+ 播放的知识短片。
>
> **适用场景**：知识科普、心理学效应、诺奖解读、数学/物理概念、历史故事、哲学道理 → 用动画+音乐+音效讲明白。
> **不适用**：实拍口播、产品带货、剧情短剧、纯混剪影视片段。

---

## 一、什么是 Vibe 知识大赏

抖音 2026 年 9-10 月主推的知识类视频活动，核心特征：

| 维度 | 说明 |
|---|---|
| **制作方式** | 不是实拍，是 AI（Claude Opus 为主）写代码 → 用 Remotion/HyperFrames 渲染成动画视频 |
| **视觉风格** | 统一画风（水墨/极简/科技感/星空等），分层制作（背景层+动效层+文字层） |
| **音频** | 不配人声旁白，用中文字幕讲解；配 BGM + 关键动作音效（类似纪念碑谷音色） |
| **节奏** | 画面变化卡在音乐重拍上，音画同步 |
| **转场** | 丝滑过渡，不硬切，用同一元素贯穿前后镜头 |
| **时长** | 30 秒 - 2 分钟，横屏 16:9（也有 9:16 竖屏版） |
| **话题标签** | 必带 `#vibe知识大赏`，艾特 `@抖音科技` |

## 二、完整制作流程（6 步法）

### 第 1 步：选题与资料搜集

**选题原则**：
- 硬核知识（数学/物理/心理学/经济学/生物学）→ 最后落到人生道理/日常共鸣
- 蹭热点：诺奖公布、节日、社会热议话题
- 每个选题都要有一个"观众自己也经历过"的锚点

**执行动作**：
```
让 AI 联网搜索这个知识点的权威来源，整理成：
- 核心概念（1-2 句话说清）
- 关键人物/年份/实验/数据（必须有出处）
- 生活化类比（让普通人能懂）
- 对观众的启发（人生道理/实用建议）
查不到出处的内容直接删掉，不要编。
```

### 第 2 步：编排分镜脚本

把知识点拆成一幕一幕的视觉化脚本：

| 镜头 | 时长 | 画面描述 | 字幕文案 | 转场方式 |
|---|---|---|---|---|
| 1 | 0-3s | ... | ... | ... |
| 2 | 3-6s | ... | ... | ... |

**关键要求**：
- 每句字幕不超过 15 字，确保观众读得完
- 每个镜头 2-5 秒，不拖沓
- 开头 3 秒必须有视觉锚点（一个突出的颜色/物体/动作）
- 结尾抛一个与观众相关的问题（引发评论）

### 第 3 步：定视觉风格

**做法**：
1. 先让 AI 出 **3 个风格方案** 供选择
2. 明确写出 `avoid: 不要卡通风格/不要高饱和色/不要...)`
3. **必须先做 10 秒试片**，确认风格满意了再做完整条
4. 风格定稿后，提炼成通用模板，后续换主题直接套

**常见成功风格**：
- 宣纸底 + 水墨风（东方感，适合历史/哲学）
- 深空黑 + 金色线条（科技感，适合数学/物理）
- 暖色调极简插画（治愈感，适合心理学）
- 纪念碑谷式 3D 几何（现代感，适合抽象概念）

### 第 4 步：定技术规格 + 卡点

**基础规格**：
- 分辨率：1080P
- 帧率：30fps
- 画幅：16:9 横屏（或 9:16 竖屏）
- 配音：不配人声，用中文字幕
- 框架：Remotion（或 HyperFrames）

**音乐卡点（关键！）**：
```
先让 AI 分析指定 BGM：
- BPM（每分钟节拍数）
- 重拍位置（标出每个重拍的秒数）
- 高潮段落在哪几秒
要求：
- 每次画面切换都落在重拍上
- 文案高潮 + 画面高潮 + 音乐高潮 三者对齐到同一帧
- 重拍前 2-3 秒字幕故意说一半，重拍时补完+画面爆开+音效冲击
```

### 第 5 步：音效设计

- 每个关键动作配一个音效（碰撞、增长、消失、出现）
- 音色推荐：清脆的电子音/钢琴音/风铃音（纪念碑谷风格）
- 音高递进：数值越大/越关键的动作，音越高
- 直接让 AI 合成音效，不用自己找素材

### 第 6 步：逐段生成 + 迭代修改

**重要原则**：不要一次性让 AI 生成完整视频！

正确做法：
1. 先做开头 10 秒试片
2. 满意 → 继续做下一段
3. 不满意 → 只重做这一段，不影响其他部分
4. 风格问题先调通用模板，再批量生成

## 三、爆款 4 要素（数据验证）

根据多个创作者实测，同提示词同风格不同选题播放量差 10 倍以上，区别在这 4 点：

### 1. 开头 3 秒留人
- 第一帧要有视觉锚点（比如一片山里一个红点）
- 第一句话讲观众正在经历的事（不是背景介绍）
- ❌ 太平："1963 年气象学家洛伦兹..."
- ✅ 抓人："你有没有想过，你们俩差一秒就不会认识？"

### 2. 节奏感
- 字幕切换卡在音乐小节线上
- 音乐高潮时，画面+文案+音效一起爆
- 每 15 秒一个小转折

### 3. 结尾抛问题
- 问题必须与观众自身相关，且每个人答案不同
- ✅ "安稳算不算人生的最优解？" → 409 条评论
- ❌ "你学到了吗？" → 8 条评论

### 4. 丝滑转场
- 不用硬切，不用闪白黑场（仅作辅助）
- 用同一元素贯穿：圆→太阳/烛火，线→地平线/道路
- 镜头推进到细节 → 细节铺满成下一个场景
- 像一个连续长镜头，观众眼睛不用重新找重点

## 四、提示词模板

### 4.1 主提示词（完整版）

```
现在你是这部片子的导演兼制作。帮我做一部知识科普短片。

【主题】{在这里写你的主题，比如：蝴蝶效应 / 局部最优解 / 手性分子}

【规格】
- 1080P，30fps，16:9 横屏
- 用 Remotion 工程来做
- 不需要配音，用中文字幕把知识点讲清楚
- 动效要足够华丽但不杂乱
- 配上 {BGM 描述，比如：轻快的电子纯音乐，类似纪念碑谷风格}

【视觉要求】
- 整体风格：{选一个，或让 AI 出 3 个方案}
- avoid: 不要卡通风格，不要高饱和荧光色，不要硬切转场
- 画面之间不要硬切，要有丝滑过渡，优先用同一个元素贯穿前后两个画面
- 转场要短而干净，淡入淡出只作辅助

【卡点要求】
- 先分析 BGM 的 BPM 和重拍位置，标出每个重拍的秒数
- 每次画面切换都落在重拍上
- 高潮段落要让画面、文案、音效同时爆发

【音效要求】
- 每个关键动作配一个音效（碰撞/出现/增长/消失）
- 音色用清脆的钢琴/风铃/电子音，类似纪念碑谷
- 越关键的动作音越高

【分镜】
（在这里贴上你编排好的分镜脚本）

先做开头 10 秒给我看效果，风格满意后再继续做完整条。
```

### 4.2 风格选择提示词

```
基于这个主题：{主题}
给我出 3 个不同的视觉风格方案，每个方案说明：
- 整体色调和质感
- 主要视觉元素
- 适合的氛围
avoid: 不要常见的 PPT 风格，不要廉价感
```

### 4.3 迭代修改提示词

```
整体风格我满意了，请把这套视觉规范提炼成一个通用模板，
后续换主题时保持风格一致。

现在调整第 {X} 段：{具体修改意见}
只改这一段，其他部分保持不变。
```

## 五、工具与模型选择

| 工具 | 用途 | 推荐度 |
|---|---|---|
| **Claude Opus 5.5** | 主模型，写 Remotion 代码、审美和动效最佳 | ⭐⭐⭐⭐⭐ |
