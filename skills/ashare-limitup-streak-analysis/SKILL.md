# A股连板与龙一判定

**用途**：回答「XX 已经 N 连板，还能不能续板」「这个板块里谁是龙一」「哪只连板概率高」。
**核心**：连板的本质是**资金接力**，判据是 **① 封板强度 ② 资金连续递增 ③ 板块广度**。

## 触发条件
- 用户说"XX 已经2连板/3连板"，问能不能跟、还能不能板
- 用户问"这个板块谁是龙一"
- 用户问"哪只连板概率高"
- 需要判断新题材（首日涨停）次日能否延续

## 一、龙一判定（三条硬指标，按优先级）

### 1.1 涨停时间（第一判据）
```
最先封板 = 龙一（早盘封板 > 午后封板）
0930 一字开盘  > 09:30-10:00 封板 > 10:00-11:30 > 13:00 后
```
**取法**：用分时数据找首次触及涨停价的时间点
```python
m=json.loads(fetch(f"https://web.ifzq.gtimg.cn/appstock/app/minute/query?code={code}"))
rows=m['data'][code]['data']['data']   # 每行 "HHMM 价 累计量 累计额"
zt_price = 昨收 * 1.1（主板）/ 1.2（创业板科创板）
first_zt = 首个 |价 - zt_price| < 0.011 的时间
```

### 1.2 封单强度（第二判据）
```
封单占流通盘比例 = 买一量(股) ÷ 流通股本
  > 3%     封板极强
  1.5-3%   强
  0.5-1.5% 一般
  < 0.5%   弱（易炸板）
流通股本 = 流通市值 ÷ 现价
```
**⚠️ 必须算占比，不能只看绝对手数** —— 小市值股 10 万手就占 3%，大市值股 10 万手只占 0.3%。

### 1.3 炸板回封 vs 一字板（含金量不同）
```
一字板（开盘即封，全天不炸）  → 最强，但买不到
炸板后回封（如 09:31 砸到平盘、09:45 回封） → 次强，抛压已被消化
尾盘偷袭封板 → 最弱，多为诱多
```

## 二、连板概率判定

### 2.0 ⭐ 连板基因检测（最重要的前置筛选）

**核心洞察**：**一只票能不能连板，先看它历史上有没有连过板。** 没有连板基因的票，游资不认，首板往往就是终点（"今天入明天死"）。

**算法**：拉 250 日 K 线，统计所有连续涨幅 ≥9.8% 的段长度，取最大值。
```python
def streak_gene(code):
    k = json.loads(fetch(f"https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,250,qfq"))
    rows = k['data'][code].get('qfqday') or k['data'][code].get('day')
    c = [float(r[2]) for r in rows]
    runs=[]; cur=0
    for i in range(1,len(c)):
        if (c[i]/c[i-1]-1)*100 >= 9.8: cur+=1
        else:
            if cur>0: runs.append(cur)
            cur=0
    if cur>0: runs.append(cur)
    return sorted(set(runs), reverse=True)   # 如 [6,2,1] 表示历史上连过6板、2板、1板
```

**判定**：
```
历史最大连板 ≥5板  → 🟢 强基因（游资熟悉，接力意愿高）
历史最大连板 3-4板 → 🟢 有基因
历史最大连板 =2板  → 🟡 弱
历史最大连板 =1板  → 🔴 无连板基因（首板大概率一日游）
```

**⚠️ 实例（2026-10-13 验证）**：
| 标的 | 历史最大连板 | 判定 |
|---|---|---|
| 冰山冷热 / 雪人集团（冰雪） | **1 板** | 🔴 **无基因** → 首板后大概率死 |
| 捷荣技术（元件） | **6 板** | 🟢 强基因 |
| 澳弘电子（元件） | **5 板** | 🟢 强基因 |
| **示例股C**（零售） | **5 板** | 🟢 强基因（解释了它为何能连板） |
| 示例股A / 中京电子（元件） | 3 板 | 🟢 有基因 |
| 长白山 / 大连圣亚（旅游） | 1 板 | 🔴 无基因 |

**用法**：**先筛基因，再看板块**。无基因的票，哪怕板块再热也不要参与连板博弈。

### 2.1 资金模式（最关键）
```
✅ 连续 3 天递增（如 +1.07亿 → +2.26亿 → +4.18亿）→ 主力持续加仓，续板概率高
⚠️ 单日突增后次日转负                                → 一日游风险
❌ 连续净流出                                         → 派发，大概率断板
```
**取法**：新浪资金流 `MoneyFlow.ssl_qsfx_zjlrqs`（逐日 netamount）。

### 2.2 换手率位置
```
首板换手 5-10%    → 健康（筹码稳定）
2-3板换手 10-20%  → 正常（有换手才有接力）
换手 > 25%        → 筹码高度不稳定，随时断板
换手 < 3% 连板    → 一字板（买不到，也卖不掉）
```

### 2.3 板块广度（决定天花板）
```
板块内 3+ 只涨停（有梯队） → 龙头空间大（有跟随资金）
板块内独苗 1 只            → 独立妖股，天花板靠游资，断板风险高
```

### 2.4 续板概率参考表
| 情形 | 续板概率 |
|---|---|
| 资金连续递增 + 封单占流通 >2% + 板块有梯队 | **60-70%** |
| 资金连续递增 + 封单一般 + 板块独苗 | **45-55%** |
| 资金单日突增 + 高换手(>20%) | **30-40%** |
| 资金转负 / 龙虎榜净卖 | **< 25%** |

## 四、实战案例：2026-10-13 龙一判定

| 标的 | 涨停时间 | 封单 | 封单占流通 | 市值 | 资金(当日) | 龙一判定 |
|---|---|---|---|---|---|---|
| **冰山冷热** 000530 | **10:10** ⭐最早 | **194,251手** | **2.3%** ⭐最高 | 48.3亿（最小） | +2.24亿 | **龙一** |
| 雪人集团 002639 | 11:19 | 115,412手 | 1.48% | 113.7亿 | **+4.81亿**（最大） | 龙二（资金龙头） |
| 示例股C 000003 | 09:30一字→09:31炸→09:45回封 | 105,460手 | 1.21% | 107.0亿 | **+4.18亿**（连续3天递增） | 独立妖股（2板） |

**判读**：
- **冰雪经济龙一 = 冰山冷热**（封板最早 10:10 + 封单占比最高 2.3% + 市值最小 48亿）
- **雪人集团是"资金龙头"**（成交 12.97亿、资金 +4.81亿 都更大），但封板晚、占比低 → 龙二
- **示例股C**：资金连续 3 天递增（1.07→2.26→4.18亿）是**最强信号**，但**板块独苗**（一般零售仅 3 只涨停）→ 独立妖股

## 五、输出结构（用户偏好）
1. **连板状态表**（标的/连板数/换手/成交额/PE/市值）
2. **封板强度对比**（涨停时间/封单/占流通比/一字或回封）
3. **资金模式**（近 3-5 日净流入，看递增还是转负）
4. **龙一判定结论**（明确说谁是龙一、为什么）
5. **续板概率**（分情况给百分比）
6. **风险提示**（妖股天地板风险 + 非投资建议）

## Pitfalls
- **只看绝对手数判封单强弱会错** —— 必须算占流通盘比例
- **"资金最大"不等于"龙一"** —— 龙一看**封板时间**，资金量看关注度
- **一字板最强但买不到** —— 交易上要提醒"看得见吃不着"
- **炸板回封比首次封板更强**（经历过抛压考验），不要误判为弱
- **板块独苗的连板不要用"板块逻辑"解释** —— 那是纯游资接力
- **连板高度≤3板时不要指望高标** —— 说明市场无主线
- 腾讯分时每行是 `HHMM 价 累计量 累计额`（**累计值**，不是增量）
- 主板涨停 +10%，创业板/科创板 +20%，ST +5% —— 算涨停价别用错
