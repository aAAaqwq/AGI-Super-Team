# 持仓处置战术（减仓 / 清仓 / 做 T / 等反包）

**用途**：已经买进去之后问「怎么操作」「做 T 卖点在哪」「明天能反包吗」时用。
**上游 skill**（这些管「要不要买」）：
- `ashare-limitup-precapture` —— 启动前/首板捕获（基因+位置+主力+板块+大盘+一票否决）
- `ashare-limitup-streak-analysis` —— N 连板后判断续板/龙一
- `youzi-stock-quality-screen` —— 五标准 + 可买性

**⚠️ 用户的行为特征（决定本 skill 的全部写法）**：
- **套牢后不愿一次性清仓，会讨价还价**（「真得完全割吗」）→ **永远给「分批 + 死线」，不要一刀切**
- **会补仓摊薄、会做 T，但常做反（卖在当日低点）** → 必须**提前**给止损铁律，不是事后复盘
- **会按分析真金白银下单**，也会买你标「禁追高」的票 → 结论要**带价位和条件**，不要只给倾向
- 平仓后要求回溯原标的验证决策对错

## 〇、开工前必须先做的三件事

1. **拉实时**：现价 / 开高低 / 昨收 / 振幅 / 外盘占比 / 量比 / 换手 / 买1卖1 手数 / 距今日高
2. **拉资金流**：近 3-5 日 `netamount` **和 `r0_net`（超大单）分开看**（判据见下）
3. **确认持仓口径**：成本是否「摊薄口径」（券商显示含已实现亏损，做 T/减仓后数字会往上走）、可用股数（T+1 锁定多少）

```python
# 资金流：超大单才是真话
GET https://vip.stock.finance.sina.com.cn/quotes_service/api/json_v2.php/MoneyFlow.ssl_qsfx_zjlrqs
  ?page=1&num=6&sort=opendate&asc=0&daima={sym}
# netamount = 主力净额（亿元）；r0_net = 超大单净额（亿元）
```

## 一、⭐ 判断「该走还是该等」的第一判据：超大单

| 组合 | 含义 | 动作 |
|---|---|---|
| 净额流出 + **超大单流入** | 大资金没跑，跑的是散户 | 🟢 洗盘，可给时间 |
| 净额流出 + **超大单也流出** | 大资金真撤 | 🔴 **立刻减，别等** |
| 净额流入 + 超大单强流入 | 还在加仓 | 🟢 持有 |
| 股价创新高 + 当日净额 < 前日 20% | **冲高不进钱** | 🔴 派发前兆，次日大概率崩 |

**实测对照（2026-11-11 → 11-12）**：
```
示例股H 11/11：净 −0.175 亿，超大单 +0.162 亿  → 判「洗盘」（当时对的）
示例股H 11/12：净 −0.579 亿，超大单 −0.246 亿  → 转为派发，4.00 破止损，该走
思美传媒 11/11：净 −0.662 亿，超大单 −0.087 亿  → 一直就是真跑
```
**➜ 教训：判断要每天重算。11/11 是洗盘不代表 11/12 还是洗盘。超大单转负那天就是离场日。**

## 二、断板后「明天能否反包」怎么算

**反包定义**：次日收阳且收盘 > 今日开盘价。**强反包** = 收盘 > 今日最高价。

### 概率基准（2 板后第 3 天大跌 −7% 样本）

| 今日收盘形态 | 次日反包概率 |
|---|---|
| 收**长下影**（收回跌幅 1/3 以上） | **40-45%** |
| 收在中间 | 25-30% |
| 收在**最低附近** | **18-20%** |

### 四个加权变量

| 变量 | 加 | 减 |
|---|---|---|
| **距 MA30** | < +15% 🟢 | > +35% 🔴（高位断板基本不反包） |
| **超大单近 2 日** | 仍净流入 | 已转流出 |
| **今日换手** | < 10% | > 20% |
| 今日最低 | 只探一次 | 反复新低 |

### ⛔ 盘中不许下反包结论

**实测 11/13 中重科技**：11:53 现价 9.46，我给的答案是「收在 9.8 以上→45%，收在 9.32-9.4→18%，现在还不能定论」。
**➜ 「收长下影 vs 收最低」让概率差 2.5 倍，必须说清「14:50 才能定论」，别给盘中拍板。**

### 反包成立的 5 个验证信号（次日）

```
① 高开 ≥ 今日收盘价
② 开盘 15 分钟不破今日最低
③ 10:00 前量比 > 1.5
④ 站上今日开盘价（这才叫反包）
⑤ 板块当日 ≥2 只涨停
```
五条全满足 → 可持有；缺两条以上 → 只是反弹，该走。

## 三、⭐ 深亏做 T 的可行性量化（先算账再给点位）

用户深亏的票上问「做 T 卖点在哪」，**先算账**，否则是陪他自我安慰。

```
理论收益 = 股数 × 现价 × 今日振幅%
净收益   ≈ 理论收益 − 佣金(最低5元×2) − 印花税(卖出0.05%)
回本次数 = 当前浮亏 ÷ 单次净收益
```

**实测示例股A（深亏 −33%、可用 100 股、今日振幅 1.28%）**：
```
100 × 18.75 × 1.28% = 24 元 → 扣费净赚 ≈ 16 元
浮亏 1,891 ÷ 16 = 118 次全对
```
**➜ 判据：单次净收益 < 浮亏的 1% → 直接说「做 T 无意义，该做的是反弹减仓」。**
用户接受这个措辞。不要绕。

### 振幅收窄 = 不能做 T 的硬信号

| 今日振幅 vs 近 5 日均值 | 判定 |
|---|---|
| ≥ 均值 | 🟢 有空间 |
| 50-80% | 🟡 空间变小 |
| **< 30%**（1.28% vs 8.68%） | 🔴 **多空收敛，做 T 必做反** |

### 做 T 卖点三档 + 止损铁律

```
档1 保底：今日均价线 / 整数关      → 卖一半，先落袋
档2 稳健：今日开盘价（常是当天压力） → 再卖一半
档3 激进：今日最高价               → 只在板块转强时挂，别指望成交
```
**⛔ 跌破今日最低 = T 做反了，立刻卖出等量股认输。**
他过去反复「卖在当日最低点」，就是因为做反了不肯认、等它回来。**这句话必须写进建议里。**

### ⚠️ 必须同时点透：做 T 不改变亏损性质

```
做T前：200 股 @28.114 → 浮亏 −1,958.80
做T后：300 股 @24.803 → 浮亏 −1,944.90
```
成本数字降 3.31 元、浮亏少 14 元（这 14 元是真的），**但多投了 1,818 元、敞口扩大 50%**。
**➜ 「成本数字好看 ≠ 亏损变小，如果继续跌你会亏更多。」**

## 四、分批减仓的固定话术（用户只认这个形状）

**永远给三档触发 + 一条死线，绝不给「建议清仓」四个字。**

| 档 | 触发条件 | 动作 |
|---|---|---|
| 档1 | 反抽到关键压力位（今日高/前一日低/成本价上方） | 减 1/2 或 1/3 |
| 档2 | 破今日最低 | 再减 |
| 档3 | 破前低 / 破 MA 关键位 | 剩下的全清 |
| **死线** | 明确价位 + 「今天必须清掉，不留过夜」 | 无条件 |

**示例（东方创业 2026-11-12，成本 8.088、现价 7.24、止损 7.38 已破）**：
```
反抽 7.30-7.35 → 立刻走
跌破 7.15      → 市价走
最后期限       → 今天必须清掉，不留过夜
理由：卖1 压 317 手是买1(91 手)的 3.5 倍，外盘 61.6% 是假反弹
```

## 五、成本口径的两个陷阱

1. **摊薄成本会随操作变化**：券商显示的是含已实现亏损的摊薄价。做 T / 减仓后数字会往上走
   （实测超声 24.195 → 28.020 → 28.155 → 28.114）。**回本价 ≠ 加权买入价**，别用旧数字算回本空间。
2. **深亏（>15%）不做 T 摊薄**：摊薄只是把成本数字改小，不改实际亏损。要真减亏只有两条路——
   涨回去（等板块）或减仓（砍敞口）。

## 六、输出格式（照抄这个结构）

```
一、实时状态表（现价/涨跌/开高低/振幅/外盘/量比/换手/买1卖1/你的盈亏）
二、⭐ 资金流判据（净额 vs 超大单 分开列，给「主力在/在换手/已撤」三态结论）
三、逐只给动作（表格：触发 → 动作 → 理由）
四、优先级排序（最急的标 1️⃣，并说明为什么最急）
五、一句话总结（每只一句，带价位）
六、风险提示（不构成投资建议 + 今天还剩多少交易时间）
```

**语气**：先给结论再给理由；不说教（他会被「禁追高」激怒也可以，但**结论必须带价位数**）；
自己判断错了要**当场认并修正**（例：「11/11 我判洗盘是对的，但 11/12 超大单转负，必须修正为派发」）。

## 七、Pitfalls

- **🔴 盘中数据不可靠**：开盘 15 分钟内的杀跌常是错杀（实测超声 09:38 砸到 18.00 后拉回 18.9）。
  给「破位就卖」的同时要写「10:30 后再定性」。
- **🔴 别用「等回本」框架**：成本 28.114 的票涨到 19.5 仍亏 30%，那不是等回本，是反弹减损。**说清楚。**
- **🔴 做 T 前先算回本次数**：不算就建议做 T = 鼓励他在负期望里反复操作。
- **⚠️ 卖出压力看买1/卖1 手数比**：外盘偏买但卖1 压大量（如 91 vs 317 手）→ 是真出货，反弹卖。
- **⚠️ 承认错判要具体**：不说「可能有变化」，说「X 日超大单从 +0.162 转 −0.246，判断从洗盘改为派发」。
