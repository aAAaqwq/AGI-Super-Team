# 涨停基因筛选 —— 用户纠正记录（2026-11-05）

## 用户原话

> **「你挑选的好垃圾都没涨停过的」**

前一小时我刚扫完 825 只旅游+消费成分股，筛出千禾味业、大商股份、重百集团，报告写得挺漂亮：横盘 10-15 天 + 地量 0.73x + 放量试盘 2.55x + 天量洗盘 5.29x 带长下影 + 大阳反包 2.64x，位置距 MA30 只 ±1.5%，户数 −1.7% 筹码集中。

用户的评价是：**垃圾。**

## 错在哪

我筛的是「技术形态好不好看」，但没回答「**游资会不会来做它**」。

- 千禾味业：20 日涨停 **0 次**，历史最大连板 1
- 大商股份：20 日涨停 **0 次**
- 重百集团：20 日涨停 **0 次**

**从没涨停过的票 = 没有游资关注过 = 慢牛。** 每天涨 2-3%，赚不到短线的钱，也不可能变成妖股/龙头。

用户要的是**有妖股基因**的票。

## 四判据（必须过 ≥2 条）

| 判据 | 达标 | 取法 |
|---|---|---|
| **20 日涨停次数** | **≥2 次**（最好 ≥3） | 日线涨跌幅 ≥9.5%（创业板/科创 ≥19.5%）计数 |
| **历史最大连板** | **≥2 板**（妖股 ≥3） | 近 60 日涨停序列里最长连续段 |
| **流通市值** | **30-50 亿** | 腾讯 `f[44]` |
| **股价** | **<10 元最佳** | 低价 = 散户基数大 = 好炒 |

**加分项**：题材属性（传媒/游戏/白酒/稀有金属等有故事的行业）。

## ⚠️ 但涨停基因 ≠ 能买 —— 必须和户数联合校验

**慈文传媒的教训**：20 日 7 次涨停、最大 5 连板、11/03 资金 +5.47 亿 + 龙虎榜 +1.34 亿（**两个数据源方向一致，不是对倒**）、10/27 跌停日龙虎榜还净买 1.62 亿（主力在跌停接货）—— 怎么看都是「主力还在」。

但：**股东户数 10/20 暴增 +121.94%**（37,255 → 82,683 户），换手 **44.20%**。

**➜ 涨停期间户数暴增 = 散户在涨停里接盘 = 主力一走就踩踏。**

**四象限**：

| 组合 | 判定 | 案例 |
|---|---|---|
| 涨停基因强 + 户数下降 | ✅ 最优 | 闽发铝业（户数 −17.6%、2 连板、距 MA30 −2.0%） |
| 涨停基因强 + 户数暴增 >50% | ⚠️ 短期能涨，中期危险 | 慈文传媒（+121.94%） |
| 涨停基因弱 + 户数下降 | 🟡 筹码好但没人做，慢牛 | 千禾味业（−1.7%、0 涨停） |
| 涨停基因弱 + 户数暴增 | ❌ 直接排除 | 大晟文化（+169.3%） |

## 三道门的分工

| 门 | 筛掉什么 | 判据 |
|---|---|---|
| **可买性** | 买不进的 | 封单 ≤0.5 亿、换手 8-20%、量比 >1 |
| **涨停基因** | 买得进但不会涨的 | 20日涨停 ≥2、最大连板 ≥2、流通 30-50 亿、股价 <10 元 |
| **户数校验** | 会涨但你在接盘的 | 股东户数不暴增（>50% 警惕） |

**三道全过才是候选，只过其一的都不算。**
