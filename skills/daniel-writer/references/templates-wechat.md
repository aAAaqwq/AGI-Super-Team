# 微信公众号高传播模板

模板用于提高被读完、被收藏和被讨论的概率，不承诺阅读量。先读取[品牌与品味](brand-and-taste.md)、[公众号长文机制](wechat-longform-patterns.md)和[公众号结尾系统](wechat-endings.md)。

## 模板一：亲测纠偏长文

适合工具、Agent、产品实测。

```text
标题：我原本想用【工具】完成【期待】，跑完后最有价值的却是【反常结果】

开头：真实欲望 → 第一个意外 → 这篇具体兑现什么
现场：输入、目标和限制
第一次失败：原方案为什么看似合理
第二次证据：什么迫使 Daniel 改口
关键发现：用一句话改写问题
完整流程：动作 → 完成标准 → 返工条件
能力边界：已验证 / 未验证 / 人工责任
结尾：回扣第一次失败 → 当前判断 → 一个低压力问题
```

失败条件：没有亲测证据、只有功能清单、结尾突然升华。

## 模板二：Skill 或产品开源

```text
标题：我把【反复摩擦】做成了一个 Skill

眼前动作：今天公开什么
一句话价值：它只解决哪一个问题
真实故障：为什么这个问题值得被做
现有方案缺口：为什么普通提示词或手工方式不够
工作模型：三到五个职责不同的部分
最小使用：一句触发语或最短流程
完整流程：每一步防止什么错误
人机分工：Agent 做什么，Daniel 不交出什么
边界：未验证、许可证、发布与数据状态
结尾：回到真实故障 → 说明以后会怎样做 → 仓库地址与反馈入口
```

## 模板三：方法论与创作反思

```text
标题：【一个小动作】为什么改变了我对【更大问题】的理解

具体卡点
旧习惯或旧判断
一次不舒服但真实的反证
新模型：解释故障，而不是追求整齐
两个对照案例
读者可执行的最小动作
仍未解决的问题
结尾：不封死答案，留下下一次验证
```

## 公众号标题终检

- 标题里是否有人的目标、真实问题或明确结果？
- 是否保留了一个答案，同时在开头迅速兑现？
- 删除夸张词后，标题是否仍值得点开？
- 正文是否真的交付了标题承诺？
