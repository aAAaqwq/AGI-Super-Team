# 高传播语言机制

## 不把“爆款”误解成夸张

高传播内容同时完成三件事：让读者迅速认出自己的欲望或痛点，制造一个必须继续读的认知缺口，并在很短距离内兑现一次具体收获。

Daniel 不承诺“必爆”。传播性是写作质量变量，不是结果保证。

## 六个语言发动机

1. **欲望先行：** 先说作者想得到什么，而不是先介绍工具。
2. **预期落空：** 尽快出现一个与常识或作者原判断相反的结果。
3. **关键名词暂缓：** 标题可以保留一个答案，但开头必须及时兑现，不能骗点击。
4. **连续小兑现：** 每 80–180 个汉字至少推进一次问题、证据、判断或动作；长文不能连续三个自然段只解释背景。
5. **数字进入故事：** 数字必须形成前后差、代价或边界，例如 `7 条长句 → 13 条短句`，而不是罗列参数。
6. **具体之后升维：** 先让一个失败成立，再从失败提炼方法；抽象观点不能抢在证据前面。

## 句段节奏

- 一段只承担一个动作或转折。
- 短句负责落锤，长句负责装载因果；不要把所有句子都切成同样长度。
- 相邻段落尽量形成关系：期待/落空、动作/结果、局部/全局、支持/反证。
- 独立成段的句子必须真正改变方向。普通信息不靠空行假装重要。
- 少用解释性连接词，让动作本身产生连接。

## 标题机制

从事实中选择一种，不套万能公式：

- **目标＋意外结果：** 我想让 Agent 自动剪视频，最后留下来的却是一张返工清单
- **小故障＋大判断：** 两次缩小字幕都失败后，我重新理解了 AI 剪辑
- **读者任务＋反常识：** 小白做口播，第一步不是打开剪辑软件
- **公开动作＋真实代价：** 我把自己的写作 Skill 重做了一遍，因为它写得太像检查报告

标题必须被正文直接兑现。禁止伪装官方通知、夸大紧迫性、隐瞒商业目的或使用无法证明的收益。

## 编辑诊断

出现以下症状时，稿子通常没有传播力：

- 前三段都在定义背景，作者还没有想做任何事；
- 每段都正确，但删掉任意一段不影响下一段；
- 只有结论，没有“旧判断如何被击穿”；
- 数字很多，却没有一个数字改变读者判断；
- 每个小节都用相同的“我原本以为—后来发现”；
- 结尾突然谈时代、未来或人类责任，正文没有铺垫；
- 为追求口语感强塞粗口、网络热词或别人的口癖。

## 边界

研究头部创作者时，只提取标题结构、信息推进、悬念兑现、情绪曲线和视觉配合。不得复制其签名句、固定开头、独特隐喻、人格设定或可识别的语言组合。
