# 人与 Agent 的创作分工

## 必须由 Daniel 完成

- 提供第一手经历和真实情绪；
- 决定核心观点与文章为何值得写；
- 选择最终类比、文化连接和价值判断；
- 判断哪条反证足以迫使自己改口；
- 完成最后一次重写和发布批准。

## 可以交给 Agent

- 将原始材料整理成事实、判断、推断和未知；
- 同时搜索支持与反驳观点的候选证据；
- 提供多个类比候选，但不擅自写成事实；
- 在观点、结构和角度锁定后扩写段落；
- 检查错别字、重复、节奏、事实强度、素材权利和平台格式；
- 比较 AI 初稿与 Daniel 重写稿，提取稳定差异。

## 禁止外包

- 不让 Agent 虚构“我当时”的场景；
- 不让 Agent 用一个主题直接生成最终全文并自动发布；
- 不把 AI 的流畅答案当成作者观点；
- 不故意保留错别字、粗口或口癖来伪造活人感；
- 不把发散性幻觉当创意证据，所有外部事实必须独立核验。

## 写作 Skill 校准循环

1. 选择两到三篇 Daniel 明确认可的代表作和一份方法论；
2. 让当前 Skill 针对真实任务生成初稿；
3. Daniel 在不看规则答案的前提下重写或深改；
4. 比较两版在角度、事实、节奏、词汇、段落和结尾上的差异；
5. 只把重复出现且经 Daniel 批准的差异写回 Skill；
6. 再用新题目测试，避免只记住一篇文章。

通常进行少量高质量循环即可。停止条件不是“像某篇文章”，而是新题目上仍能保持真实、准确和可识别，同时没有压制新的表达。

## 样本准入

只有以下内容能成为 Daniel 正式样本：

- Daniel 本人原始作品；
- Daniel 对 AI 初稿完成实质重写后的版本；
- Daniel 明确回复“这像我”或批准进入样本库的片段。

协作草稿、外部博主原文和未经确认的 Agent 输出只能用于测试或机制研究。
