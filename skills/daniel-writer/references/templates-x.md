# X 高传播模板

默认写一条可独立传播的短帖，不承诺曝光。先读[品牌与品味](brand-and-taste.md)和[平台适配合同](platform-adapters.md)。

## 模板一：一次改口

```text
我原本以为【旧判断】。

直到【一个硬证据或失败】。

现在我更愿意写成：【降低强度后的新判断】。

【一条可执行规则或失效条件】。
```

## 模板二：资源发布

```text
我把【真实摩擦】整理成了【资源或 Skill】。

它只解决一件事：【一句话价值】。

适合：【明确对象】
不适合：【明确边界】

【链接】
```

## 模板三：数字反差

```text
【动作前数字】→【动作后数字】。

表面看，是【直觉解释】。
真正改变结果的，是【被证据支持的机制】。

下次我会先检查【一个触发条件】，而不是继续调【错误方向】。
```

## 终检

只保留一个判断、最多三个硬事实、一个真实人的动作。不能靠拆成串文逃避压缩。
