# 小红书高传播模板

目标是让用户迅速判断“与我有关、值得收藏、可以照做”，不使用必火公式。

## Emoji 使用合同

把 emoji 当作视觉标点，不当作热闹装饰。

- 正文默认使用 `4–6` 个彼此不同的 emoji；很短的笔记可降到 `3` 个。同一篇笔记或同一卡组内，每个 emoji 只出现 `1` 次。
- 根据内容原型选择一组同气质、语义直观但不同的符号；不要从所有词库各拿一个，拼成没有视觉关系的表情杂烩。
- 封面默认不用 emoji；确有助于识别时最多 `1` 个。单张卡片最多 `1` 个，不能每一行都加。
- 标题如使用 emoji，只在开头或结尾放 `1` 个，并计入全文唯一性；黄金三秒开头最多出现 `1` 个，先制造问题或反差，再兑现收益。
- emoji 优先放在小标题、清单入口、关键转折或 CTA 前，不插进数字、版本号、代码、证据 ID 和完整句子中间。
- 不用 emoji 替代必要文字；即使去掉 emoji，标题、步骤和风险仍应表达完整。
- 风险、授权、失败和未知项使用克制符号，不用庆祝、夸张或玩笑表情削弱事实边界。
- 清单需要多个项目时使用数字或普通项目符号，不连续重复 `✅`、`👉`、`🔥` 等图标。
- 不用一长串表情伪造活人感，也不照搬其他博主固定的 emoji 组合。

### 按内容原型选择 Emoji

以下是功能词库，不是每篇照抄的固定组合。每篇选 `4–6` 个且不重复，优先让符号与该段动作一眼对应。

| 内容原型 | 候选 Emoji | 适合承担的任务 |
|---|---|---|
| 干货合集 / 保姆级攻略 | `✨` `📌` `📝` `💡` `🧩` `🎯` | 收益兑现、重点、步骤、技巧、框架、目标 |
| 踩雷避坑 / 真实测评 | `⚠️` `❌` `🔍` `🧯` `⭕` `🔒` | 风险、错误、证据、修正、替代、边界 |
| 真实故事 / 复盘 | `🎬` `💭` `🪞` `🌧️` `🌱` `🤍` | 场景、想法、反思、低点、转折、温和收束 |
| 工具教程 / 工作流 | `🎬` `🧩` `✂️` `🔍` `🛠️` `📌` | 任务、分工、编辑、验收、修复、结论 |
| 工具避坑 / 实测纠偏 | `🎬` `❌` `📌` `🔍` `✅` `🔒` | 任务、失败、判断、检查、动作、边界 |
| 美食 / 生活方式 | `🍞` `📍` `😋` `🛍️` `💰` `🧾` | 品类、地点、真实体验、购买、价格、凭证 |

使用限制：`😋`、`💰`、`🛍️` 等体验或消费符号，只能用于已确认的试吃、价格或购买事实；`🌧️`、`💭` 等情绪符号不能替代 Daniel 对真实情绪的确认。

### 三种模板的 Emoji 落点

- **干货合集：** 开头用 `✨` 兑现收藏价值，中段用 `📝`、`💡`、`🧩` 区分步骤、技巧和框架，结尾用 `📌` 或 `🎯` 留下一个动作。
- **踩雷避坑：** 开头用 `⚠️` 建立风险，中段用 `❌` 标记真实失败、`🔍` 给证据、`🧯` 或 `⭕` 给修正，结尾用 `🔒` 写清边界。
- **真实故事：** 开头用 `🎬` 给真实场景，中段用 `🪞` 或 `🌱` 标记反思和转折，结尾用 `🤍` 克制收束；没有真实低谷时不使用 `🌧️` 制造戏剧。

## 标签合同

标签负责主题归类与检索，不负责承诺流量。

- 正文末尾默认提供 `4–8` 个强相关候选标签，集中放在一个标签区，不穿插到正文句子里。
- 标签至少覆盖三层：`任务/人群`、`具体痛点/方法`、`工具/场景`。例如：`#新手剪辑`、`#字幕排版`、`#OpenCut`。
- 优先使用正文真实出现的名词；一个标签不能承载正文没有兑现的能力、身份或结果。
- 删除宽泛堆量、重复近义和诱导性标签，不使用 `#必火`、`#热门`、`#流量密码` 等无法验证的效果暗示。
- 标签只是编辑候选。发布前在平台内人工复核词义、当日可用性、品牌风险与动态规则，不声称实时热度。

## 模板一：小白避坑

```text
封面：【任务】最容易返工的，不是【直觉答案】

第 1 卡：我原本怎么做
第 2 卡：第一次失败画面或数据
第 3 卡：为什么直觉修正无效
第 4 卡：真正的问题
第 5–7 卡：三个动作及完成标准
最后一卡：适用范围、仍需人工检查、收藏理由

正文：补充真实过程与边界，不重复逐卡文字。
```

## 模板二：前后对比

```text
封面：【前】和【后】只改了【一个关键变量】

前：真实失败，不故意做丑
中：判断依据与修改动作
后：可核结果，不扩大为全面成功
清单：读者如何复现
边界：什么条件下不会有效
```

## 模板三：资源筛选

```text
封面：我筛了【有证据的数量】，最后只留下【数量】个

先说筛选任务
公布三条淘汰标准
每个资源只回答：适合谁 / 最强项 / 权利或成本 / 不适合什么
最后给选择路径，而不是继续堆数量
```

## 终检

封面、首卡、正文第一句必须承诺同一件事。卡片可收藏不等于素材可转载，权利状态必须单独检查。

- emoji 是否来自同一内容原型的视觉气质，并帮助扫读，而不是随机凑多样性？
- 同一篇正文或卡组中是否每个 emoji 都只出现一次，并与所在段落的任务匹配？
- 标签是否来自正文真实主题，并覆盖任务、痛点和工具/场景？
- 删除 emoji 和标签后，正文是否仍然完整、准确、像 Daniel？
