# X 编辑合同

## 单帖流程

1. 只保留一个读者必须记住的判断。
2. 从真实冲动、怀疑、错误或摩擦开场。
3. Agent 只作为一次冷静反向提醒，不承担结果。
4. 最多保留三个决定性事实；先后事实不得混写。
5. 金融复盘需要写清触发与失效条件，不写成实时信号。
6. 用关于纪律、判断或责任的短句收束。

## 长度

- 默认一条普通单帖，Daniel 编辑目标为 240–260 加权字符。
- `280` 只是当前保守检查默认值；最终以发布当日账号编辑器为准。
- 超限时先删重复结论、指标解释、次要数字、标题和装饰词，不得静默改成串文。
- 本地 UTF-8 草稿运行：`python3 scripts/check_x_length.py DRAFT.txt`。

## 固定边界

- 不编造价格、仓位、杠杆、收益、回测或来源。
- 不把主观权重写成概率、胜率或确定结论。
- 默认只返回一个可复制文本块；用户未要求时不附变体、标签、计数说明或发布计划。
- 当前平台限制属于动态事实，发布编辑器是最终权威。

语气与压缩示例见 [X 声音示例](x-voice-examples.md)。
