# 知乎高传播模板

知乎需要可回答的问题、明确立场、证据链与反例。高传播来自“真正回答”，不是拉长篇幅。

## 先选双轨

- **故事 / 盐选叙事轨：** 用人物处境、冲突、反转和余味承载主题。适合真实故事、获授权改编或明确标注的虚构作品。
- **干货 / 观点回答轨：** 用痛点、限定结论、证据、机制和行动建议回答问题。适合实测、教程、解释、比较和观点论证。

两条轨道都可以采用“强钩子 → 冲突或问题升级 → 反转或认知修正 → 共鸣或可执行结论”，但模板只能放大已有材料，不能制造事实。

## 万能四段结构

### 1. 黄金开头：立即兑现阅读理由

从以下方式选一种，不要全部叠加：

- **金句或反常识：** 用一句可由正文证明的判断推翻直觉。
- **高潮前置：** 把材料中最关键的选择、失败、尴尬或悬念提前，但暂不泄露完整原因。
- **痛点共鸣：** 干货文直接说出读者正在承受的具体代价。
- **限定结论：** 先给答案，同时说明它只适用于什么条件。

开头之后应在 2–3 段内交代问题，不能只吊胃口、不兑现。

### 2. 发展铺垫：升级冲突或问题

- 交代人物身份、资源差异、目标和代价；身份反差必须来自材料。
- 每一节至少改变一次局面：增加证据、提高代价、暴露误判或排除一种解释。
- 用有来源的时间、金额、动作、物件和现场细节增强可信度。
- 有逐字记录时才使用引号还原对话；没有记录时改用转述，不伪造心理活动。
- 干货文逐层拆开“表象 → 原因 → 底层机制”，并回应最强反例。

### 3. 高潮反转：产生爽点或认知增量

- **故事轨：** 主角作出有代价的选择，或真相改变读者对前文的理解。
- **干货轨：** 用关键证据、反例或机制修正开头的常见认知。
- 反转必须有前文伏笔和因果支撑；不得凭空追加隐藏身份、阴谋、财富或巧合。
- “打脸”只能是事实后果，不用羞辱、围攻或捏造反派承载情绪。
- 高潮后说明真实代价和未解决问题，避免无成本胜利。

### 4. 结尾收束：升华而不喊口号

- 回扣正文已经证明的价值判断、规则或责任。
- 故事轨留下人物选择的余味；干货轨给出读者今天能执行的一步。
- 可以提出开放问题，但必须与核心两难相关，不使用无关的“评论区扣 1”或虚假站队。
- 不把个案强行上升为普遍规律；明确适用条件和未知项。

## 模板一：亲测回答

```text
问题：【工具】真的适合小白完成【任务】吗？

先给限定结论
说明测试版本、输入与目标
列出真正完成的部分
讲一次最关键失败
解释失败揭示的机制
给出适合与不适合的人
保留未验证项
```

## 模板二：反常识解释

```text
问题：为什么【常见做法】反而容易导致【具体失败】？

先承认常见做法为什么合理
给出一个反例
拆开因果链
提供替代规则
说明规则失效条件
回应最强反对意见
```

## 模板三：方法比较

```text
问题：【方案甲】和【方案乙】应该怎么选？

先说选择维度，不急着站队
给出相同输入下的对照
比较结果、成本、返工和权利边界
按人群给选择路径
公开无法比较或尚未验证的部分
```

## 模板四：故事 / 盐选式叙事

起草前先声明素材模式，三选一：

- `已核验真实经历`：关键时间、身份、金额、对话和结果均连接证据 ID。
- `获授权改编 / 匿名化`：列明合并、改名、时间压缩等改编动作，不改变核心事实。
- `明确虚构`：在交付物和发布文本中清楚标注，不伪装成 Daniel 或他人的亲历。

```text
问题或标题：【关系/身份/目标】发生【异常事件】后，真正的原因是什么？

开场画面：前置最关键冲突或选择
阅读承诺：读者最终会理解什么
处境建立：人物、目标、权力差和风险
第一次升级：原有办法失败，代价增加
第二次升级：新证据推翻一种解释
伏笔回收：前文细节获得新含义
关键反转：真相或选择改变局面
真实代价：反击或觉醒并非没有损失
余波：人物此后如何承担结果
点题：只总结正文已经证明的判断
讨论问题：围绕真正的两难邀请回答
```

不要为了戏剧性连续堆叠背叛、绝症、豪门、隐藏身份和天降证据。冲突强度由真实素材决定。

## 模板五：干货 / 观点回答

```text
问题：【人群】为什么总在【具体任务】上付出【具体代价】？

痛点开场：指出读者可以识别的具体场景
限定结论：先给答案和适用条件
错误直觉：解释常见做法为什么看似合理
证据一：数据、实测或真实案例
证据二：反例或失败样本
机制拆解：说明现象为何发生
行动框架：给出 3–5 个有顺序的步骤
适用人群：谁应该采用
失效条件：谁不适合、何时停止
一句点题：压缩成可复用判断
讨论问题：邀请读者补充反例或条件
```

## 标题公式

标题必须由正文兑现，不保证“爆火”，不要制造正文不存在的秘密或结果。

### 反常识类

- `千万不要以为【常见认知】，真正决定【结果】的是【机制】`
- `为什么【看似正确的做法】，反而让【人群】更容易【失败】？`
- `【对象】真正难的不是【表象】，而是【底层问题】`

### 故事悬疑类

- `在【关系/阶段】的第【时间】，我发现了【异常事实】`
- `当【冲突画面】发生时，我才知道【旧认知】一直错了`
- `【人物】做出【反常选择】后，所有人都误会了原因`

第一人称标题只用于有证据的本人经历；虚构或改编作品不得冒充真实亲历。

### 干货利他类

- `零基础如何在【时间/约束】内完成【可验证任务】？`
- `做【任务】前，先检查这【数量】个容易返工的地方`
- `我用同一组输入测试了【方案甲】和【方案乙】，差别在这里`

只有内容确实值得反复查阅时才使用“建议收藏”，不要把它当作默认标题前缀。

## 知乎交付格式

```yaml
问题:
内容轨道: 故事盐选|干货观点
素材模式: 已核验真实经历|获授权改编匿名化|明确虚构|事实论证
标题候选:
开头钩子:
核心冲突或痛点:
证据ID:
伏笔与回收:
反转或认知修正:
最强反例:
行动建议:
适用与失效条件:
结尾讨论问题:
未知项:
```

## 终检

标题必须是正文真正能回答的问题。结论、事实、推断和未知分别标清；不要用经历替代普遍证明。

- 开头承诺是否在正文兑现？
- 每次冲突升级是否有材料依据？
- 具体数字、对话、心理和身份是否有证据或虚构标识？
- 反转是否有伏笔和因果，而不是凭空追加设定？
- 干货文是否提供证据、反例、步骤和失效条件？
- 结尾是否回扣已证明内容，而非强行升华？
- 互动问题是否邀请真实讨论，而非诱导站队？
