# 对标机制综合

本文件只保存可迁移机制，不保存外部文章全文，不要求模仿任何在世作者的独特风格。

## Khazix Writer

可迁移机制：

- 个人价值观先于格式规则；
- 选题同时考虑好奇、知识和共鸣；
- 明确 AI 擅长补证据与结构，人必须提供真实经历、核心角度和情绪；
- 按调查、体验、现象、工具、方法论区分文章原型；
- 用具体场景启动，用过程发现推动，用回扣句维持主线；
- 提供丰富的开头、转场、反例与修改对照；
- 以硬规则、风格、内容、活人感做分层检查。

不迁移：粗口、特殊标点、固定尾部、签名句、人物设定、独特隐喻及可识别口癖。

## 两篇 Khazix 公众号长文

### 创作 Skill 开源文

可迁移机制：

- 从当天的开源动作进入，再解释为什么普通的“风格蒸馏”不够；
- 先交付 Skill，再把后半篇升级为“如何构建自己的 Skill”和“AI 如何参与创作”；
- 用 AI 初稿—人工重写—差异回灌—新题复测的循环说明 Skill 不是一次成型；
- 把人机分工落到证据搜索、类比候选、锁定角度后的扩写和事实校验；
- 用一个发生在创作卡点中的真实故事，把抽象的人类判断变成可感知的选择；
- 结尾将“是否使用 AI”改写为“是否仍有真实的人在判断和表达”。

不迁移：其个人影视经历、书架场景、文化隐喻、固定断句、粗口、活动广告和签名尾部。

### 洁癖 Skill 开源文

可迁移机制：

- 用略带自嘲的产品名降低发布姿态，随后快速说明一句话价值；
- 用 SQLite 切换 PostgreSQL 后文档未更新的故障证明需求，而不是靠功能自夸；
- 主动提出“这是否只是开发者问题”，再反转到非专业 vibe coder 才更容易受伤；
- 通过记忆、Agent 约束文档和项目文档三层模型解释知识职责；
- 通过五步流程、一个最小命令和“任务结束时存档”的使用时机降低理解成本；
- 从文档整理升到持久化知识与上下文腐败，再用数字化断舍离收束。

不迁移：强迫式身体感受、特定产品口号、固定哲思句、粗口和品牌行动引导。

## 用户提供的三条 X 样本

可迁移机制：

- Khazix：一句明确价值承诺＋资源链接，删除解释性前言；
- 朝朝：用读者问题开场，再说明“我把这个问题做成了 Skill”；
- 逸尘：先给资源规模，再编号展示，使用低压力行动引导让读者按需取用。

Daniel 适配：资源发布帖必须说明解决什么真实摩擦、自己为何做、读者如何验证，而不是只报“开源”。

## 用户提供的小红书视频

公开页面与关键帧支持的机制：

- 先承认一个容易被误解的议题，再给立场边界；
- 用身体、体重、训练记录和日常饮食组成过程证据；
- 同时展示“做了什么”和“没有做什么”；
- 把“变瘦”重构为“变强”的身份叙事；
- 真人、镜面记录、数据截图、清单卡与生活片段交替；
- 中英字幕维持统一信息，不只依赖画面。

未验证：完整语音逐字稿、每个镜头时长与字幕逐句准确性。

## 逸尘研究路由

可迁移机制：搜索发现、候选确认、内容归档、按需转写分层；匿名公开路线优先；不绕过验证码或登录墙；明确错误与覆盖范围。

Daniel Writer 将它转为写作要求：每篇稿子先建立来源台账，再决定哪些证据可以进入文章。

## 补充对标池

Khazix 的公开方法论将影视飓风、何同学、小Lin说、毕导和九边列作节奏参考。公开可核样本进一步支持以下高层机制：头部标题常把人的目标放在产品之前，用反常结果或暂缓一个关键答案形成缺口；高播放标题仍以具体任务和具体物件为主，而不是抽象行业判断。当前没有逐篇完成其正文一手审计，因此不归纳任何作者的独特句法或人格口癖。

例如，Bilibili 公开列表中何同学的多个高播放标题使用“具体动机＋保留结果”的结构，公开视频列表同时显示数百万级播放。Daniel 只迁移“动机先行、答案暂缓、正文快速兑现”这一机制，不复制固定标题句式。

## 综合后的 Daniel 差异

Daniel 的识别点不是更夸张的口语，而是：亲自跑流程、保存证据、允许 Agent 反驳、精确降低事实强度，并把授权和验收写进故事。

两篇长文进一步确认 Daniel 应学习的不是“像朋友聊天”这一层表象，而是四段推进：个人故障证明问题，概念模型解释问题，最小流程解决问题，人的判断限定问题。

2026-08 的这轮校准又补上一条：正确和可信只是底线，发表稿还必须持续制造并兑现好奇心。审计语言负责不说错，传播语言负责让人愿意读到证据。
