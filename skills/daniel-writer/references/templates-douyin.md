# 抖音高传播模板

默认一条视频只讲一个转折。脚本必须同时设计口播、画面证据和字幕，不承诺播放量。

## 模板一：两次修错

```text
0–2 秒：我把【参数】改了两次，【问题】还是没解决。
2–8 秒：因为真正的问题不只在【直觉归因】，还在【新发现】。
8–25 秒：展示第一次修改和失败证据。
25–40 秒：展示新修改与结果边界。
40–55 秒：给出观众下一次能执行的规则。
55–60 秒：说明仍需人工检查什么。
```

## 模板二：小白第一步

```text
0–2 秒：小白做【任务】，第一步不是【常见动作】。
2–8 秒：先锁定【输入、结果或返工条件】。
8–35 秒：用一次真实返工证明原因。
35–50 秒：交付三步最小流程。
50–60 秒：一个明确边界或评论问题。
```

## 模板三：工具真实能力

```text
0–3 秒：【工具】没有替我【夸张承诺】，但它解决了【真实摩擦】。
3–10 秒：展示最终结果和限制。
10–35 秒：三段画面分别证明它做了什么。
35–50 秒：展示它没有做什么。
50–60 秒：适合谁、下一步怎么试。
```

## 终检

前两秒冲突必须真实；前八秒兑现观看承诺；字幕使用短句和安全区。静态抽检不能写成真机通过。

## 标准逐秒表

正式脚本必须逐段填写：

| 时间码 | Daniel 口播 | 主画面/动作 | 证据 ID | 屏幕字幕 | 音效/节奏 | 素材权利 | 未验证项 |
|---|---|---|---|---|---|---|---|
| 00:00–00:03 |  |  |  |  |  |  |  |

每个口播主张必须与同期画面证据对齐。没有证据画面就标注“无画面证明”，不得靠无关素材暗示结果已经发生。
