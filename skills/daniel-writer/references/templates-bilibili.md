# B站高传播模板

目标是形成清晰观看承诺、持续信息推进和可视化证据，不用辅助画面掩盖空洞结论。

## 模板一：实验翻车

```text
标题：我用【工具】挑战【具体任务】，结果先坏在了【意外环节】

0–30 秒：目标、限制、最意外结果
第一章：为什么原方案看起来会成功
第二章：第一次失败与错误归因
第三章：新证据如何改变问题
第四章：修正过程与前后对比
第五章：观众可以复现的规则
结尾：这次只证明了什么，还没有证明什么
```

## 模板二：做一个东西

```text
标题：为了【真实动机】，我做了一个【暂缓揭晓的东西】

动机必须具体且可信
快速展示结果，但暂缓解释机制
拆解三个最难决策
保留一次失败和取舍
展示最终结果与验收
回答“为什么不用更简单方案”
结尾回到最初动机
```

不得复制其他创作者固定的“为了……我们做了……”标题句式；应根据 Daniel 的真实任务重新组织语言。

## 模板三：工具能力边界

```text
标题：【工具】到底能不能【流行承诺】？我把流程跑完了

先给限定结论
公开测试输入和版本
展示成功步骤
展示失败步骤
区分工具、Agent 与人工职责
给出适合人群与不适合场景
用独立检查结束，而不是用产品界面结束
```

## 终检

每 30–60 秒必须出现新证据、失败、修正或规则。标题承诺、开头画面和结论强度必须一致。

## 标准分轨表

正式脚本必须逐段填写：

| 时间码 | Daniel 口播 | 主画面/界面 | 证据 ID | 屏幕字幕 | 声音与节奏 | 素材权利 | 未验证项 |
|---|---|---|---|---|---|---|---|
| 00:00–00:15 |  |  |  |  |  |  |  |

口播中的每个关键主张都必须映射到同段证据画面；没有画面证明时明确写“无画面证明”，不能用装饰性辅助画面制造已验证的错觉。
