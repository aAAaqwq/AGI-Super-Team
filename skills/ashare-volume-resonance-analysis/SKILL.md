# A股四维共振分析（时间轴 / 结构轴 / 节奏轴 / 量价轴）

**出处**：黎承祖自己沉淀的「量能四坐标」体系（2026-09-09 首讲，10-26 固化为可执行 skill）。
**姊妹 skill**：`youzi-stock-quality-screen`（第20集五标准 + 第19集量价四象限）。**两者串成一条完整流水线：五标准过筛 → 量价定阶段 → 四维共振定排序。**

**一句话原理**：
> **共振 ≠ 每个维度都好，而是多个维度指向同一方向。**
> 单看任何一个维度都会被骗（放量上涨可能是天量派发，缩量下跌可能是高控盘洗盘）；四轴一起看，才知道「这波上涨有没有第二条腿」。

---

## 一、四个坐标（定义 + 算法）

| 坐标 | 算法 | 回答什么问题 | 数据源 |
|---|---|---|---|
| **① 时间轴** | 今日量 ÷ 5/20/60 日均量（均量取**不含今日**的前 N 日） | 绝对量能是多是少 | 腾讯 fqkline 日K |
| **② 结构轴** | 同行业**涨停家数**（+ 板块成交额占两市比） | 资金在不在这个方向、有没有梯队 | 东财涨停池 `hybk` |
| **③ 节奏轴** | 日内分时段成交额占比（早盘 30 分钟占比为核心） | 边际在变强还是变弱、是封死还是换手 | 腾讯分时 |
| **④ 量价轴** | 涨跌幅 × 量能变化（量比 5 日） | 放量是进攻还是撤退 | 行情 + 日K |

> 实战中 99% 的人只看①，所以永远看不懂「为什么放量了还跌」——因为漏了②③④。

## 二、判定阈值（2026-10-23 实测校准，不是拍脑袋）

### ① 时间轴（倍率 = 今日量 / 均量）

| 倍率（/5日） | 判定 | 分值 | 含义 |
|---|---|---|---|
| **> 7** | 🔴🔴 极端天量 | −2 | 历史级分歧，主力已找到接盘资金出局（第19集「天量天价」） |
| **3 ~ 7** | 🔴 天量 | −1 | 分歧极大，警惕见顶 |
| **1.5 ~ 3** | 🟡 放量 | +1 | 温和进攻，可接受 |
| **0.9 ~ 1.5** | 🟢 平量 | +1 | 锁仓/健康 |
| **< 0.9** | 🟢 缩量 | +1 | 惜售/高控盘（涨停时=封死锁仓） |

### ② 结构轴（同行业涨停家数，含自己）

| 家数 | 判定 | 分值 |
|---|---|---|
| **≤ 1（独苗）** | 🔴 板块无托底，全靠自己 | −2 |
| **2** | 🟡 偏小 | 0 |
| **3 ~ 4** | 🟡 一般 | +1 |
| **≥ 5** | 🟢🟢 有梯队，有跟随资金 | +2 |

> **< 5 家的板块，龙头断了没人接力** —— 独苗型龙头只能做「一日游/两日游」，不能当主线。

### ③ 节奏轴（早盘 9:30-10:00 成交额占全天比）

| 早盘占比 | 判定 | 分值 | 含义 |
|---|---|---|---|
| **≥ 50%** | 🟢 封死锁仓 | +2 | 早盘打完量后无量 = 封板不动、筹码锁死 |
| **35% ~ 50%** | 🟡 偏集中 | +1 | 正常换手 |
| **< 35%** | 🟡 全天分散 | 0 | 无明确主攻时段（多为弱势/散乱） |

**附加读法（不看分值，看形态）**：
- **早盘 50%+ 且午后彻底无量** → 封死（最强锁仓）
- **两波放量（早盘 + 午后 13:30）** → 午后有资金继续推，健康
- **早盘 54% + 午后开盘 13:00-13:30 再放 19%** → 两次集中换手，2 板典型
- **尾盘 14:30-15:00 突然放量** → 抢筹 or 出货，看当时涨跌方向

### ④ 量价轴（涨跌 × 量比5日）

| 组合 | 判定 | 分值 |
|---|---|---|
| 涨 + 量比 1.2~3 | ✅ 放量上涨（健康进攻） | +2 |
| 涨 + 量比 < 0.9 | 🟢 缩量上涨（高控盘锁仓） | +2 |
| 涨 + 量比 0.9~1.2 | 🟡 平量上涨 | +1 |
| 涨 + 量比 > 3 | ⚠️ 天量上涨（分歧极大） | −1 |
| 跌 + 量比 > 1.2 | 🔴 放量下跌（派发） | −2 |
| 跌 + 量比 < 0.8 | 🟠 缩量下跌（须分辨洗盘/真跌） | −1 |
| 跌 + 量比 0.8~1.2 | 🟡 平量下跌 | −1 |

## 三、共振度打分与排序（★ 本 skill 的核心）

```
共振度 = 四轴分值之和（范围 −8 ~ +8）
同时看两个指标：
  ① 总分（多空强度）
  ② 一致性（正负号是否同向）← 比总分更重要
```

| 情形 | 标签 | 处理 |
|---|---|---|
| 无负分，且 ≥3 个正分 | **共振** | 可参与，按分排序 |
| 正负差 ≥3（4正0负 / 3正1负） | **弱共振** | 可关注，等确认 |
| 正负接近（2正2负 / 1正3负 / 3正1负但有 −2） | **矛盾 → 单点爆发，不是共振** | **降级/放弃** |
| 无正分 | **反向共振** | 回避/离场 |

> **矛盾比低分更危险**：低分可能是「安静的强势」（缩量锁仓），矛盾说明「多个维度在打架」，即市场自己都没共识。

### 排序口径（优先级顺序）

1. **一致性优先**：共振 > 弱共振 > 矛盾（矛盾的一律排到最后，不管总分）
2. **同档内比总分**
3. **同分比「结构轴」**：有梯队（≥5 家）优于独苗 —— 因为梯队决定「断了有没有第二条腿」
4. **同分比位置**：板数越低越好（2 板 > 3 板 > 4 板）

## 五、四轴的数据获取（自己写代码时看这里）

```python
# ① 时间轴 —— 腾讯前复权日K（120日，含今日）
"https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600838,day,,,120,qfq"
#   data[code]['qfqday'] 每行: [日期, 开, 收, 高, 低, 成交量(手), ...]
#   倍率 = v[-1] / mean(v[-6:-1])   ← 分母不含今日

# ② 结构轴 —— 东财涨停池（hybk = 行业，4 字截断）
"https://push2ex.eastmoney.com/getTopicZTPool?ut=7eea3edcaed734bea9cbfc24409ed989"
"&dpt=wz.ztzt&Pageindex=0&pagesize=300&sort=fbt%3Aasc&date=YYYYMMDD"
#   字段: c(代码) n(名称) hybk(行业) lbc(连板数) fund(封单额) fbt(首封时间) zbc(炸板次数)

# ②b 个股行业 —— 主源 push2 f127；抽风时降级 F10 核心题材（BOARD_TYPE=行业）
"https://push2.eastmoney.com/api/qt/stock/get?ut=fa5fd1943c7b386f172d6893dbfba10b"
"&fltt=2&invt=2&secid=1.600838&fields=f57,f58,f127,f128,f129"
"https://datacenter.eastmoney.com/securities/api/data/v1/get?reportName=RPT_F10_CORETHEME_BOARDTYPE"
"&columns=SECUCODE,BOARD_CODE,BOARD_NAME,BOARD_TYPE&filter=(SECUCODE%3D%22600838.SH%22)&pageSize=60&source=HSF10&client=PC"

# ③ 节奏轴 —— 腾讯分时（day/query 一次给近 5 个交易日，含今日）
"https://web.ifzq.gtimg.cn/appstock/app/day/query?code=sh600838"
#   data[code]['data'] = [{date, data:[ "HHMM 价 累计量(手) 累计额(元)" ... ]}]
#   分时段额 = 后一时点累计额 − 前一时点累计额（差分，不是直接取）

# ④ 量价轴 —— 腾讯实时快照
"http://qt.gtimg.cn/q=sh600838"   # f[32]=涨跌%  f[6]=成交量(手)  f[30]=时间戳
```

## 六、实战案例（2026-10-23 收盘，实测数据）

> 三只都是当日强势股，只看「五标准」时排序是 上海九百 > 明月镜片 > 多伦科技；**加上四维共振后，明月镜片直接掉到最后**。

| 维度 | 上海九百 600838 | 明月镜片 301101 | 多伦科技 603528 |
|---|---|---|---|
| ① 时间轴 | 0.80 倍 → 🟢 缩量 | **7.12 倍 → 🔴🔴 极端天量** | 2.59 倍 → 🟡 温和放量 |
| ② 结构轴 | 一般零售 3 家 → 🟡 | **文娱用品 1 家（独苗）→ 🔴** | **软件开发 7 家 → 🟢🟢** |
| ③ 节奏轴 | 早盘 50.2% 后无量 → 🟢 封死 | 早盘 44.9% + 午后 19% → 🟡 | 早盘 54.1% + 午后 18.7% → 🟢 |
| ④ 量价轴 | +10% × 0.80 → 🟢 缩量涨停 | **+20% × 7.12 → ⚠️ 天量上涨** | +10% × 2.59 → ✅ 放量上涨 |
| **共振度** | 6（4正0负）共振 | **−4（1正3负）矛盾** | **7（4正0负）共振** |

**结论**：
- **明月镜片**：五标准里流通 68.6 亿 ✅、户数 −3.4% ✅ 都过关，量价单看也是「放量上涨」——**但时间轴 8.84 倍（/20日）+ 结构轴独苗 = 天量 + 无托底，最坏组合**。四个坐标一拉开就露馅 → 不是共振，是单点爆发。
- **多伦科技**：板块 7 家涨停（有梯队）+ 量能温和不透支 + 2 板位置不高 → **三个维度在同一方向说话 = 真共振**。
- **上海九百**：缩量 + 封死 + 缩量涨停，三个维度都说「没人卖了」→ 一致；**但结构轴只有 3 家 = 独狼型锁仓**，断了没接力。

## 七、Pitfalls（都是踩过的坑）

- **⚠️ `hybk` 是 4 字截断行业名**（"汽车零部"、"自动化设"、"文娱用品"），与东财 `f127`/F10 行业名可能微差（`文娱用品` vs `文化用品`）。匹配用 **exact / startswith / difflib ratio ≥ 0.7**；**不要用 0.5 阈值** —— 实测 0.5 会把「个护用品」「家居用品」误算成「文化用品」的同板块，把独苗算成 4 家。
- **push2 `qt/stock/get` 会间歇返回空**（无报错、无 JSON）→ 必须写降级到 F10 `RPT_F10_CORETHEME_BOARDTYPE`（取 `BOARD_TYPE=="行业"`）。降级时行业名可能不同，注意上面的模糊匹配。
- **腾讯 `minute/query` 只给当天**，盘前/非交易日返回唯一的空行（成交量 0）→ 用 **`day/query`** 一次拿近 5 日分时，挑「最近一个有成交的交易日」，否则节奏轴会算成 0%。
- **分时数据是累计额，必须差分**：`"0930 11.00 61247 67371700.00"` 第 3 列=累计量、第 4 列=累计额（元）。
- **11:30 → 13:00 之间没有记录**，午休段要用 11:30 的累计值做起点跨到 13:00，别当成缺失丢掉。
- **盘中跑 ≠ 收盘跑**：盘中今日量/涨跌未完成，时间轴与量价轴会系统性偏低，必须同时段折算；节奏轴不受影响，反而盘中更有用。
- **结构轴的「板块」用行业，不用概念**：概念标签（AI眼镜、机器人）会跨行业，家数虚高；游资的「资金容纳度」看的是行业。概念只用于找催化。
- **涨停池要指定日期**：`date=YYYYMMDD` 不传默认当天；复盘历史必须显式传，否则拿到的是今天的池子配昨天的K线。
- **ETF/指数不适用**：没有「板块涨停家数」和「控盘」概念。

## 八、与其他 skill 的分工

| skill | 职责 | 在流水线中的位置 |
|---|---|---|
| `youzi-stock-quality-screen` | 五标准过筛（非庄股/机构少/流通≤100亿/筹码集中/板块容纳度）+ 量价四象限定阶段 | **第 1 步**（决定「能不能做」） |
