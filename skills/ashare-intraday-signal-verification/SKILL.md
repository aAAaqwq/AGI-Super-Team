# A股日内信号验证层（动手前最后一道检查）

**定位**：日线层面的判断（板块/量价/四维共振/游资五标准）回答「**这票值不值得做**」。
本 skill 回答「**现在这一秒能不能动手**」—— 用**盘中不可造假的数据**，把日线信号里那些「看起来对、实际是幌子」的东西戳穿。

**姊妹 skill**（都回答不同层的问题，串起来用）：
- `youzi-stock-quality-screen` — 五标准过筛 + 量价四象限（**值不值得做**）
- `ashare-volume-resonance-analysis` — 四维共振打分（**这波是进攻还是撤退**）
- `ashare-auction-analysis` — 竞价/五档读法（**开盘怎么定调**）
- `ashare-limitup-openboard-diagnosis` — 涨停开板性质（**是洗还是派、能不能买**）
- 本 skill — **动手前验证**（**这个信号是真的吗**）

**触发场景**：
- 用户问「现在呢」「能不能进」「要不要减」
- 准备基于「买盘厚/卖盘薄」「突破前高/MA60」下结论时
- 用户问「能否做 T」
- 提醒里出现「盘中突破」类信号，需要判断是否成立

## 一、内外盘背离 → 识别「假托单诱多」（本 skill 最有用的一条）

### 概念

| 概念 | 定义 | 含义 |
|---|---|---|
| **外盘** | 以卖一价成交（**主动买**） | 买方急，愿意追 |
| **内盘** | 以买一价成交（**主动卖**） | 卖方急，愿意砸 |

**外盘占比 = 外盘 ÷ (内盘 + 外盘)**，`>55%` 偏买，`<45%` 偏卖。
腾讯字段：`f[7]` 内盘、`f[8]` 外盘。

### 判据表

| 挂单形态 | 内外盘 | 判读 | 操作 |
|---|---|---|---|
| 买盘厚 | 外盘 > 内盘 | 🟢 真承接 | 可持有 / 低吸 |
| **买盘厚** | **内盘 ≫ 外盘** | 🔴🔴 **假托单**：买1 大单是幌子，实际在砸 | **立刻减仓，别被大买单骗** |
| 卖盘薄 | 内盘 > 外盘 | 🔴 抛压真实，卖盘只是暂时撤了 | 走 |
| **卖盘薄** | **外盘 > 内盘** | 🟢 惜售 + 主动买，最强形态 | 最强 |

### 一句话铁律

> **挂单是意愿，成交是事实。**
> 「卖盘薄」≠「没人卖」，「买盘厚」≠「有人接」。
> **五档只能看想不想买卖，内外盘才看谁在真成交。**

### 实战（2026-10-26，两次命中，都验证对）

```
【示例股A 竞价】
  表面：卖1-5 合计仅 98 手（抛压极轻）+ 买2(20.00) 挂 1,435 手（像护盘）
  真相：内盘 9,089 / 外盘 2,101 → 外盘占比 18.8%（内盘 4.3 倍）
  判定：假托单
  结果：开盘 20.01 → 9 分钟砸到 18.95（−8.2%）

【示例股F 竞价】
  表面：买1(7.15) 挂 3,603 手
  真相：内盘 44,418 / 外盘 11,348 → 外盘占比 20.3%（内盘 3.9 倍）
  判定：同样的托单出货
  结果：开盘 −5.67%，之后直奔跌停 6.82
```

**反向对照（同日能源ETF）**：内盘 490 / 外盘 1,516 → 外盘占比 75.6%，买1 挂 6,301 手 → **真实承接**，当天在大盘 −1.93% 时逆势 +0.76%。

## 二、盘中突破 ≠ 收盘确认

**盘中冲过关键位（MA60 / 前高 / 整数关口）不算突破，必须看收盘价站稳。**

### 反面教材（示例股A 2026-10-20）

```
10/20 盘中冲到 27.18（突破前高），量比 1.57，收盘 25.61 → 长上影
10/21 −6.01% → 10/22 −8.48% → 10/23 −6.31%
四天从 27.18 跌到 20.64（−24%）
```

**当时的判断是「放量上涨、健康」，实际是「天量长上影 = 派发」。**

### 判据

| 突破形态 | 可信度 |
|---|---|
| 收盘站上 + **缩量/平量** | 🟢 高质量突破（锁仓） |
| 收盘站上 + 量比 1.5-3 | 🟡 可接受 |
| **盘中站上但收盘回落（长上影）** | 🔴 **假突破** |
| **长上影 + 量比 >3** | 🔴🔴 **假突破概率极高，等次日不回落再认** |

**操作纪律**：盘中突破只「记录待确认」，**收盘后**再决定是否进场。次日不回落 = 确认。

## 三、做 T 的适用性判断

**先否决，再谈怎么做。** 用户问「能否做 T」时，先跑这三个条件，缺一即答「不建议」。

| # | 前置条件 | 否决判据 |
|---|---|---|
| 1 | **趋势不是单边** | 单边下跌 / 逼近跌停 → ❌ 不做（正 T 会「卖在低点买在高点」） |
| 2 | **盘口有承接** | 买1 只有几手 → ❌ 不做（卖了买不回） |
| 3 | **跌幅不深** | 已亏 >15% → ❌ 摊薄杯水车薪，**该减仓不该做 T** |

**环境条件**：**下跌市（大盘 −2%、创业板 −1.9%）一律不做 T** —— 做 T 只在震荡市有效。

### 摊薄效果测算（劝退做 T 最有效的方式）

**务必算给用户看**，比讲道理有效十倍：

```
示例股A 成本 24.18、现价 19.08（亏 21%）
  · 做 T 赚 2%（成功一次）→ 成本 23.80，仍亏 19.8%
  · 连做 10 次全对        → 成本 20.40，仍亏 6.5%
  · 失败一次（−4%）       → 成本 24.90，亏 23.4%
➜ 10 次全对才勉强摊到 −6.5%，失败一次倒退两次。
➜ 此时正确动作是「减仓位」，不是「摊成本」。
```

### 第 4 条前置条件：**当日振幅 ≥ 2.5%**（2026-11 新增，最容易被忽略）

做 T 赚的是**当日振幅的一部分**。振幅不够，数学上就不成立。

```
示例股A 2026-11-05：
  当日振幅 16.88 → 17.18 = 1.68%
  完美做 T（卖最高买最低）赚 1.68%，扣手续费（万三双边+印花税 ≈0.13%）→ 净 1.55%
  300 股 × 17.08 × 1.55% ≈ 79 元
  要摊薄 1 个百分点要赚 73 元 → 一次 T 才够 1 个点
  要回本（−29.41% → 0）需 2,134 元 → 27 次全对
  做错一次亏 1.68% ≈ −79 元 → 要两次才能补
```

**判据表**：

| 当日振幅 | 结论 |
|---|---|
| **< 2%** | ❌ **不做 T**，赚的钱覆盖不了手续费和判断失误 |
| 2.5%-4% | 🟡 可做，但只做一次，见好就收 |
| **> 4%** | 🟢 值得做，振幅够撑一次完整来回 |
| > 8% | 🟢 高波动，但要注意单边趋势风险（见第 1 条） |

**➜ 开盘 10 分钟内就能算出当日振幅（今日高−今日低）。振幅不到 2% 时，直接答「今天不适合做 T」，别硬给价位。**

### 第 5 条前置条件：先算净收益，不划算就不做（2026-11-17 新增）

**别一上来就给价位。先做这张表 —— 算完自然知道哪只值得做、哪只是给券商交手续费。**

```
净收益 = 可做股数 × 现价 × 目标涨幅% − 手续费
手续费 = 股数 × 现价 × (佣金 0.03%×2 + 印花税 0.05%) ≈ 股数 × 现价 × 0.11%
```

实测（2026-11-17 四只持仓，目标涨幅都按 3% 算）：

| 标的 | 可做股数 | 赚 3% 毛利 | 手续费 | **净收益** | 结论 |
|---|---|---|---|---|---|
| 示例股A 17.26 | 200 | 103.6 | 3.8 | **≈100 元** | 🟢 值得做 |
| 博纳影业 6.32 | 300 | 56.9 | 1.9 | **≈55 元** | 🟢 值得做 |
| 示例股H 3.88 | 100 | 11.6 | 0.4 | **≈11 元** | ❌ 100 股太少，不做 |
| 能源ETF 1.697 | 400 | 20.4 | 0.7 | **≈20 元** | ❌ 振幅仅 2.21%，不做 |

**➜ 判据：净收益 < 30 元的，直接答「不值得做」，把注意力集中到那一两只上。**
**➜ 小仓位（≤100 股）+ 低价股（<5 元）几乎永远不值得做 T —— 涨 3% 才赚 11 元。**

### ⭐ 当日均价（VWAP）是做 T 的中枢，也是判强弱的标尺

**很多判断用「现价 vs 当日均价」「收盘 vs 当日均价」就够，不需要复杂指标。**

```python
# 腾讯实时行情算当日 VWAP
# f[6]  = 成交量（单位：手）
# f[37] = 成交额（单位：万元）  ← 注意是「万元」不是元
vwap = (f[37] * 10000) / (f[6] * 100)      # 元/股
```

**⛔ 单位坑（实测踩过）**：直接写 `f[37]/f[6]` 会得到 1746.16 这种离谱数字 —— 差 100 倍。
正确等价写法：`vwap = f[37] * 100 / f[6]`。

| 判据 | 含义 |
|---|---|
| **收盘价 < 当日 VWAP** | 🔴 **尾盘走弱**（卖盘压过买盘收的盘） |
| 收盘价 > 当日 VWAP | 🟢 尾盘走强 |
| **现价 > 当日 VWAP（盘中）** | 🟢 相对强，可做反 T（等反抽 VWAP 上方卖） |
| **现价 < 当日 VWAP（盘中）** | 🔴 相对弱，只做反 T 不做正 T |

**实测（2026-11-16 收盘）**：超声 17.26 vs VWAP 17.462（**−1.15%**）、博纳 6.32 vs 6.409（**−1.38%**）
→ 两只都是尾盘走弱，次日不该期待高开。

### 外盘 × 均价位置 —— 四象限决定「正 T 还是反 T」

| 外盘占比 | 现价 vs VWAP | 判读 | 做 T 方向 |
|---|---|---|---|
| **>55%** | 在 VWAP 上方 | 🟢🟢 买盘推上去的强势 | 可正 T，也可持有 |
| **>55%** | 在 VWAP 下方 | 🟢 有买盘但被压着 | **正 T 首选**（低了买） |
| **<45%** | 在 VWAP 上方 | 🔴 **矛盾：价格是卖盘打上去的** | **只做反 T**（反抽就卖） |
| **<45%** | 在 VWAP 下方 | 🔴🔴 单边弱 | 不做 T，直接减仓 |

**实测（2026-11-17 10:00）**：
- 超声 17.01 在 VWAP 16.846 上方（+1.33%），但**外盘只有 44.7%**
  → 「价格拉回 3.15% 是卖盘撤退造成的，不是买盘推的」→ **只做反 T**
- 博纳 6.09 外盘 58.1% + 量比 3.81 → 反弹中最强 → **正 T 可行**

### 破关键均线后，正 T 必须降级

**博纳 2026-11-17 破 MA20（6.029）后仍想做正 T → 三条降级：**

1. **仓位减半**：原计划 200 股 → 只买 100 股
2. **卖点下移**：不看 MA10（6.272），改看**刚破的 MA20（6.029）** —— 刚破的均线有套牢盘，是最现实的反弹终点
3. **条件加严**：必须「不破今日低 + 外盘转 >58% + 大盘不再破前低」三条同时成立

**➜ 一句话：上升趋势回踩是「买错还有趋势救你」，下跌趋势抢反弹是「买错就是接刀」。前者可正 T，后者只能反 T 或不做。**

### ⚠️ 成本数字幻觉：卖出后「追高买回」只让成本好看，不减少亏损

**这是用户最高频犯的错，必须每次都拦。**

实测（2026-11-05，示例股A）：

```
持仓 300 股，成本 24.195
用户在 16.90 卖出 100 股（当日最低 16.88 附近，卖在最低点）
股价一路涨到 17.55

若现在 17.55 买回 100 股：
  新成本 = (24.195×200 + 17.55×100) / 300 = 21.98   ← 成本数字从 24.20 降到 21.98，好看 2.2 元
  但实际多花：(17.55 − 16.90) × 100 = 65 元现金

总资产对比：
  A. 原封不动 300 股      → 5,208 元
  B. 卖了不买回 200 股    → 3,472 + 1,690 = 5,162 元
  C. 卖了又买回 300 股    → 5,208 − 46(净支出) = 5,162 元
                                     ↑ B 和 C 总资产完全一样！
```

**➜ 买回与否，总资产一分不差；买回只是把「已实现亏损」变回「账面成本」，让数字好看。**

**必须跟用户说的三句话**：
1. 「成本数字不改变亏损。」
2. 「现在追高买回 = 用错误纠正错误。」
3. 「只看一件事：这票还能不能涨。能涨就留着已有仓位，不能涨就别加。」

**两个可选方案（给用户选，别替他决定）**：
- **方案 A（推荐）**：不买回，剩 200 股，敞口天然降下来；涨了 200 股也在赚。
- **方案 B**：等回踩到 MA5 或当日均价附近再买回（比追高便宜 1.5-2%）。

### 「做 T 做反」的识别信号

用户常卖在当日最低点附近，然后股价反弹 —— 这是典型的**方向做反**，不是运气差。

| 信号 | 说明 |
|---|---|
| 卖出价距当日最低 < 1% | 🔴 卖在底部，做反了 |
| 卖出后 30 分钟内涨幅 > 2% | 🔴 卖飞 |
| 卖出时外盘占比 > 50% | 🔴 主动买占优时不该卖 |
| 卖出时刚站上 MA5 | 🔴 突破位卖出 |

**事后必须做的一件事**：明确说「这一笔做反了，多亏 X 元」，但**同时肯定方向**（如果减仓方向本身是对的）。
用户接受「卖点差、方向对」这个说法，不接受全盘否定。

## 真要做 T 时的四条铁律（用户既有纪律）

1. **必须有底仓**
2. **正 T 卖点在 9:30-10:00**（早盘冲高窗口）
3. **卖了不追、买回必须更低、仓位 ≤ 底仓 1/2**
4. **连错 2 次停手**

## 四、数据获取层的两个坑

### ① 竞价量占比：必须用「昨日」成交量

```python
# ❌ 错：盘中/早盘时 rows[-1] 已经是「今天」，占比会算成 100%
prevv = float(rows[-1][5])

# ✅ 对：先判断最后一根是不是今天
today = datetime.now(BJ).strftime("%Y-%m-%d")
is_today = rows[-1][0] == today
prevv = float(rows[-2][5]) if is_today else float(rows[-1][5])
ratio = auction_volume / prevv * 100
```

**实测症状**：三只票占比全部算成 `100.00%` —— 一看就不对，说明分母取错了。

### ② 腾讯日K字段顺序是 `[date, open, close, high, low, volume]`

**不是 OHLC**。昨高取 `k[-2][3]`、昨低取 `k[-2][4]`（且要按上面的盘前/盘中规则换 index）。

## 五、输出结构（用户偏好）

用户要的是**结论 + 可执行动作**，不是数据罗列。固定这个骨架：

```
1. 一句话结论（做 / 不做 / 等）
2. 验证表（把「表面信号」和「真相」并排，矛盾点加粗）
3. 关键价位块（ASCII 竖排价位，标出死线/压力/支撑）
4. 分情况操作表（情况 | 动作 | 价位）
5. 一句话总结（3-4 条编号，每条一句话）
6. 风险提示（非投资建议）
```

**必须做的一件事**：如果用户的某个**旧判断/旧卖出动作事后被验证是对的**，明说一句「这个决策验证正确」并给数据（例：「你在 20.90 减半，现在 20.35，避开了 2.6% 跌幅」）。用户会真金白银按分析下单，这种事后校验比事前预测更有价值。

## 六、Pitfalls

- **别用「卖盘薄」当利好**：卖盘可以随时撤，薄只说明当下没人挂；要看内盘有没有在砸。2026-10-26 示例股A卖1-5 仅 98 手，看着极轻，实际内盘是外盘 4.3 倍。
- **别把「盘中突破」写进告警当买点**：盘中触发会被反复打脸。告警里写「站上 MA60」时，提示语必须带「收盘确认更好」。
- **量比在 9:30 前是 0**：早盘用绝对成交量比（今日量/5日均量），不要用量比字段。
- **ETF 的竞价量和内外盘量级完全不同**：ETF 竞价量常在 0.001-0.1 亿股，内外盘绝对值也小，阈值要单独设（外盘占比仍可用同一套 55%/45%）。
- **跌停附近的「买盘厚」是接刀不是抄底**：2026-10-26 示例股F 6.85 附近买1-3 堆 14,027 手，那不是支撑，是排队接刀 —— 此时正确动作是撬板就走。
- **做 T 的成功率不能只看单次收益**：一次赚 0.5% 但失败一次亏 4%，期望值是负的。要算「需要多少次成功才能覆盖一次失败」。
- **当日振幅 <2% 直接否决做 T**，别硬给价位。300 股 + 振幅 1.68% = 一次赚 79 元，回本要 27 次全对。
- **VWAP 单位坑**：腾讯 `f[37]` 成交额是**万元**、`f[6]` 成交量是**手**，`f[37]/f[6]` 会差 100 倍（算成 1746.16 这种）。正确：`(f[37]*10000)/(f[6]*100)`。
- **净收益 <30 元就别做 T**：小仓位（≤100 股）+ 低价股（<5 元）涨 3% 只赚 11 元，扣完费用几乎白干。先把「可做股数 × 涨幅 − 手续费」算成表，再决定动哪只。
- **用户卖出后问「要不要买回」时，先讲成本数字幻觉**：买回只降低账面成本，总资产不变。追高买回是多花钱买一个好看的数字。
- **用户说「我 X 元卖了」时，先对比当日最低价**：卖在最低点附近 1% 内 = 做反了，要直说「卖点差」但同时肯定「方向对」（若减仓方向本身合理）。
- **卖出动作本身可能是对的**：深亏（>20%）减仓降低敞口是正确决策，只是执行价差。别把「卖点差」说成「不该卖」。
