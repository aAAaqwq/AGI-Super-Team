# 主力拉升前五步曲（地量伏击法）

**来源**：2026-10-29 对 6 只主升浪个股（超声电子 +84.7%、襄阳轴承 +98.1%、上海九百 +65.3%、光洋股份 +58.8%、多伦科技 +51.5%、凯众股份 +48.6%）的起涨日量化复盘，**六只全部符合同一模式**。

**用途**：
1. 用户问「主力拉升前有什么规律」「怎么找起涨前的票」
2. 判断「今天的地量是吸筹还是无人问津」
3. 建立观察池 + 等确认启动再买入（**本 skill 核心是"不预测、只确认"**）

### 六条共性

1. **起涨日很平淡**：涨跌幅 **−2.8% ~ +1.6%**，没有一只是当天大涨启动
2. **起涨日量能 ≤1.7x**：4 只是缩量 **0.46-0.67x**
3. **起涨价在 MA30 ±5.4% 内**：贴近均线，不追高
4. **起涨前必有"地量日"**：量能缩到 20 日均量的 **0.43-0.68 倍**
5. **到首板需 3-11 天**：多数 5-10 天，先小阳堆积再涨停
6. **起涨前 1-2 天常有"最后一跌"**：−2% ~ −9.6%，且是缩量跌

## 二、五步曲（主力完整操作路径）

```
第 1 步  放量试盘（1.3-2.0x 20日均量，涨 +3~+6%）
           ↓  测上方抛压
第 2 步  缩量洗盘（0.5-0.9x，跌 -2~-5%，持续 3-8 天）
           ↓  洗掉浮筹
第 3 步  地量见底（<0.7x）        ← ⭐ 关键信号
           ↓  卖盘枯竭
第 4 步  最后一跌（-2~-9%，缩量）  ← ⭐ 黄金观察点
           ↓  挖坑洗最后一批
第 5 步  小阳堆积（+1~+4%/天，量 0.8-1.5x，连续 3-7 天）
           ↓
        首板（+10%，量 1.5-2.5x）
```

## 三、⭐ 核心机制：观察期 + 确认启动（**用户明确要求**）

**铁律：不预测，只确认。找到候选后不立刻买，进入观察池，等启动信号出现才买。**

### 阶段 1：扫描发现（收盘后）

**必要条件（缺一不可）**：

| # | 条件 | 判据 |
|---|---|---|
| 1 | **地量** | 今日量 ≤ 20 日均量 **0.7 倍** |
| 2 | **贴近均线** | 收盘价在 **MA30 ±5%** 内 |
| 3 | **当天平淡** | 涨跌幅 **±3% 内** |
| 4 | **前期有试盘** | 近 25 日内有某天量 > 1.3x 20日均量 |
| 5 | **无天量** | 近 10 日没有 > 3x 的天量 |

**加分项**：长下影 · 前 1-2 天缩量跌 −3% 以上 · 股东户数减少 · 板块 3 家以上涨停 · 流通 30-100 亿

**排除项**：起涨前已涨停过（那是第二波）· 量能 >2x · 距 MA30 >+10% · 均线全破且距离 >10%

**→ 输出「观察池」，加入后连续跟踪**

### 阶段 2：观察期（1-5 个交易日）

**观察池里的票，每天收盘检查，只看不动手。**

| 观察项 | 记录 |
|---|---|
| 量能是否继续萎缩（<0.6x = 极度地量） | 每天记 |
| 是否出现"最后一跌"（缩量跌 −3% 以上） | **最佳埋伏点** |
| 是否出现长下影 | 主力接货痕迹 |
| 是否跌破前低 | 破了剔除 |
| 大盘环境是否配合 | 大盘急跌时暂停 |

**观察期淘汰规则**：
- 放量下跌（>1.5x 且跌 −5%）→ **剔除**（主力出货，不是洗盘）
- 跌破观察期内最低点 −3% 以上 → **剔除**
- 超过 8 个交易日仍无启动 → **剔除**（失效）

### 阶段 3：确认启动（**买点，必须等这个**）

**满足以下任意一条才算"确认启动"：**

| # | 确认信号 | 判据 | 强度 |
|---|---|---|---|
| **A** | **放量小阳突破** | **涨 +3%~+7%** 且 **量 1.3-2.5x** 且 **收盘站上 5 日新高** | 🟢🟢 最强 |
| **B** | **涨停** | 涨 +9.5% 以上，量 1.5-2.5x | 🟢🟢 |
| **C** | **放量长下影反包** | 跌到 −3% 后拉回收红，量 >1.5x | 🟢 强 |
| **D** | **连续两日小阳** | 连续 2 天 +1%~+3%，量温和放大 0.9-1.5x | 🟡 中等 |

**❌ 不算确认（别提前进）**：
- 缩量小阳（量 <0.9x）—— 只是自然波动
- 放量下跌后的小反抽 —— 是出货中的反弹
- 大盘暴跌日的个股小涨 —— 不成立

### 阶段 4：买入与止损

| 项 | 规则 |
|---|---|
| **仓位** | 确认启动首日 ≤10%，次日站稳可加至 20% |
| **止损** | **确认启动那天的开盘价下方 1%**，或 **−5%** 取更近的 |
| **加仓** | 突破观察期最高点 +2% 且放量 |
| **止盈** | 首板后看能否 2 板；不板则次日冲高减半 |

## 四、⚠️ 适用环境（用错会亏钱）

| 环境 | 适用性 |
|---|---|
| **大盘横盘 / 小幅震荡** | ✅ **最佳**（地量 = 吸筹） |
| 大盘上涨趋势中 | ✅ 可以 |
| **大盘急跌中** | ❌ **不适用**（地量 = 无人问津，不是吸筹） |

**判据**：看创业板指数近 3 日涨跌幅
- 近 3 日累计 > −2% → 可用
- 近 3 日累计 < −5% → **暂停扫描**

**实例（2026-10-29）**：创业板当日 −3.60%，扫出的"地量股"（合众思壮 0.62x）全部均线跌破 −11% —— 那是下跌趋势，不是横盘蓄势，**不适用**。

## 六、Pitfalls

- **地量必须配合横盘**：地量 + 下跌 = 没人要；地量 + 横盘 = 吸筹。判据：MA30 走平或向上、近 20 日振幅 <25%
- **"起涨前"≠"第一波回调"**：如果近 20 日已涨停过，那是第二波，不适用本框架
- **不要提前埋伏**：这是本 skill 最重要的一条。六只票从起涨到首板要 3-11 天，提前买要熬一周，且可能失败
- **观察期不能超过 8 个交易日**：超过说明逻辑失效
- **大盘急跌时暂停**：2026-10-29 实测，急跌中地量全是"无人问津"
- **放量下跌必须剔除**：>1.5x 且跌 −5%，是出货不是洗盘
- **股东户数看变化率不看绝对值**：季度数据，可能过期 4 个月
