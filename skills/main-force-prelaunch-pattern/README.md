# 主力拉升前五步曲 · 使用说明

## 一、以后怎么触发这个 skill

**你只要说这些话，我就会自动加载：**

| 你说 | 我会做什么 |
|---|---|
| **「找起涨前的票」** / 「有没有还没启动的」 | 跑地量扫描，输出观察池候选 |
| **「主力前期怎么操作的」** | 讲五步曲 + 六只票的实战轨迹 |
| **「今天这个地量是吸筹还是没人要」** | 用「地量+横盘 vs 地量+下跌」判据回答 |
| **「观察池怎么样了」** | 跑 `--watch`，报告观察期进度和是否出现买点 |
| 「我买的 XX 现在算启动了吗」 | 用阶段 3 的四个确认信号判定 |

**自动触发词**：起涨前、地量、伏击、观察池、主力吸筹、还没启动

## 二、核心：观察期 + 确认启动（这是你要求的机制）

```
第 1 步  收盘后扫描 → 发现候选
         条件：地量(≤0.7x) + 贴MA30(±5%) + 当天平淡(±3%) + 前期有试盘 + 无天量
           ↓
第 2 步  加入观察池 → 【观察期 1-5 天，只看不动手】
         每天收盘跑 --watch
         淘汰：放量下跌(-5%以上) / 跌破观察期低点-3% / 超8天没启动
           ↓
第 3 步  【确认启动】← 必须等这个才买
         A 放量小阳突破5日新高（涨3-7%，量1.3-2.5x）★最强
         B 涨停（量1.5-2.5x）
         C 放量长下影反包
         D 连续两日小阳（量0.9-1.5x）
           ↓
第 4 步  买入
         仓位 ≤10%，止损 = 启动日开盘价下方1% 或 -5%
```

**⚠️ 铁律：扫描只是「发现」，不进观察池不买，不确认启动不买。**

---

## 三、为什么必须等确认启动

**六只票的真实数据**：

| 股票 | 起涨日 | 到首板 | 中间等了几天 |
|---|---|---|---|
| 超声电子 | 8/26 | 9/7 | **等了 9 天** |
| 襄阳轴承 | 9/22 | 9/24 | 等了 3 天 |
| 上海九百 | 12/12 | 12/18 | 等了 4 天 |
| 多伦科技 | 9/21 | 10/12 | **等了 11 天** |
| 凯众股份 | 12/24 | 1/7 | **等了 9 天** |
| 光洋股份 | 8/20 | 9/2 | **等了 10 天** |

**➜ 从「起涨日」到「首板」平均要 5-10 个交易日。**

**➜ 如果你在起涨日就买，要熬一周，而且这一周里可能跌 5%（洗盘）。**

**➜ 等「确认启动」再买，虽然成本高 3-5%，但不用熬，而且启动失败的概率小很多。**

## 四、脚本用法

### 扫描候选

```bash
python3 prelaunch_scan.py                    # 扫龙擎主力池 78 只
python3 prelaunch_scan.py --codes 002403,002368   # 扫指定股票
```

**输出**：
```
环境检查: 创业板近3日 -4.6% → 可扫描
✅ 符合五条必要条件: 2 只
代码      名称        现价    今日%   量/20均   距MA30    MA30  加分项
002403   爱仕达      10.84   -2.95%    0.62    +4.59%   10.36  长下影/MA30向上
```

### 加入观察池

```bash
python3 prelaunch_scan.py --add 002403       # 单只
python3 prelaunch_scan.py --add 002403,002383  # 多只
```

### 每日检查（收盘后跑）

```bash
python3 prelaunch_scan.py --watch
```

**输出示例**：
```
🚨 确认启动（可买入）
  002403 爱仕达  11.20（+4.20%/量1.8x）
    信号: A 放量小阳突破5日新高
    加入价 10.84 → 现价 11.20（+3.3%）
    ⚡ 建议: 仓位≤10% | 止损 10.65

👀 观察中（不能买）
  002383 合众思壮  第3天  观察中 量0.62x 涨+0.4% 距加入价+0.0%

❌ 剔除
  002500 XX: 放量下跌 -6.2% / 1.8x → 主力出货
```

### 查看观察池

```bash
python3 prelaunch_scan.py --pool
```

## 六、适用环境（用错会亏钱）

| 大盘环境 | 适用性 |
|---|---|
| 横盘 / 小幅震荡 | ✅ **最佳**（地量=吸筹） |
| 上涨趋势 | ✅ 可以 |
| **急跌** | ❌ **不适用**（地量=无人问津） |

**脚本会自动检查**：创业板近 3 日累计跌幅 < −5% 时提示「暂停扫描」。
