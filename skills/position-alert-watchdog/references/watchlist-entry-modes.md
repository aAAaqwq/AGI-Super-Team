# 观察池买点：A 类（起涨前）vs B 类（已启动）必须分开

## 问题：位置规则被无脑套到板块龙头上

`youzi-stock-quality-screen` 的位置统计（878 只票平均）说「距 MA30 >+15% 降级」，
`main-force-prelaunch-pattern` 说「贴近 MA30 ±5% 才算起涨前候选」。

**这两条都是 A 类规则。把它们套到已经涨停启动的板块龙头身上，会错过整段。**

## 实测代价：锋龙股份 002931

```
11/09  收 43.86（首板）｜通用设备板块 5 只涨停（当日梯队最好）
       20日 3 次涨停｜历史最大连板 2
       距 MA30 +13.4%

我的结论（按位置规则）：「股价 43.86 偏高、距 MA30 +13.4%，等回踩 MA5 40.90 再考虑」

11/10  直接 53.08 涨停（+21%），全程未回踩 MA5
```

判断依据本身没错，错在**用错了类别**。

## 两类判别表

| | **A 类：起涨前候选** | **B 类：已启动强势股** |
|---|---|---|
| 形态 | 地量 + 横盘 + 当天平淡（±3%） | 已涨停 / 2 连板 + 板块梯队 ≥5 只 |
| 距 MA30 | 严格 ±5%（候选）到 +10%（上限） | **+10~20% 是正常状态，不是追高** |
| 量能 | ≤0.7x 地量 | 1.5-8x 放量 |
| 入场 | 等 A/B/C/D 确认启动信号 | 见下面三条 |
| 等回踩 MA5 | ✅ 正确做法 | ❌ 等不到，行情不给机会 |
| 止损 | 启动日开盘价下方 1% 或 -5% | **昨低**（MA5 太远，跌到那儿已亏 12%） |

## B 类的三条入场（任选其一）

1. **次日高开不破前低 → 跟**（最常用）
2. **首次回调到「首板收盘价」附近** + 缩量止跌 → 跟
3. **3 板后第一次回调** → 跟（买在分歧，不买在涨停）

**止损统一用昨低。仓位 ≤1 成。3 天不涨就走。**

## 例外的边界（很重要）

**例外只给「有梯队的龙头」。**

| 情况 | 处理 |
|---|---|
| 板块梯队 ≥5 只 + 有连板基因 | ✅ B 类，位置门槛让位 |
| 板块 3-4 只 | 🟡 半放行，仓位减半 |
| **板块 0-2 只（独苗）** | 🔴 **仍严格禁追** —— 无梯队的连板最多两日游 |

## 落到盯盘脚本的规则写法

```python
# A 类（起涨前，无 cost 的观察股）
("near_ma5", "ma5", "🎯 回踩 MA5（±2%）→ 买点观察")
(">=", "limit_up", "🔥 涨停 → 强势，看能否连板")
("<=", "ma30", "🔴 跌破 MA30 → 放弃")

# B 类（已启动，追踪连板延续）
(">=", "prev_high", "🟢 破昨日高 → 连板延续，可跟")
("<=", "prev_low",  "🔴 破昨日低 → 一日游结束，放弃")
(">=", "limit_up",  "🔥 涨停 → 强势，看能否连板")
```

**⚠️ 两类都不能用 `(">=", "ma60", ...)`** —— 已在 MA60 上方的票会天天触发，
实测出现过东方创业 −5.74% 却推「🟢 站上 MA60 → 突破确认」的假信号。
