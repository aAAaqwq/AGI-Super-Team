# Daniel 小红书图文写作

目标：把素材或公众号长文重写为「与我有关、值得收藏、可以照做」的小红书图文笔记，交付可直接复制发布的标题 + 正文 + 标签 + 封面 / 配图方案。

## 前置（不可跳过）

涉及 Daniel 个人 IP 的内容：先 `daniel-self-media-top-mindset` 五维检查 → `daniel-content-writing-style` 证据账本与阶段状态机（EVIDENCE → CORE\_DRAFT → APPROVAL → PLATFORM\_ADAPTATION → FINAL\_AUDIT → FINAL\_APPROVAL）。本 Skill 只提供小红书图文写法，不拥有绕过版本批准与外部授权的权限。

写作资源（风格、声音、模板）来自 `daniel-writer`；本 Skill 的小红书输出合同对齐 `daniel-writer/references/xhs-card-contract.md` 与 `templates-xiaohongshu.md`。

## 核心原则



1. **承诺先行**：每篇至少一个清晰承诺 —— 省时间 / 避坑 / 拿模板 / 做选择 / 看对比 / 真实经验。

2. **单点聚焦**：一篇只服务一个核心需求、一个主张。

3. **收藏优先**：正文给「资产」（清单 / 步骤 / 对比 / 模板），收藏是小红书算法权重最高的互动。

4. **真实边界**：事实有出处，判断标注为判断，不编造亲历、截图或结果。

5. **不保证爆火**：任何结果不得表述为「保证爆款 / 必火」，不得用流量词暗示未经验证的分发效果。

## 爆款六要素



| 要素           | 要点                                                          |
| ------------ | ----------------------------------------------------------- |
| 标题（≤20 字含标点） | 数字 + 痛点 + 人群；自我暴露 / 数据引诱 / 正话反说；关键词前置吃搜索；第一任务是筛选精准用户        |
| 封面（3:4）      | 缩略图 3 秒看懂主题与收益；对比感 + 核心标签（≤5 字）；封面文案承接标题钩子；固定构图 / 风格 / 场景   |
| 开头（前 3 行）    | 0.1 秒给价值 / 冲突 / 结果 / 痛点；不写废话铺垫                              |
| 正文（≤1000 字）  | 总分总（点题 - 拆分 - 总结）；故事 + 观点 + 方法 + 金句；70% 干货 + 30% 情绪；短段落有呼吸感 |
| 标签（4-8 个）    | 覆盖任务 / 人群、痛点 / 方法、工具 / 场景三层；用正文真实名词                         |
| 互动           | 结尾收藏钩 / 评论钩 / 关注钩；预埋争议点诱导评论                                 |

## 六类爆款结构



* 结果型：我用什么方法拿到了什么结果

* 避坑型：不要再这样做，问题出在哪里

* 清单型：一口气整理 N 个工具 / 步骤 / 模板

* 对比型：A 和 B 怎么选，谁适合谁

* 复盘型：这次为什么数据好 / 差，我学到了什么

* 模板型：直接给可复制的表格 / 流程 / 清单

## 公众号 → 小红书转化六步



1. **拆母稿**：核心观点、可收藏资产（清单 / 步骤 / 对比 / 模板）、金句、真实案例；一篇长文 = 1 篇主笔记 + 一组系列选题。

2. **定标题**：≤20 字，数字 + 痛点 + 人群，关键词前置。

3. **定封面**：3:4，封面文案 = 标题钩子，对比感 + 核心标签。

4. **重写正文**：钩子开头 → 清单正文 → 互动结尾，≤1000 字，口语化、短段落、emoji 做视觉标点。

5. **配图**：4-6 张含封面，一图一要点，统一风格。

6. **标签 + 发布检查**：4-8 个标签，发布前人工复核词义、可用性与品牌风险。

* 不得在同一篇笔记或卡组内重复 emoji；不得用 emoji 代替证据、风险文字或卡片层级。

## Emoji 合同（对齐 templates-xiaohongshu.md）



* 正文默认 4-6 个互不重复 emoji；封面默认不用（确有帮助时最多 1 个）；每个 emoji 全篇只出现 1 次。

* 清单用数字或普通项目符号，不连续重复 `✅` `👉` `🔥`。

* 不用 emoji 替代必要文字：去掉 emoji 后标题、步骤、风险仍表达完整。

* 风险、授权、失败、未知项用克制符号，不用庆祝 / 夸张表情削弱事实边界。

* 标签不穿插进正文句子，集中放在正文末尾标签区；不使用 `#必火` `#热门` `#流量密码`。

## 硬门



* 关键事实、数字、第一人称经历无证据：`BLOCK`。

* 泄露雇主、客户、家人、精确收入、未落地计划且无必要受众价值：`BLOCK`。

* 依赖卖惨、阶层恐惧、暴富承诺、刷量、伪造互动：`BLOCK`。

* 任何表述承诺「保证爆火」：`BLOCK`。

* 未经用户批准产出平台稿，或未经单独授权发布 / 存草稿：`BLOCK` / `EXTERNAL_AUTH_REQUIRED`。
