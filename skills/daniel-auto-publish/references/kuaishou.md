# 快手创作者发布流程

来源模型：`cp.kuaishou.com`；参考 `social-auto-upload` commit `008e4ff` 的视频和图文流程。实时界面优先。

## 登录

1. 打开快手创作者服务平台。
2. 确认账号，由用户扫描登录二维码。
3. 打开发布页；阅读引导层后再关闭。

## 视频

1. 选择视频上传，文件只选择一次。
2. 等待“上传中”消失，并确认没有上传错误。
3. 按实时表单填写描述和标题。
4. 添加话题。经审计实现只添加前三个，不要误认为这是平台上限。
5. 设置并核对封面和裁剪。
6. 选择立即或定时发布，核对准确时间。
7. 停在复核页，逐项对照发布简报。
8. 发布只点击一次；若出现独立的“确认发布”弹窗，把它视为同一次已授权提交。
9. 在内容管理页核验。

## 图文

1. 切换到图文标签页。
2. 按预定顺序上传图片。
3. 检查引导层后再关闭。
4. 填写图文正文；实时表单存在独立标题字段时填写标题。
5. 添加话题并等待素材处理完成。
6. 需要时设置排期。
7. 复核、单次发布；如有确认弹窗只确认一次，再到内容管理页核验。

## 风险停止点

- 超过预期处理时间后上传状态仍然不明；
- 实时界面缺少简报所需的标题字段；
- 确认弹窗改变了可见范围、声明或发布目标；
- 出现账号或会话验证。
