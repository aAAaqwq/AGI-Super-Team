# 哔哩哔哩创作者发布流程

经审计项目把哔哩哔哩发布委托给外部 `biliup` 二进制。以下真实浏览器流程把相同元数据映射到哔哩哔哩创作中心；实时界面优先。

## 登录

1. 使用用户常用浏览器打开哔哩哔哩创作中心。
2. 二维码、密码或 MFA 登录交给用户。
3. 确认频道身份并进入视频投稿。

## 视频

1. 视频文件只上传一次，等待处理完成。
2. 填写标题和简介。
3. 选择正确分区。源码 CLI 要求数字 `tid`；浏览器内应核对人类可读的分区名称。
4. 添加标签。
5. 上传并确认封面。
6. 检查类型、来源、版权和原创字段，只根据用户提供的事实设置。
7. 选择立即或定时发布，确认时区。
8. 复核完整投稿信息。
9. 只提交一次。
10. 在稿件管理中核验，并报告处理中、审核中、已定时、被退回或已发布。

## 安全提示

- 用户要求真实浏览器 Computer Use 时，不要下载或执行 `biliup`。
- 不要推断分区、版权来源或原创属性。
- 上传完成不等于审核通过。
