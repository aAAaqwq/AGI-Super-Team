# 小红书创作者发布流程

来源模型：`creator.xiaohongshu.com`；参考 `social-auto-upload` commit `008e4ff` 的浏览器上传器。实时界面优先。

## 登录

1. 打开小红书创作服务平台。
2. 确认创作者账号。
3. 由用户使用小红书 App 扫描创作者登录二维码。
4. 出现 CAPTCHA、异常登录警告或创作者身份不符时停止。

## 视频笔记

1. 打开发布页面并选择视频模式。
2. 上传一个视频。
3. 同时等待可编辑标题栏和明确的处理完成预览；不要只以标题栏出现判断上传完成。
4. 填写标题。经审计实现会截断至 20 字，执行时确认实时上限。
5. 填写正文或简介。
6. 逐个添加话题并选择可见候选项，避免未匹配的原始标签意外留在正文。
7. 用户提供视频封面时上传并确认。
8. 只有用户拥有权利并明确授权声明时才设置原创。
9. 设置立即或定时发布，核对本地日期和时间。
10. 核对账号、标题、正文、话题、封面、声明和排期。
11. “发布”或“定时发布”只点击一次。
12. 等待成功或处理中结果，再到内容管理页核验。

## 图文笔记

1. 选择文件前先切换到图文模式。
2. 按预定顺序上传图片。
3. 等待标题、正文编辑器可见且缩略图处理完成。
4. 填写标题和正文。
5. 话题数量以实时平台上限为准；经审计代码最多添加 10 个。
6. 确认原创和商业披露。
7. 设置立即或定时发布。
8. 复核、单次提交，并在内容管理页核验。

## 小红书专项安全规则

- 在用户确认当前授权前，把非官方创作者自动化视为具有显著平台协议风险。
- 官方分享或开放平台能力满足场景时优先采用官方路径。
- 保持账号、浏览器和网络稳定，仅进行低频、有明确目的的操作。
- 不盲目重试发布按钮。经审计代码存在无限重试；本 Skill 用“单次提交 + 管理页核验”替代。
- 出现验证、限流、账号限制或无法解释的跳转时立即停止。
