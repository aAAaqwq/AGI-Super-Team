# TikTok 与百家号历史流程

这两个平台在经审计项目中只存在于历史或示例路径，不属于当前统一 CLI 能力。所有步骤只能作为未经实时验证的界面定位线索。

## TikTok Studio 视频

1. 打开 TikTok Studio 并确认账号。
2. 登录和安全挑战交给用户。
3. 打开上传页面并选择一个视频。
4. 等待编辑器出现且发布按钮明确可用。
5. 填写说明、标题和 Hashtag。
6. 用户提供封面时上传并确认。
7. 选择立即或定时发布，核对时区。
8. 核对账号、素材、说明、Hashtag、封面、披露、可见范围和排期。
9. 发布只点击一次。
10. 在 TikTok Studio 内容页核验最新内容和内容 ID。

不要复制经审计源码中的无限发布重试或自动切换语言逻辑。实时界面不匹配时停止。

## 百家号视频

1. 打开百家号创作中心并确认账号。
2. 登录和百度安全验证交给用户。
3. 打开视频创建页，文件只上传一次。
4. 等待编辑器、上传完成以及封面生成或选择完成。
5. 严格填写用户提供的标题，不自动追加营销文案。
6. 按实时表单完成分类、简介、标签、来源、版权和声明。
7. 选择立即或定时发布，核对日期和时间。
8. 复核、单次发布，并在内容管理页核验。

出现“百度安全验证”时停止，绝不自动化或绕过。
