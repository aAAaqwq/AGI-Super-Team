# 通用浏览器发布流程

## 1. 发布前检查

1. 确认平台和当前账号身份。
2. 确认每个本地素材存在且可正常打开。
3. 对照实时上传器检查方向、时长、分辨率、封面比例和文件大小。
4. 准备准确的标题、正文、话题、封面、可见范围、排期和声明。
5. 确认排期时区以及平台是否采用浏览器本地时间。
6. 同一账号只保留一项活动任务。

## 2. 登录和会话检查

1. 使用用户常用浏览器档案打开官方创作者网站。
2. 上传前检查页面显示的头像、账号或频道。
3. 密码、二维码、MFA、CAPTCHA 或设备确认交给用户完成。
4. 网站提示异常登录、账号限制或身份不符时停止。

不要导出或打印 Cookie，也不要把认证状态复制进 Skill 目录。

## 3. 上传和编辑

1. 进入平台创建或上传页面。
2. 选择文件前先切换到视频或图文模式。
3. 素材只上传一次。
4. 等待编辑器可见，并确认上传或处理已经明确完成。
5. 填写标题和正文，回读页面最终显示值。
6. 平台要求时，通过候选建议界面添加话题或标签。
7. 仅根据简报设置封面、播放列表、合集、受众、可见范围、地点、商品链接等元数据。
8. 仅根据用户提供的事实设置原创、商业、AI/合成内容、版权或来源声明。

## 4. 复核门

提交前逐项对照实时页面和简报：

- 账号正确；
- 素材及顺序正确；
- 标题、正文、话题没有意外截断；
- 封面正确；
- 可见范围或准确排期及时区正确；
- 受众和声明正确；
- 没有错误、政策警告、安全挑战或未完成上传。

优先保存草稿。涉及后果的字段存在差异时，展示给用户，不要静默修改。

## 5. 单次提交

1. 获取所需的最终授权。
2. 最终发布、定时或保存草稿按钮只点击一次。
3. 等待成功提示、跳转至管理页或明确的处理中状态。
4. 不要只因跳转缓慢而再次点击。

## 6. 结果核验

1. 打开平台内容管理页。
2. 核对账号、标题、时间、状态和内容类型。
3. 有条件时记录内容 URL 或 ID。
4. 严格区分 `处理中`、`审核中`、`已定时`、`草稿` 与 `已发布`。
5. 找不到内容时返回 `未知` 或 `未找到`，不要自动重新提交。

## 7. 安全恢复

- 上传失败：保持页面、记录错误，重新上传前询问用户。
- 会话过期：停止，让用户重新认证。
- CAPTCHA 或安全挑战：交给用户。
- 页面改版：读取最新界面，不猜测旧坐标。
- 可能重复：任何再次提交前先查内容管理页。
