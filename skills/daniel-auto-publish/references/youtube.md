# YouTube Studio 发布流程

来源模型：参考 `social-auto-upload` commit `008e4ff` 的 YouTube Studio 上传流程。实时界面优先。

## 登录

1. 使用用户常用 Chrome 档案打开 YouTube Studio。
2. Google 登录、MFA 和频道选择交给用户。
3. 上传前确认当前频道。

## 视频

1. 选择“创建/上传视频”，文件只选择一次。
2. 等待“详细信息”对话框。
3. 填写标题和说明。
4. 用户提供自定义缩略图时上传。
5. 仅在用户明确要求时加入已有播放列表或新建播放列表。
6. 选择受众设置，绝不推断内容是否面向儿童。
7. 用户要求时打开更多详细信息并添加标签。
8. 逐步完成检查和可见范围设置，并阅读所有警告。
9. 严格按要求选择公开、不公开或私享。
10. 经审计源码没有实现定时发布。用户要求定时时，只能在确认日期、时间和时区后使用 Studio 实时选项。
11. 等待上传和处理达到 Studio 允许保存或发布的状态。
12. 停在最终复核页，核对频道、标题、缩略图、播放列表、受众、检查结果、可见范围和排期。
13. 保存或发布只点击一次。
14. 记录视频 URL，并在 Studio 内容页核验可见范围和状态。

## 风险停止点

- 频道身份不明确；
- 出现版权或检查警告；
- 缺少受众分类；
- 上传尚未完成；
- 可见范围或排期与简报不同；
- 重复或批量生产内容可能违反 YouTube 垃圾内容政策。
