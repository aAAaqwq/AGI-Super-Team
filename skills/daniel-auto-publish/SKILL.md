# Daniel 自动发布

使用平台可见的创作者界面和稳定的真实浏览器会话。目标是正确、合规、低频且可核验的发布，不是“不可检测”。

## 路由任务

1. 确认平台和内容类型。
2. 始终读取 [通用发布流程](references/common-workflow.md) 与 [检测面和账号安全边界](references/detection-and-safety.md)。
3. 只读取对应的平台参考：

- 抖音：[douyin.md](references/douyin.md)
- 小红书：[xiaohongshu.md](references/xiaohongshu.md)
- 快手：[kuaishou.md](references/kuaishou.md)
- 微信视频号：[wechat-channels.md](references/wechat-channels.md)
- 哔哩哔哩：[bilibili.md](references/bilibili.md)
- YouTube：[youtube.md](references/youtube.md)
- TikTok 或百家号：[legacy-platforms.md](references/legacy-platforms.md)

发布图文、文章或需要封面排版时，按需读取：

- 模板选择、卡片结构和平台尺寸：[typography-template-routing.md](references/typography-template-routing.md)
- 微信文章正文主题：[md2wechat-article-templates.md](references/md2wechat-article-templates.md)
- Markdown 到微信 HTML 的预览和发布门：[md2wechat-preview-workflow.md](references/md2wechat-preview-workflow.md)

把控件名称和页面顺序视为定位线索，不要当作永久选择器。实时界面与参考存在实质冲突时停止并报告。

## 先完成图文排版

用户提供 Markdown、长文或需要多张知识卡时，先完成排版资产，再打开发布页面：

1. 判断产物是微信文章 HTML、图文卡片组、单张封面还是普通配图。
2. 根据内容目的选择模板，不只根据“好看”选择。
3. 先压缩标题并确定主关键词、层级、语义分行、对齐和留白。
4. 图文卡片保持同一网格、字体、强调色和页码系统；一套内容只用一个主模板。
5. 生成本地预览，检查截断、溢出、字体替换、对比度、图片顺序和移动端可读性。
6. 把最终 HTML 或图片列表写入发布简报，获得用户批准后才进入浏览器发布阶段。

不要把模板名称当成品牌授权，不要复制第三方 Logo、受保护字体文件或品牌独有装饰。优先使用系统字体或许可证明确的开源字体。

## 获取发布简报

打开创作者页面前，明确：

- 平台、账号和发布目标；
- 视频或图文；
- 素材路径、排列顺序和封面；
- 标题、正文或简介、话题、标签、播放列表或合集；
- 立即发布、定时、草稿、私密、不公开或公开；
- 受众或儿童内容设置；
- 商业合作、商品链接、原创、AI/合成内容和其他必要声明；
- 用户是否授权执行最终发布动作。

不要推断原创权、商业关系、内容声明、受众分类或法律确认。缺少会影响结果的事实时，向用户确认。

## 选择发布通道

按以下顺序选择：

1. 官方发布 API 或官方授权集成；
2. 用户自有稳定浏览器档案中的普通创作者界面；
3. 使用可见的 Computer Use 执行重复界面操作，并保留人工复核。

不要引入指纹伪造、代理轮换、验证码求解、逆向请求签名、隐藏 JavaScript 注入或以规避平台执法为目的的自动化。

## 使用 Computer Use

1. 每次决策前获取最新浏览器状态。
2. 优先使用辅助功能元素；辅助功能树不足时才使用坐标点击。
3. 每次跳转、弹窗、上传或切换标签页后重新获取状态，不复用过期元素索引。
4. 使用可见输入并回读页面值，核对字数、话题、封面、受众、排期和声明。
5. 同一时间只操作一个账号的一项发布任务。
6. 密码、扫码、MFA、CAPTCHA、安全警告和异常权限请求均交给用户。
7. 平台支持时优先保存草稿，否则停在最终确认页。
8. 最终提交前展示目标账号、标题、素材、可见范围或排期以及全部声明。没有明确授权时必须确认；遇到意外承诺或高影响内容时，即使已有一般授权也要停止确认。
9. 最终发布按钮只点击一次，不因页面响应慢而盲目重试。
10. 通过内容管理页或返回的内容 URL 核验结果。

## 处理提交状态不明

最终点击没有明确结果时：

1. 记录当前 URL、可见状态和截图。
2. 不再次点击发布。
3. 使用同一账号打开内容管理页。
4. 按标题、上传时间、草稿、定时或处理中状态检索。
5. 带证据返回 `已发布`、`已定时`、`草稿`、`未找到` 或 `未知`。

## 停止条件

出现以下任一情况时停止，不发布：

- 登录账号或目标身份不明确；
- 出现安全挑战、账号警告或限制；
- 页面要求用户没有授权的声明；
- 素材、封面、可见范围、受众或排期与简报不符；
- 上传或处理状态不清楚；
- 同一账号正被其他会话操作；
- 平台提示频率、政策或账号风险；
- 内容管理页无法区分提交失败和延迟处理。
