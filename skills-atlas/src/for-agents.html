Endpoints

1. 先读索引，再读正文

索引只包含筛选所需的信息；正文按需加载，避免一次读取全部 6 MB 语料。

data/index.json全部技能元数据id · category · description · tags · path · json_url · original data/skills/<id>.json单个技能的完整内容元数据 + Markdown content llms.txt纯文本索引分类、技能列表与使用说明 llms-full.txt完整语料仅在确实需要全部技能时读取 data/originals.json原创技能列表project-original 的 {{ORIGINALS}} 个技能 id sitemap.xml站点入口索引与指南页

Workflow

2. 推荐检索流程

  1. 读索引GET data/index.json，拿到 {{TOTAL}} 个技能的 id、分类、描述和标签。
  2. 先筛选按任务选择 3-5 个最相关的 id；不要一次读完全部正文。
  3. 读正文GET data/skills/<id>.json，使用 content 字段作为技能说明。
  4. 再执行先说明选择理由和执行步骤；需要全量语料时才读 llms-full.txt。

3. 可直接发给 Agent 的指令

Agent prompt
你是我的技能检索助手。请完成以下任务：

1. 读取 AGI Skills Atlas 索引：{{PAGES_URL}}data/index.json
2. 根据我的任务，从索引中筛选 3-5 个最相关的技能；只使用索引里真实存在的 id。
3. 读取这些技能的完整内容：{{PAGES_URL}}data/skills/<id>.json，使用其中的 content 字段。
4. 先用一句话说明你选了什么、为什么；再给出执行步骤。
5. 不要编造不存在的技能或能力；如果索引里没有合适的，直接说没有。

我的任务：<在这里写你的任务>

把这段指令和索引地址一起发给 Claude、Codex、OpenClaw、Hermes 或其他能联网的 Agent。它会先筛选，再按需读取正文。

4. 字段说明

字段位置说明
idindex / skill技能唯一标识，也是 JSON 文件名
categoryindex / skill14 个主分类之一的 id
category_labelindex / skill分类中文名
descriptionindex / skill用于筛选的摘要；正文在 content
tagsindex / skill角色、领域或关键词
pathindex / skill仓库内路径，如 skills/ui-ux-pro-max/SKILL.md
json_urlindex该技能的 JSON 地址
originalindex / skill是否 project-original
contentskillSKILL.md 正文（Markdown）
content_availableskill正文是否公开；为 false 时只保留索引

Notes

5. 注意事项

  • 所有文件都是 UTF-8。若用本地静态服务器预览，使用 python3 skills-atlas/serve.py，它会返回正确的 charset。
  • 索引中的 description 是摘要；执行前以 content 为准。
  • 技能正文可能包含命令、脚本或平台操作步骤；先读懂再执行，不要盲目运行。
  • 这个站点是只读镜像。新增或修正技能请走 PR；合并后 Pages 自动重建。
  • 需要全量检索时再读 llms-full.txt；日常任务优先用 data/index.json + 单技能 JSON。
